# 软考系统架构师 · 每日执行任务表

> 目标考试：2026年10月24-27日
> 核心策略：不读教材，刷题为驱动，错题本为核心资产
> 如何使用：从第一阶段开始，每天打开对应星期的任务，照做即可

---

## 重要说明：三科并重

很多人刷题只刷选择题，这是最大的坑。

**每天的任务里已经包含了三科轮换，不要自己只做选择题。**

| 科目 | 每天占比 | 原因 |
|------|---------|------|
| 综合知识（选择题） | 60% | 分值最大，提分最快 |
| 案例分析 | 25% | 需要专门练"写"，不是看懂就行 |
| 论文 | 15% | 每天积累一点，避免考前突击 |

---

## 第一阶段：建立框架（第1-4周）

> 目标：做2套真题摸底，建立错题本，整理3个项目素材卡

### 每日任务（工作日）

**每天固定：晚上 1.5 小时**

```
【第1步 · 45分钟】刷选择题
  → 打开近5年真题，按套卷做
  → 每天做30-40题（不要求连续，做到哪算哪）
  → 每题做完立刻对答案，错的题立刻搞懂

【第2步 · 30分钟】整理错题
  → 把今天错的题记入错题本
  → 每条错题记录：题目要点 + 正确答案 + 我为什么错
  → 格式：YYYY-MM-DD | 考点 | 题目摘要 | 正确思路

【第3步 · 15分钟】轮换任务（按星期几决定今天做什么）
```

**第3步轮换表：**

| 星期 | 今日轮换任务 | 说明 |
|------|-------------|------|
| 周一 | 看案例分析1道（只读题+看答案，不写） | 先建立案例题感 |
| 周二 | 整理1个项目素材卡（背景+问题） | 论文素材准备 |
| 周三 | 看案例分析1道 | 同上 |
| 周四 | 整理1个项目素材卡（方案+效果） | 论文素材准备 |
| 周五 | 本周错题复盘（快速过一遍本周所有错题） | 巩固记忆 |

### 周末任务

| 时间 | 任务 |
|------|------|
| 周六上午 2h | 完整做1套真题选择题（75题，限时120分钟） |
| 周六下午 1h | 对答案 + 整理错题 |
| 周日上午 2h | 论文写作练习（第1周写摘要，第2周起写完整论文） |
| 周日下午 1h | 本周总结：错题本多少条？正确率提升了吗？ |

### 第一阶段验收（第4周末）

- [ ] 错题本有至少100条
- [ ] 整理了3个项目素材卡（五段式初步版）
- [ ] 做了2套完整真题，知道自己的盲区分布

**如果没达到 → 延长第一阶段1-2周，不要硬进第二阶段**

## 第二阶段：全面攻坚（第5-11周，共7周）

> 目标：选择题正确率稳定在55+，案例能写出完整步骤，论文有3篇草稿

### 每日任务（工作日）

**每天固定：晚上 2 小时**

```
【第1步 · 50分钟】刷选择题 + 整理错题
  → 每天40-50题
  → 错题本新增条目
  → 二刷旧错题（每天过10条旧错题）

【第2步 · 40分钟】轮换任务（按星期几）
```

**第2步轮换表（第二阶段）：**

| 星期 | 今日轮换任务 | 具体要求 |
|------|-------------|----------|
| 周一 | 案例分析1道（完整写，不限时） | 写完整步骤，对答案打分 |
| 周二 | 论文练习（摘要300字，计时15分钟） | 练速度和结构感 |
| 周三 | 案例分析1道（完整写） | 同上 |
| 周四 | 论文练习（完整写，计时120分钟） | 每周完整写1篇 |
| 周五 | 本周错题大复盘 | 所有本周新错题 + 二刷旧错题 |

### 周末任务

| 时间 | 任务 |
|------|------|
| 周六上午 2.5h | **全真模拟**：选择题75题（限时）+ 案例分析1道 |
| 周六下午 1.5h | 对答案 + 分析失分点 |
| 周日上午 2h | 论文完整写作（计时120分钟，选不同题目） |
| 周日下午 1h | 本周总结 + 调整下周重点 |

### 第二阶段论文推进表

| 周次 | 本周论文任务 |
|------|-------------|
| 第5周 | 项目A素材卡完善（五段式完整版） |
| 第6周 | 项目B素材卡完善 |
| 第7周 | 项目C素材卡完善 |
| 第8周 | 论文1完整草稿（基于项目A，计时写） |
| 第9周 | 论文2完整草稿（基于项目B） |
| 第10周 | 论文3完整草稿（基于项目C） |
| 第11周 | 三篇论文找人批改 + 修改 |

### 第二阶段验收（第11周末）

- [ ] 选择题正确率稳定在55分以上
- [ ] 错题本累计300条以上
- [ ] 案例分析每道题能写出完整步骤
- [ ] 3篇论文草稿完成，至少1篇经过批改

## 第三阶段：冲刺模拟（第12-16周，共5周）

> 目标：全真模拟，查漏补缺，论文熟到能默写

### 每日任务（工作日）

**每天固定：晚上 2-2.5 小时**

```
【每日必做 · 60分钟】刷选择题 or 二刷错题本
  → 交替进行：一天刷新题，一天二刷错题
  → 目标：选择题正确率稳定在60+

【每日轮换 · 60-90分钟】
```

**轮换任务表（第三阶段）：**

| 星期 | 今日轮换任务 |
|------|-------------|
| 周一 | 案例分析1道（计时完成） |
| 周二 | 论文默写练习（不看书，默写摘要+正文框架，限时） |
| 周三 | 选择题薄弱模块专项刷（只刷错题本里的高频考点） |
| 周四 | 案例分析1道（计时完成） |
| 周五 | 本周全科目复盘（选择题正确率 + 案例失分点 + 论文问题） |

### 周末任务（全真模拟）

```
周六：全真模拟考试（完全按真实考试节奏）
  上午 9:00-13:00：综合知识 + 案例分析（连考）
  下午：对答案 + 打分 + 分析
  
周日：论文 + 查漏
  上午：论文完整写作（计时120分钟，选不同题目）
  下午：查漏补缺（专攻本周发现的弱点）
```

### 第三阶段验收（第16周末）

- [ ] 选择题模拟分数稳定在60+
- [ ] 120分钟内能完成2500字论文（含思考）
- [ ] 全真模拟三科总分 > 140分（225满分）

## 第四阶段：考前调整（第17-18周）

> 目标：保持手感，不过度消耗，调整状态

### 每日任务（每天1小时，不要多）

```
每天：
  【30分钟】看错题本（只看，不重新做，保持印象）
  【15分钟】默写1篇论文摘要（300字，计时）
  【15分钟】做10道选择题保持手感（不追求正确率）
```

### 考前一周特别安排

| 时间 | 任务 |
|------|------|
| 考前第7天 | 最后一套全真模拟（找节奏感，不纠结分数） |
| 考前第5天 | 论文素材卡最后过一遍（3个项目全部默念一遍） |
| 考前第3天 | 停止刷题，只看笔记和错题本 |
| 考前第2天 | 熟悉机考系统（官网模拟系统） |
| 考前第1天 | 准备好证件，早睡，不复习 |

## 错题本格式模板

用Excel或Markdown表格，每天维护：

| 日期 | 考点分类 | 题目摘要 | 正确答案 | 我为什么错 | 掌握状态 |
|------|---------|----------|----------|-----------|---------|
| 0603 | 架构评估-ATAM | 问ATAM评估的输出产物 | 质量属性场景 | 我答成了架构方案 | 未掌握 |

**掌握状态三档：**
- 未掌握：第一次错
- 模糊：二刷时还犹豫
- 已掌握：三刷以上不再错

---

## 论文素材卡模板

每个项目单独一张卡，按这个格式整理：

```
【项目X素材卡】

一、项目背景（写在论文第一段）
  - 项目名称：
  - 项目规模：用户量/并发量/数据量
  - 技术栈：
  - 我在项目中的角色：

二、遇到的问题（写在论文第二段）
  - 核心架构问题是什么：
  - 这个问题导致的后果：

三、方案对比（写在论文第三段，这是得分重点）
  - 方案A：描述 + 优缺点
  - 方案B：描述 + 优缺点
  - 最终选择：为什么选这个

四、实施过程（写在论文第四段）
  - 分几步落地的：
  - 遇到什么阻力，怎么解决的：

五、效果（写在论文第五段，要有量化数据）
  - 响应时间：从 X ms 降到 Y ms
  - 可用性：从 X% 提升到 Y%
  - 其他量化指标：
```

## 关于"纯刷题不读教材"的补充说明

这个计划完全基于刷题驱动，**不需要读官方教材**。

但有一件事教材替代不了：**考试专用术语体系。**

如果你刷题时发现某个概念反复出现但就是理解不透（比如"质量属性六个维度"、"架构评估ATAM步骤"），去搜一下这个概念的解释，**只学这个概念，不要读整章**。

推荐资源（不用买书）：
- 希赛网/51CTO的考点精讲视频（B站有）
- CSDN上"软考系统架构师 XX考点总结"系列文章
- 某个概念不懂 → 直接搜"软考 架构师 XX概念"，不用系统学
