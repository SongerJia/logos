  NodeA(Follower)  NodeB(Follower)  NodeC(Follower)
       |                |               |
    心跳超时?         心跳超时?        心跳超时?
       |           最先超时!            |
       v                v               v
  [等待]          Candidate开始选举!     [等待]
                   term=2
                   投票给 自己(A)
                   RequestVote → B, C

NodeB收到:        NodeC收到:
term=2 >= myTerm=1  term=2 >= myTerm=1  
OK! 投给 A         OK! 投给 A
VoteResponse → A   VoteResponse → A

NodeA 收到 2票 (自己+B 或 自己+C)
  2 >= majority(3/2=1.5) ✓
  → 成为 Leader!
  → 开始发 AppendEntries(心跳)
