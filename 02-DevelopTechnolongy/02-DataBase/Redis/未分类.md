## Redis 整体优先级

```
P0 必考（源码级深度）：
  01 数据结构底层编码  >  05 缓存三大问题  >  06 分布式锁(SETNX/Redlock)
  >  03 Cluster槽位/故障转移

P1 高频问答（原理 + 工程实践）：
  02 持久化(RDB/AOF/混合)  >  04 内存淘汰策略
  >  07 事务与Lua脚本  >  08 Pipeline/多线程

P2 架构加分项：
  03 Sentinel选举/Raft  >  05 缓存一致性(订阅binlog)
```

**推荐笔记顺序**：`01 → 05 → 06 → 02 → 04 → 07 → 03 → 08`

理由：先攻克最重的数据结构底层(01)，紧接着学缓存设计三大问题(05)和分布式锁(06)（这两块工程上最常用），然后学持久化(02)和内存管理(04)（运维必备），接着是事务与 Lua(07)（原子操作必备），再看高可用架构(03)（Sentinel/Cluster 原理），最后补充性能调优(08)。

## Redis 与其它模块的关键连接点

```
Redis                               MySQL
─────                               ─────
缓存一致性(旁路缓存)                → 先更DB还是先删缓存？
缓存穿透(BloomFilter)               → 用MySQL数据初始化布隆过滤器
热key/bigkey                       → 大表查询结果的缓存策略
事务隔离                          → Redis事务(无回滚) vs MySQL ACID

Redis                               Spring
─────                               ──────
@Cacheable注解                     → CacheManager → RedisCache
RedisTemplate序列化                 → Jackson2JsonRedisSerializer vs JDK序列化
分布式锁                           → Redisson与Spring Integration整合
Session共享                        → Spring Session Redis

Redis                               消息队列
─────                                ──────
List(BLPOP/BRPUSH)                → 简易MQ（不如RabbitMQ/Kafka）
Stream(Pub/Sub进化版)              → 支持消费者组，类似Kafka
与RabbitMQ选型                    → 高可靠用RabbitMQ，高吞吐用Kafka，简单场景用Redis Stream
```
