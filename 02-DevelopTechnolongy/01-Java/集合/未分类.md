**Map 是集合里最重的**，光 HashMap 就能问出一套完整面试题。建议这个模块单独开一篇笔记，把 `put` 全流程画成流程图——从 hash 计算 → 找桶 → 链表/红黑树判断 → 扩容，每一步都能说清楚。

**并发集合（05）和并发模块有强依赖**，`ConcurrentHashMap` 的 CAS+synchronized 要放到你后面整理并发笔记时一起深入，这里只需要记住"是什么、为什么比 Hashtable 好"就够了，原理留到并发篇。

**设计思想（07）这块容易被忽视**，但它是把知识点"用起来"的关键。建议在整理完前几个模块后，回来做一张对比表——什么场景用什么集合，加载因子、初始容量怎么定，这样笔记才是有逻辑的网络而不是词条堆砌。
