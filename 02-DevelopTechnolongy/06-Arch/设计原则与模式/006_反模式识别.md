|#|反模式|表现|后果|如何识别 & 重构|
|---|---|---|---|---|
|**1.6.1**|**God Object 上帝对象**|一个类几千行，什么都管|无法测试、无法复用、改动牵一发动全身|按SRP拆分；看类的行数和方法数是否超标|
|**1.6.2**|**Spaghetti Code 意大利面代码**|if-else嵌套10层，逻辑缠绕|无人敢改，改一处崩三处|用策略/状态/责任链替代深层嵌套；圈复杂度>10报警|
|**1.6.3**|**Golden Hammer 金锤子综合征**|手里拿着锤子看什么都是钉子|强行用不合适的方案解决问题|技术选型前至少对比2个候选方案(ADR)|
|**1.6.4**|**Cargo Cult Programming 货物崇拜编程**|不理解就照抄别人的代码|出问题时完全不知道怎么排查|每一行代码都要知道"为什么要这么写"|
|**1.6.5**|**Premature Optimization 过早优化**|还没瓶颈就开始搞复杂的优化|代码复杂度飙升，收益极低|先跑基准测试(Benchmark)，找到真正的瓶颈再优化|
|**1.6.6**|**Copy-Paste Programming 复制粘贴编程**|同一段逻辑copy了5份，每份稍有不同|改bug要改5处，漏改一处就是隐患|DRY原则；抽取公共方法/基类/工具类|
