## 第一章 滑动窗口核心思想

### 1.1 什么是滑动窗口

滑动窗口是一种**在数组/字符串上维护一个连续区间**的技术，通过两个指针 `left` 和 `right` 描述窗口边界，`right` 向右扩展窗口，`left` 向右收缩窗口，像一扇窗户在数据上滑动。

```
数组:  [2, 3, 1, 2, 4, 3]
        |_______|
        left   right    ← 窗口 [2,3,1,2]
```

### 1.2 适用场景

滑动窗口适用于以下**关键词**的题目：

| 关键词 | 典型题目 |
|--------|----------|
| 连续子数组 | 和 ≥ K 的最短子数组 |
| 连续子串 | 无重复字符的最长子串 |
| 固定大小 | 长度 K 的子数组最大和 |
| 至多/至少 | 最多包含 K 个不同字符 |
| 满足某条件 | 最小覆盖子串 |

### 1.3 两大模板

#### 模板一：求最长/最大窗口（窗口合法时扩大）

```java
public int slidingWindowMax(int[] nums) {
    int left = 0, result = 0;
    // 维护窗口状态的变量（如计数、和等）
    int windowState = 0;

    for (int right = 0; right < nums.length; right++) {
        // 1. 将 nums[right] 加入窗口，更新 windowState
        windowState += nums[right];

        // 2. 当窗口不合法时，收缩左边界
        while (windowInvalid(windowState)) {
            // 移除 nums[left]，更新 windowState
            windowState -= nums[left];
            left++;
        }

        // 3. 此时窗口合法，更新结果
        result = Math.max(result, right - left + 1);
    }
    return result;
}
```

**关键点**：`while` 循环保证收缩到窗口**恰好合法**，此时窗口最大。

#### 模板二：求最短/最小窗口（窗口合法时收缩）

```java
public int slidingWindowMin(int[] nums, int target) {
    int left = 0, result = Integer.MAX_VALUE;
    int windowState = 0;

    for (int right = 0; right < nums.length; right++) {
        // 1. 扩展右边界
        windowState += nums[right];

        // 2. 当窗口满足条件时，尝试收缩左边界
        while (windowState >= target) {
            // 更新最短结果
            result = Math.min(result, right - left + 1);
            // 收缩
            windowState -= nums[left];
            left++;
        }
    }
    return result == Integer.MAX_VALUE ? 0 : result;
}
```

**关键点**：`while` 循环在满足条件时**不断收缩**，找到最短窗口。

### 1.4 时间复杂度

- `left` 和 `right` 各最多遍历数组一次
- 总时间复杂度 **O(n)**，空间复杂度取决于窗口状态维护（通常 O(1) 或 O(k)）

> **面试核心**：滑动窗口的本质是将暴力 O(n²) 优化到 O(n)，因为两个指针同向移动、不回退。

## 第二章 固定窗口

### 2.1 固定窗口原理

窗口大小 `k` 恒定，`right` 每右移一步，`left` 同步右移一步，窗口始终为 `k` 大小。

```
[1, 3, -1, 5, 7, 3]   k=3
|______|              窗口 [1,3,-1] 和=3
   |______|           窗口 [3,-1,5] 和=7
      |______|        窗口 [-1,5,7] 和=11
```

### 2.2 题1343：大小为 K 且平均值大于等于阈值的子数组数目

**题目**：给你一个整数数组 `arr` 和两个整数 `k` 和 `threshold`，求长度为 `k` 且平均值 ≥ threshold 的子数组数目。

**思路**：固定窗口 + 维护窗口和

```java
public int numOfSubarrays(int[] arr, int k, int threshold) {
    int sum = 0;
    int count = 0;
    int target = k * threshold; // 转换为总和比较，避免浮点

    // 先计算第一个窗口
    for (int i = 0; i < k; i++) {
        sum += arr[i];
    }
    if (sum >= target) count++;

    // 滑动窗口
    for (int i = k; i < arr.length; i++) {
        sum += arr[i] - arr[i - k]; // 右进左出
        if (sum >= target) count++;
    }
    return count;
}
```

- **时间**：O(n)
- **空间**：O(1)

### 2.3 题239：滑动窗口最大值（⭐Hard 必考）

**题目**：给你一个数组 `nums` 和滑动窗口大小 `k`，返回每个窗口中的最大值。

```
输入: nums = [1,3,-1,-3,5,3,6,7], k = 3
输出: [3,3,5,5,6,7]
```

#### 方法一：大顶堆（容易理解但非最优）

```java
public int[] maxSlidingWindow(int[] nums, int k) {
    int n = nums.length;
    int[] result = new int[n - k + 1];
    // 大顶堆：存储 {值, 索引}，按值降序
    PriorityQueue<int[]> heap = new PriorityQueue<>((a, b) -> b[0] - a[0]);

    for (int i = 0; i < n; i++) {
        heap.offer(new int[]{nums[i], i});
        // 移除窗口外的元素（堆顶但索引超出窗口）
        while (heap.peek()[1] <= i - k) {
            heap.poll();
        }
        // 窗口形成后记录结果
        if (i >= k - 1) {
            result[i - k + 1] = heap.peek()[0];
        }
    }
    return result;
}
```

- **时间**：O(n log n)，每次堆操作 O(log n)
- **空间**：O(n)

#### 方法二：单调递减队列（⭐最优解）

**核心思想**：维护一个**单调递减的双端队列**，队首永远是当前窗口最大值。

```java
public int[] maxSlidingWindow(int[] nums, int k) {
    int n = nums.length;
    int[] result = new int[n - k + 1];
    // 双端队列存储索引，对应值单调递减
    Deque<Integer> deque = new LinkedList<>();

    for (int i = 0; i < n; i++) {
        // 1. 移除队首超出窗口的元素
        while (!deque.isEmpty() && deque.peekFirst() <= i - k) {
            deque.pollFirst();
        }
        // 2. 从队尾移除所有比当前元素小的（它们不可能成为最大值）
        while (!deque.isEmpty() && nums[deque.peekLast()] <= nums[i]) {
            deque.pollLast();
        }
        // 3. 当前索引入队
        deque.offerLast(i);
        // 4. 窗口形成后，队首即最大值
        if (i >= k - 1) {
            result[i - k + 1] = nums[deque.peekFirst()];
        }
    }
    return result;
}
```

**图解单调队列过程**：

```
nums = [1, 3, -1, -3, 5, 3, 6, 7], k = 3

i=0: 队列=[0(1)]          窗口未形成
i=1: 1<3,移除0,队列=[1(3)] 窗口未形成
i=2: 队列=[1(3),2(-1)]    窗口[1,3,-1], max=3 ✓
i=3: 队列=[1(3),2(-1),3(-3)] 窗口[3,-1,-3], max=3 ✓
i=4: 4-k=1,移除1; 3<5移除2,3; 队列=[4(5)] 窗口[-1,-3,5], max=5 ✓
i=5: 队列=[4(5),5(3)]     窗口[-3,5,3], max=5 ✓
i=6: 6-k=3,不移除; 5<6移除4,5; 队列=[6(6)] 窗口[5,3,6], max=6 ✓
i=7: 7-k=4,不移除; 6<7移除6; 队列=[7(7)] 窗口[3,6,7], max=7 ✓

结果: [3, 3, 5, 5, 6, 7]
```

- **时间**：O(n)，每个元素入队出队各一次
- **空间**：O(k)

**面试追问**：
- Q: 为什么是单调递减而不是递增？
- A: 因为我们需要最大值在队首。如果递增，最大值在队尾，不方便移除窗口外的元素。递减保证队首始终是当前窗口最大值。

- Q: 为什么 `<=` 而不是 `<`？
- A: 用 `<=` 移除等于当前值的元素也无所谓，因为当前值也能充当最大值。不影响结果正确性，但可以减少队列长度。

### 2.4 题438：找到字符串中所有字母异位词

**题目**：给定字符串 `s` 和 `p`，找到 `s` 中所有 `p` 的字母异位词子串的起始索引。

```java
public List<Integer> findAnagrams(String s, String p) {
    List<Integer> result = new ArrayList<>();
    if (s.length() < p.length()) return result;

    int[] pCount = new int[26];
    int[] sCount = new int[26];

    for (char c : p.toCharArray()) pCount[c - 'a']++;

    int k = p.length();
    for (int i = 0; i < s.length(); i++) {
        sCount[s.charAt(i) - 'a']++;
        if (i >= k) {
            sCount[s.charAt(i - k) - 'a']--; // 移除窗口最左
        }
        if (i >= k - 1 && Arrays.equals(sCount, pCount)) {
            result.add(i - k + 1);
        }
    }
    return result;
}
```

- **时间**：O(n × 26)，可优化为 O(n) 用 `matches` 计数

#### 优化：matches 计数法

```java
public List<Integer> findAnagramsOpt(String s, String p) {
    List<Integer> result = new ArrayList<>();
    if (s.length() < p.length()) return result;

    int[] count = new int[26];
    for (char c : p.toCharArray()) count[c - 'a']++;

    int k = p.length();
    int matches = 0; // 记录匹配的字符数

    for (int i = 0; i < s.length(); i++) {
        // 右进
        int idx = s.charAt(i) - 'a';
        count[idx]--;
        if (count[idx] >= 0) matches++; // 还需要这个字符
        else matches--;                  // 多余字符

        // 左出
        if (i >= k) {
            int leftIdx = s.charAt(i - k) - 'a';
            count[leftIdx]++;
            if (count[leftIdx] > 0) matches--; // 移除了需要的字符
            else matches++;                     // 移除了多余字符
        }

        if (matches == k) result.add(i - k + 1);
    }
    return result;
}
```

**面试追问**：
- Q: `Arrays.equals` 每次比较 26 个元素，为什么还能 O(n)？
- A: 严格说是 O(26n) = O(n)，但常数较大。用 `matches` 计数可以做到真正的 O(n)。

## 第三章 可变窗口——求最长

### 3.1 题3：无重复字符的最长子串（⭐必考 Top 3）

**题目**：给定一个字符串 `s`，找到其中不包含重复字符的最长子串的长度。

```
输入: s = "abcabcbb"
输出: 3  ("abc")
```

**思路**：可变窗口 + HashSet/HashMap 记录字符位置

```java
public int lengthOfLongestSubstring(String s) {
    Map<Character, Integer> lastIndex = new HashMap<>(); // 字符→上次出现位置
    int left = 0, maxLen = 0;

    for (int right = 0; right < s.length(); right++) {
        char c = s.charAt(right);
        // 如果字符之前出现过，且出现在窗口内，移动 left
        if (lastIndex.containsKey(c) && lastIndex.get(c) >= left) {
            left = lastIndex.get(c) + 1;
        }
        lastIndex.put(c, right);
        maxLen = Math.max(maxLen, right - left + 1);
    }
    return maxLen;
}
```

**图解**：

```
s = "abcabcbb"

right=0 'a': lastIndex={a:0}, left=0, window="a",     maxLen=1
right=1 'b': lastIndex={a:0,b:1}, left=0, window="ab",  maxLen=2
right=2 'c': lastIndex={a:0,b:1,c:2}, left=0, window="abc", maxLen=3
right=3 'a': a出现过(0)>=left(0), left=1, window="bca", maxLen=3
right=4 'b': b出现过(1)>=left(1), left=2, window="cab", maxLen=3
right=5 'c': c出现过(2)>=left(2), left=3, window="abc", maxLen=3
right=6 'b': b出现过(4)>=left(3), left=5, window="cb",  maxLen=3
right=7 'b': b出现过(6)>=left(5), left=7, window="b",  maxLen=3

结果: 3
```

- **时间**：O(n)
- **空间**：O(min(m, n))，m 为字符集大小

**面试追问**：
- Q: 为什么判断条件是 `lastIndex.get(c) >= left`？
- A: 字符可能在 `left` 之前出现过，此时它在窗口外，不影响。只有 `lastIndex >= left` 才说明重复出现在当前窗口内。

- Q: 如果字符集是 ASCII，能否用数组代替 HashMap？
- A: 可以，`int[128]` 即可，性能更好。

### 3.2 题424：替换后的最长重复字符

**题目**：给你一个字符串 `s` 和一个整数 `k`，你可以选择字符串中任一字符并替换为其他字符，最多操作 `k` 次。求替换后最长的重复字符子串长度。

```
输入: s = "AABABBA", k = 1
输出: 4  (替换中间的A得到 "AABBBA" 或替换B得到 "AAAABBA")
```

**思路**：窗口内出现次数最多的字符 + k 替换 ≤ 窗口长度

```java
public int characterReplacement(String s, int k) {
    int[] count = new int[26];
    int left = 0, maxCount = 0, maxLen = 0;

    for (int right = 0; right < s.length(); right++) {
        int idx = s.charAt(right) - 'A';
        count[idx]++;
        maxCount = Math.max(maxCount, count[idx]); // 窗口内最高频字符数

        // 窗口长度 - 最高频字符数 > k → 需要替换太多，收缩
        while (right - left + 1 - maxCount > k) {
            count[s.charAt(left) - 'A']--;
            left++;
        }
        maxLen = Math.max(maxLen, right - left + 1);
    }
    return maxLen;
}
```

**核心公式**：`窗口长度 - 最高频字符数 = 需要替换的字符数 ≤ k`

**面试追问**：
- Q: `maxCount` 不需要在收缩时更新吗？
- A: 不需要。`maxCount` 记录的是历史最大值。如果收缩后真正的最高频变小了，`maxCount` 仍然偏大，导致 `while` 条件更严格（窗口可能更小），但最终 `maxLen` 不受影响——我们只关心能**扩大**窗口的情况，而扩大窗口一定需要 `maxCount` 更大。

### 3.3 题1004：最大连续1的个数 III

**题目**：给定一个二进制数组 `nums` 和整数 `k`，可以翻转最多 `k` 个 0 为 1，求最长连续 1 的子数组长度。

**思路**：窗口内 0 的个数 ≤ k

```java
public int longestOnes(int[] nums, int k) {
    int left = 0, zeros = 0, maxLen = 0;

    for (int right = 0; right < nums.length; right++) {
        if (nums[right] == 0) zeros++;

        while (zeros > k) {
            if (nums[left] == 0) zeros--;
            left++;
        }
        maxLen = Math.max(maxLen, right - left + 1);
    }
    return maxLen;
}
```

- **时间**：O(n)

### 3.4 题3：无重复最长子串的变种——至多包含 K 个不同字符

**题目**（LeetCode 340）：给定字符串 `s` 和整数 `k`，求至多包含 `k` 个不同字符的最长子串长度。

```java
public int lengthOfLongestSubstringKDistinct(String s, int k) {
    if (k == 0) return 0;
    int[] count = new int[128];
    int left = 0, distinct = 0, maxLen = 0;

    for (int right = 0; right < s.length(); right++) {
        char c = s.charAt(right);
        if (count[c]++ == 0) distinct++;

        while (distinct > k) {
            char leftChar = s.charAt(left);
            if (--count[leftChar] == 0) distinct--;
            left++;
        }
        maxLen = Math.max(maxLen, right - left + 1);
    }
    return maxLen;
}
```

### 4.1 题209：长度最小的子数组

**题目**：给定一个正整数数组 `nums` 和正整数 `target`，找出满足其和 ≥ target 的长度最小的连续子数组。

```
输入: target = 7, nums = [2,3,1,2,4,3]
输出: 2  ([4,3])
```

```java
public int minSubArrayLen(int target, int[] nums) {
    int left = 0, sum = 0, minLen = Integer.MAX_VALUE;

    for (int right = 0; right < nums.length; right++) {
        sum += nums[right];
        while (sum >= target) {
            minLen = Math.min(minLen, right - left + 1);
            sum -= nums[left];
            left++;
        }
    }
    return minLen == Integer.MAX_VALUE ? 0 : minLen;
}
```

**图解**：

```
nums = [2, 3, 1, 2, 4, 3], target = 7

right=0: sum=2  <7, 继续
right=1: sum=5  <7, 继续
right=2: sum=6  <7, 继续
right=3: sum=8  ≥7! minLen=4, 收缩: sum=6, left=1
right=4: sum=10 ≥7! minLen=4→no, 收缩: sum=7,left=2, minLen=3
                          再收缩: sum=6,left=3
right=5: sum=9  ≥7! minLen=3→no, 收缩: sum=7,left=4, minLen=2 ✓
                          再收缩: sum=4,left=5

结果: 2
```

- **时间**：O(n)
- **空间**：O(1)

### 4.2 题76：最小覆盖子串（⭐Hard 高频）

**题目**：给你字符串 `s`、`t`，找到 `s` 中涵盖 `t` 所有字符的最小子串。

```
输入: s = "ADOBECODEBANC", t = "ABC"
输出: "BANC"
```

**思路**：窗口覆盖 `t` 的所有字符时收缩左边界

```java
public String minWindow(String s, String t) {
    if (s.length() < t.length()) return "";

    // t 的字符需求
    Map<Character, Integer> need = new HashMap<>();
    for (char c : t.toCharArray()) need.merge(c, 1, Integer::sum);

    // 窗口内的字符计数
    Map<Character, Integer> window = new HashMap<>();
    int left = 0, valid = 0; // valid: 已满足的字符种类数
    int start = 0, minLen = Integer.MAX_VALUE;

    for (int right = 0; right < s.length(); right++) {
        char c = s.charAt(right);
        window.merge(c, 1, Integer::sum);

        // 如果该字符数量恰好满足需求
        if (window.get(c).equals(need.get(c))) {
            valid++;
        }

        // 当所有字符都满足时，尝试收缩
        while (valid == need.size()) {
            // 更新最短结果
            if (right - left + 1 < minLen) {
                minLen = right - left + 1;
                start = left;
            }
            // 收缩左边界
            char leftChar = s.charAt(left);
            if (window.get(leftChar).equals(need.get(leftChar))) {
                valid--; // 即将不满足
            }
            window.merge(leftChar, -1, Integer::sum);
            left++;
        }
    }
    return minLen == Integer.MAX_VALUE ? "" : s.substring(start, start + minLen);
}
```

**核心要点**：
1. `need` 记录 `t` 中每个字符的需求量
2. `window` 记录当前窗口内各字符数量
3. `valid` 记录已满足需求的字符种类数
4. 当 `valid == need.size()` 时所有字符满足，开始收缩

- **时间**：O(n + m)，n = s.length，m = t.length
- **空间**：O(字符集大小)

**面试追问**：
- Q: `valid` 的含义？
- A: 它记录"窗口中满足需求量的字符种类数"。例如 `need = {A:2, B:1}`，当窗口中有 ≥2 个 A 且 ≥1 个 B 时，`valid = 2 = need.size()`，表示全覆盖。

- Q: 为什么收缩时先判断再减少？
- A: 如果当前 `window[leftChar] == need[leftChar]`，再减少一个就不满足了，所以先 `valid--`，再 `window[leftChar]--`。

### 5. 题567：字符串的排列

**题目**：判断 `s2` 是否包含 `s1` 的排列。

```java
public boolean checkInclusion(String s1, String s2) {
    if (s1.length() > s2.length()) return false;

    int[] count = new int[26];
    for (char c : s1.toCharArray()) count[c - 'a']--;

    for (int i = 0; i < s2.length(); i++) {
        count[s2.charAt(i) - 'a']++; // 右进
        if (i >= s1.length()) {
            count[s2.charAt(i - s1.length()) - 'a']--; // 左出
        }
        if (allZero(count)) return true;
    }
    return false;
}

private boolean allZero(int[] count) {
    for (int c : count) if (c != 0) return false;
    return true;
}
```

**技巧**：初始时 `count` 为 `s1` 的字符需求（负值），窗口滑动时累加，全 0 即匹配。

### 5.3 题30：串联所有单词的子串（⭐Hard）

**题目**：找到 `s` 中恰好包含 `words` 所有单词（任意顺序连接）的子串起始索引。每个单词长度相同。

```
输入: s = "barfoothefoobarman", words = ["foo","bar"]
输出: [0, 9]  ("barfoo" 和 "foobar")
```

**思路**：固定窗口 = 单词长度 × 单词数，按单词做频率匹配

```java
public List<Integer> findSubstring(String s, String[] words) {
    List<Integer> result = new ArrayList<>();
    if (words.length == 0) return result;

    int wordLen = words[0].length();
    int totalLen = wordLen * words.length;
    if (s.length() < totalLen) return result;

    Map<String, Integer> need = new HashMap<>();
    for (String w : words) need.merge(w, 1, Integer::sum);

    // 按 offset 分类，每类做一次滑动窗口
    for (int offset = 0; offset < wordLen; offset++) {
        int left = offset;
        Map<String, Integer> window = new HashMap<>();
        int valid = 0;

        for (int right = offset; right + wordLen <= s.length(); right += wordLen) {
            String word = s.substring(right, right + wordLen);

            if (need.containsKey(word)) {
                window.merge(word, 1, Integer::sum);
                if (window.get(word).equals(need.get(word))) valid++;

                // 超过窗口总长度，收缩
                if (right - left + wordLen > totalLen) {
                    String leftWord = s.substring(left, left + wordLen);
                    if (window.get(leftWord).equals(need.get(leftWord))) valid--;
                    window.merge(leftWord, -1, Integer::sum);
                    left += wordLen;
                }

                if (valid == need.size()) {
                    result.add(left);
                }
            } else {
                // 遇到不需要的单词，重置
                window.clear();
                valid = 0;
                left = right + wordLen;
            }
        }
    }
    return result;
}
```

**关键点**：按 `offset` 分类（0 到 wordLen-1），每类内部以单词为单位做标准滑动窗口。

- **时间**：O(n × wordLen / wordLen) = O(n)

### 6.3 题560：和为 K 的子数组（前缀和 + HashMap）

> 注意：这题**不能用滑动窗口**，因为数组可能有负数，窗口扩展不保证和递增。

```java
public int subarraySum(int[] nums, int k) {
    Map<Integer, Integer> prefixCount = new HashMap<>();
    prefixCount.put(0, 1); // 前缀和为0出现1次

    int count = 0, sum = 0;
    for (int num : nums) {
        sum += num;
        // 如果 sum - k 之前出现过，说明存在子数组和为 k
        count += prefixCount.getOrDefault(sum - k, 0);
        prefixCount.merge(sum, 1, Integer::sum);
    }
    return count;
}
```

**原理**：`prefix[j] - prefix[i] = k` → `prefix[i] = prefix[j] - k`

### 8.1 题1：两数之和（⭐面试第一题）

```java
public int[] twoSum(int[] nums, int target) {
    Map<Integer, Integer> map = new HashMap<>(); // 值→索引
    for (int i = 0; i < nums.length; i++) {
        int complement = target - nums[i];
        if (map.containsKey(complement)) {
            return new int[]{map.get(complement), i};
        }
        map.put(nums[i], i);
    }
    return new int[]{};
}
```

- **时间**：O(n)，**空间**：O(n)

**面试追问**：

### 8.3 题128：最长连续序列（⭐Union-Find / Set）

**题目**：给定未排序数组，找到最长连续元素序列长度（如 [100,4,200,1,3,2] → 4，即 [1,2,3,4]）。

```java
public int longestConsecutive(int[] nums) {
    Set<Integer> set = new HashSet<>();
    for (int n : nums) set.add(n);

    int maxLen = 0;
    for (int n : set) {
        // 只从序列起点开始找（n-1 不在集合中）
        if (!set.contains(n - 1)) {
            int current = n;
            int len = 1;
            while (set.contains(current + 1)) {
                current++;
                len++;
            }
            maxLen = Math.max(maxLen, len);
        }
    }
    return maxLen;
}
```

**核心**：只从**序列起点**（`n-1` 不存在）开始向右扩展，保证 O(n)。

- **时间**：O(n)，**空间**：O(n)

### 8.4 题41：缺失的第一个正数（⭐Hard 原地哈希）

**题目**：找到未排序数组中缺失的最小正整数，要求 O(n) 时间 + O(1) 空间。

```
输入: [3, 4, -1, 1]  →  输出: 2
```

**思路**：把数字 x 放到索引 x-1 的位置（原地哈希）

```java
public int firstMissingPositive(int[] nums) {
    int n = nums.length;
    // 把 nums[i] 放到 nums[nums[i]-1] 位置
    for (int i = 0; i < n; i++) {
        while (nums[i] > 0 && nums[i] <= n && nums[nums[i] - 1] != nums[i]) {
            int temp = nums[nums[i] - 1];
            nums[nums[i] - 1] = nums[i];
            nums[i] = temp;
        }
    }
    // 找到第一个 nums[i] != i+1 的位置
    for (int i = 0; i < n; i++) {
        if (nums[i] != i + 1) return i + 1;
    }
    return n + 1;
}
```

**图解**：

```
[3, 4, -1, 1]

i=0: nums[0]=3, 交换到位置2 → [-1, 4, 3, 1]
     nums[0]=-1, 跳过
i=1: nums[1]=4, 交换到位置3 → [-1, 1, 3, 4]
     nums[1]=1, 交换到位置0 → [1, -1, 3, 4]
     nums[1]=-1, 跳过
i=2: nums[2]=3, 已在正确位置
i=3: nums[3]=4, 已在正确位置

检查: [1, -1, 3, 4]
       ✓   ✗  →  缺少 2

输出: 2
```

- **时间**：O(n)，虽然 while 循环，但每次交换至少把一个数放到正确位置，总共最多 n 次交换
- **空间**：O(1)

### 8.5 题73：矩阵置零

```java
public void setZeroes(int[][] matrix) {
    int m = matrix.length, n = matrix[0].length;
    boolean firstRowZero = false, firstColZero = false;

    // 检查第一行/列是否有0
    for (int j = 0; j < n; j++) if (matrix[0][j] == 0) firstRowZero = true;
    for (int i = 0; i < m; i++) if (matrix[i][0] == 0) firstColZero = true;

    // 用第一行/列标记
    for (int i = 1; i < m; i++) {
        for (int j = 1; j < n; j++) {
            if (matrix[i][j] == 0) {
                matrix[i][0] = 0;
                matrix[0][j] = 0;
            }
        }
    }
    // 根据标记置零
    for (int i = 1; i < m; i++)
        for (int j = 1; j < n; j++)
            if (matrix[i][0] == 0 || matrix[0][j] == 0) matrix[i][j] = 0;

    // 处理第一行/列
    if (firstRowZero) for (int j = 0; j < n; j++) matrix[0][j] = 0;
    if (firstColZero) for (int i = 0; i < m; i++) matrix[i][0] = 0;
}
```

- **时间**：O(m × n)，**空间**：O(1)（用矩阵首行首列做标记）

### 9.1 题15：三数之和（⭐必考）

**题目**：找出数组中所有和为 0 的三元组（不重复）。

```java
public List<List<Integer>> threeSum(int[] nums) {
    List<List<Integer>> result = new ArrayList<>();
    Arrays.sort(nums);

    for (int i = 0; i < nums.length - 2; i++) {
        // 跳过重复
        if (i > 0 && nums[i] == nums[i - 1]) continue;
        // 剪枝：最小值 > 0
        if (nums[i] > 0) break;

        int left = i + 1, right = nums.length - 1;
        while (left < right) {
            int sum = nums[i] + nums[left] + nums[right];
            if (sum < 0) left++;
            else if (sum > 0) right--;
            else {
                result.add(Arrays.asList(nums[i], nums[left], nums[right]));
                // 跳过重复
                while (left < right && nums[left] == nums[left + 1]) left++;
                while (left < right && nums[right] == nums[right - 1]) right--;
                left++;
                right--;
            }
        }
    }
    return result;
}
```

- **时间**：O(n²)，**空间**：O(1)（不含输出）

**面试追问**：
- Q: 为什么排序？
- A: 排序后可以用对撞双指针 O(n) 找两数之和，总 O(n²)。不排序需要 O(n²) 嵌套 + 去重。

- Q: 去重逻辑？
- A: `i` 层 `nums[i] == nums[i-1]` 跳过；找到一组后 `left` 和 `right` 也要跳过相同的。

### 9.2 题11：盛最多水的容器

```java
public int maxArea(int[] height) {
    int left = 0, right = height.length - 1;
    int maxArea = 0;
    while (left < right) {
        int area = Math.min(height[left], height[right]) * (right - left);
        maxArea = Math.max(maxArea, area);

}
```

### 9.3 题42：接雨水（⭐Hard 高频）

**方法一：动态规划（左右最大值）**

```java
public int trap(int[] height) {
    int n = height.length;
    if (n == 0) return 0;

    int[] leftMax = new int[n];
    int[] rightMax = new int[n];

    leftMax[0] = height[0];
    for (int i = 1; i < n; i++) leftMax[i] = Math.max(leftMax[i - 1], height[i]);

    rightMax[n - 1] = height[n - 1];
    for (int i = n - 2; i >= 0; i--) rightMax[i] = Math.max(rightMax[i + 1], height[i]);

    int water = 0;
    for (int i = 0; i < n; i++) {
        water += Math.min(leftMax[i], rightMax[i]) - height[i];
    }
    return water;
}
```

**方法二：双指针 O(1) 空间**

```java
public int trap(int[] height) {
    int left = 0, right = height.length - 1;
    int leftMax = 0, rightMax = 0;
    int water = 0;

    while (left < right) {
        if (height[left] < height[right]) {
            if (height[left] >= leftMax) leftMax = height[left];
            else water += leftMax - height[left];
            left++;
        } else {
            if (height[right] >= rightMax) rightMax = height[right];
            else water += rightMax - height[right];
            right--;
        }
    }
    return water;
}
```

**原理**：`leftMax` 记录左侧最高，`rightMax` 记录右侧最高。哪边矮就处理哪边——矮的一侧的雨水只取决于该侧的最大值。

- **时间**：O(n)，**空间**：O(1)

### 10.2 题155：最小栈

```java
class MinStack {
    Deque<Integer> stack;
    Deque<Integer> minStack;

    public MinStack() {
        stack = new LinkedList<>();
        minStack = new LinkedList<>();
    }

    public void push(int val) {
        stack.push(val);
        if (minStack.isEmpty() || val <= minStack.peek()) {
            minStack.push(val);
        }
    }

    public void pop() {
        int val = stack.pop();
        if (val == minStack.peek()) minStack.pop();
    }

    public int top() { return stack.peek(); }
    public int getMin() { return minStack.peek(); }
}
```

**核心**：辅助栈只在新元素 ≤ 当前最小值时入栈。

### 10.3 题739：每日温度

### 10.4 题84：柱状图中最大矩形（⭐Hard 单调栈经典）

```java
public int largestRectangleArea(int[] heights) {
    int n = heights.length;
    int[] left = new int[n];  // 左边第一个更矮的位置
    int[] right = new int[n]; // 右边第一个更矮的位置

    Deque<Integer> stack = new LinkedList<>();

    // 找左边边界
    for (int i = 0; i < n; i++) {
        while (!stack.isEmpty() && heights[stack.peek()] >= heights[i]) {
            stack.pop();
        }
        left[i] = stack.isEmpty() ? -1 : stack.peek();
        stack.push(i);
    }
    stack.clear();

    // 找右边边界
    for (int i = n - 1; i >= 0; i--) {
        while (!stack.isEmpty() && heights[stack.peek()] >= heights[i]) {
            stack.pop();
        }
        right[i] = stack.isEmpty() ? n : stack.peek();
        stack.push(i);
    }

    int maxArea = 0;
    for (int i = 0; i < n; i++) {
        maxArea = Math.max(maxArea, heights[i] * (right[i] - left[i] - 1));
    }
    return maxArea;
}
```

**核心**：对每根柱子，找到左右两边第一个比它矮的柱子，面积 = 高度 × 宽度。

- **时间**：O(n)

### 10.5 题232：用栈实现队列

```java
class MyQueue {
    Deque<Integer> inStack;
    Deque<Integer> outStack;

    public MyQueue() {
        inStack = new LinkedList<>();
        outStack = new LinkedList<>();
    }

    public void push(int x) { inStack.push(x); }

    public int pop() {
        peek();
        return outStack.pop();
    }

    public int peek() {
        if (outStack.isEmpty()) {
            while (!inStack.isEmpty()) {
                outStack.push(inStack.pop());
            }
        }
        return outStack.peek();
    }

    public boolean empty() { return inStack.isEmpty() && outStack.isEmpty(); }
}
```

**原理**：入栈 `inStack`，出栈时如果 `outStack` 为空就把 `inStack` 全部倒入 `outStack`，利用栈的 LIFO 翻转两次恢复 FIFO。

### 11.1 题33：搜索旋转排序数组（⭐必考）

```java
public int search(int[] nums, int target) {
    int left = 0, right = nums.length - 1;
    while (left <= right) {
        int mid = left + (right - left) / 2;
        if (nums[mid] == target) return mid;

        // 判断哪半边有序
        if (nums[left] <= nums[mid]) { // 左半有序
            if (nums[left] <= target && target < nums[mid]) {
                right = mid - 1; // target 在左半
            } else {
                left = mid + 1;
            }
        } else { // 右半有序
            if (nums[mid] < target && target <= nums[right]) {
                left = mid + 1; // target 在右半
            } else {
                right = mid - 1;
            }
        }
    }
    return -1;
}
```

- **时间**：O(log n)

**面试追问**：
- Q: 为什么 `nums[left] <= nums[mid]` 用 `<=` 不用 `<`？
- A: 当 `left == mid`（只剩两个元素）时，用 `<=` 确保判断为左半有序。

### 11.3 题4：寻找两个正序数组的中位数（⭐Hard 必考）

```java
public double findMedianSortedArrays(int[] nums1, int[] nums2) {
    if (nums1.length > nums2.length) {
        return findMedianSortedArrays(nums2, nums1); // 保证 nums1 较短
    }
    int m = nums1.length, n = nums2.length;
    int left = 0, right = m;
    // 在 nums1 上二分，找分割点
    while (left <= right) {
        int i = (left + right) / 2;       // nums1 的分割点
        int j = (m + n + 1) / 2 - i;      // nums2 的分割点

        int nums1LeftMax = (i == 0) ? Integer.MIN_VALUE : nums1[i - 1];
        int nums1RightMin = (i == m) ? Integer.MAX_VALUE : nums1[i];
        int nums2LeftMax = (j == 0) ? Integer.MIN_VALUE : nums2[j - 1];
        int nums2RightMin = (j == n) ? Integer.MAX_VALUE : nums2[j];

        if (nums1LeftMax <= nums2RightMin && nums2LeftMax <= nums1RightMin) {
            // 找到正确分割
            if ((m + n) % 2 == 1) {
                return Math.max(nums1LeftMax, nums2LeftMax);
            } else {
                return (Math.max(nums1LeftMax, nums2LeftMax)
                      + Math.min(nums1RightMin, nums2RightMin)) / 2.0;
            }
        } else if (nums1LeftMax > nums2RightMin) {
            right = i - 1;
        } else {
            left = i + 1;
        }
    }
    throw new IllegalArgumentException();
}
```

- **时间**：O(log(min(m, n)))

**核心思路**：在较短数组上二分找分割点 `i`，则另一个数组的分割点 `j = (m+n+1)/2 - i` 自动确定。满足 `nums1LeftMax ≤ nums2RightMin` 且 `nums2LeftMax ≤ nums1RightMin` 即为正确分割。

```java
    return result;

private void backtrack(int[] nums, List<Integer> path,
                      List<List<Integer>> result, boolean[] used) {
    if (path.size() == nums.length) {
        result.add(new ArrayList<>(path));
        return;
    }
    for (int i = 0; i < nums.length; i++) {
        if (used[i]) continue;
        used[i] = true;
        path.add(nums[i]);
        backtrack(nums, path, result, used);
        path.remove(path.size() - 1);
        used[i] = false;
    }
}
```

### 12.6 题79：单词搜索（⭐矩阵回溯）

```java
public boolean exist(char[][] board, String word) {
    int m = board.length, n = board[0].length;
    boolean[][] visited = new boolean[m][n];
    for (int i = 0; i < m; i++) {
        for (int j = 0; j < n; j++) {
            if (dfs(board, word, 0, i, j, visited)) return true;
        }
    }
    return false;
}

private boolean dfs(char[][] board, String word, int index,
                    int i, int j, boolean[][] visited) {
    if (index == word.length()) return true;
    if (i < 0 || i >= board.length || j < 0 || j >= board[0].length
        || visited[i][j] || board[i][j] != word.charAt(index)) {
        return false;
    }
    visited[i][j] = true;
    boolean found = dfs(board, word, index + 1, i + 1, j, visited)
                  || dfs(board, word, index + 1, i - 1, j, visited)
                  || dfs(board, word, index + 1, i, j + 1, visited)
                  || dfs(board, word, index + 1, i, j - 1, visited);
    visited[i][j] = false; // 回溯
    return found;
}
```

**优化**：用 `board[i][j] ^= 256` 代替 `visited` 数组，省空间。

### 12.7 题131：分割回文串

```java
public List<List<String>> partition(String s) {
    List<List<String>> result = new ArrayList<>();
    backtrack(s, 0, new ArrayList<>(), result);
    return result;
}

private void backtrack(String s, int start, List<String> path,
                       List<List<String>> result) {
    if (start == s.length()) {
        result.add(new ArrayList<>(path));
        return;
    }
    for (int end = start + 1; end <= s.length(); end++) {
        if (isPalindrome(s, start, end - 1)) {
            path.add(s.substring(start, end));
            backtrack(s, end, path, result);
            path.remove(path.size() - 1);
        }
    }
}

private boolean isPalindrome(String s, int l, int r) {
    while (l < r) {
        if (s.charAt(l++) != s.charAt(r--)) return false;
    }
    return true;
}
```

**优化**：预计算 `dp[i][j]` 表示 `s[i..j]` 是否回文，避免重复判断。

### 12.8 题51：N 皇后（⭐经典回溯）

```java
public List<List<String>> solveNQueens(int n) {
    List<List<String>> result = new ArrayList<>();
    char[][] board = new char[n][n];
    for (char[] row : board) Arrays.fill(row, '.');
    backtrack(board, 0, result);
    return result;
}

private void backtrack(char[][] board, int row, List<List<String>> result) {
    if (row == board.length) {
        List<String> solution = new ArrayList<>();
        for (char[] r : board) solution.add(new String(r));
        result.add(solution);
        return;
    }
    for (int col = 0; col < board.length; col++) {
        if (isValid(board, row, col)) {
            board[row][col] = 'Q';
            backtrack(board, row + 1, result);
            board[row][col] = '.';
        }
    }
}

private boolean isValid(char[][] board, int row, int col) {
    // 检查同列
    for (int i = 0; i < row; i++)
        if (board[i][col] == 'Q') return false;
    // 检查左上对角线
    for (int i = row - 1, j = col - 1; i >= 0 && j >= 0; i--, j--)
        if (board[i][j] == 'Q') return false;
    // 检查右上对角线
    for (int i = row - 1, j = col + 1; i >= 0 && j < board.length; i--, j++)
        if (board[i][j] == 'Q') return false;
    return true;
}
```

- **时间**：O(n!)，每行选一列，有效剪枝后远小于 n^n

**面试追问**：
- Q: 能否用集合优化 `isValid`？
- A: 用三个 `Set`：`cols`（同列）、`diag1`（主对角线 `row-col`）、`diag2`（副对角线 `row+col`），O(1) 判断。

```java
public boolean canFinish(int numCourses, int[][] prerequisites) {
    List<List<Integer>> graph = new ArrayList<>();
    int[] inDegree = new int[numCourses];
    for (int i = 0; i < numCourses; i++) graph.add(new ArrayList<>());

    for (int[] pre : prerequisites) {
        graph.get(pre[1]).add(pre[0]);
        inDegree[pre[0]]++;
    }

    Queue<Integer> queue = new LinkedList<>();
    for (int i = 0; i < numCourses; i++) {
        if (inDegree[i] == 0) queue.offer(i);
    }

    int completed = 0;
    while (!queue.isEmpty()) {
        int course = queue.poll();
        completed++;
        for (int next : graph.get(course)) {
            if (--inDegree[next] == 0) queue.offer(next);
        }
    }
    return completed == numCourses;
}
```

### 14.5 并查集模板

```java
class UnionFind {
    int[] parent;
    int[] rank;
    int count; // 连通分量数

    public UnionFind(int n) {
        parent = new int[n];
        rank = new int[n];
        count = n;
        for (int i = 0; i < n; i++) parent[i] = i;
    }

    public int find(int x) {
        if (parent[x] != x) {
            parent[x] = find(parent[x]); // 路径压缩
        }
        return parent[x];
    }

    public boolean union(int x, int y) {
        int rootX = find(x), rootY = find(y);
        if (rootX == rootY) return false;
        // 按秩合并
        if (rank[rootX] < rank[rootY]) {
            parent[rootX] = rootY;
        } else if (rank[rootX] > rank[rootY]) {
            parent[rootY] = rootX;
        } else {
            parent[rootY] = rootX;
            rank[rootX]++;
        }
        count--;
        return true;
    }
}
```

```java
            uf.union(i, valueToIndex.get(nums[i] - 1));
        }
        if (valueToIndex.containsKey(nums[i] + 1)) {
            uf.union(i, valueToIndex.get(nums[i] + 1));
        }
    }

    // 统计每个连通分量的大小
    Map<Integer, Integer> componentSize = new HashMap<>();
    int max = 0;
    for (int i = 0; i < nums.length; i++) {
        int root = uf.find(i);
        componentSize.merge(root, 1, Integer::sum);
        max = Math.max(max, componentSize.get(root));
    }
    return max;
}
```

## 第十五章 堆与优先队列

### 15.1 题215：数组中的第 K 个最大元素

```java
public int findKthLargest(int[] nums, int k) {
    // 小顶堆，维护 K 个最大的
    PriorityQueue<Integer> heap = new PriorityQueue<>();
    for (int num : nums) {
        heap.offer(num);
        if (heap.size() > k) heap.poll(); // 堆顶是最小的，弹出
    }
    return heap.peek();
}
```

- **时间**：O(n log k)，**空间**：O(k)

**面试追问**：
- Q: 为什么用小顶堆找第 K 大？
- A: 小顶堆堆顶是最小值。维护大小为 k 的堆，当堆中元素超过 k 时弹出最小的，最终堆中保留最大的 k 个，堆顶即第 K 大。

- Q: 能否用快速选择？
- A: 可以，平均 O(n)，最坏 O(n²)。

```java
public int findKthLargestQuickSelect(int[] nums, int k) {
    return quickSelect(nums, 0, nums.length - 1, nums.length - k);
}

private int quickSelect(int[] nums, int left, int right, int k) {
    int pivot = nums[right], i = left;
    for (int j = left; j < right; j++) {
        if (nums[j] <= pivot) {
            swap(nums, i++, j);
        }
    }
    swap(nums, i, right);
    if (i == k) return nums[i];
    else if (i < k) return quickSelect(nums, i + 1, right, k);
    else return quickSelect(nums, left, i - 1, k);
}
```

### 15.2 题347：前 K 个高频元素

```java
public int[] topKFrequent(int[] nums, int k) {
    Map<Integer, Integer> freq = new HashMap<>();
    for (int num : nums) freq.merge(num, 1, Integer::sum);

    // 小顶堆，按频率排序
    PriorityQueue<Integer> heap = new PriorityQueue<>(
        (a, b) -> freq.get(a) - freq.get(b));
    for (int num : freq.keySet()) {
        heap.offer(num);
        if (heap.size() > k) heap.poll();
    }

    int[] result = new int[k];
    for (int i = 0; i < k; i++) result[i] = heap.poll();
    return result;
}
```

### 15.3 题295：数据流的中位数（⭐Hard）

```java
class MedianFinder {
    PriorityQueue<Integer> leftHeap;  // 大顶堆（存较小的一半）
    PriorityQueue<Integer> rightHeap; // 小顶堆（存较大的一半）

    public MedianFinder() {
        leftHeap = new PriorityQueue<>(Collections.reverseOrder());
        rightHeap = new PriorityQueue<>();
    }

    public void addNum(int num) {
        // 先加入大顶堆
        leftHeap.offer(num);
        // 将大顶堆的最大值移到小顶堆
        rightHeap.offer(leftHeap.poll());
        // 平衡：大顶堆可以比小顶堆多一个
        if (leftHeap.size() < rightHeap.size()) {
            leftHeap.offer(rightHeap.poll());
        }
    }

    public double findMedian() {
        if (leftHeap.size() > rightHeap.size()) {
            return leftHeap.peek();
        }
        return (leftHeap.peek() + rightHeap.peek()) / 2.0;
    }
}
```

**核心**：
- `leftHeap`（大顶堆）存较小的一半，堆顶是这半的最大值
- `rightHeap`（小顶堆）存较大的一半，堆顶是这半的最小值
- 两个堆大小差 ≤ 1
- 中位数 = 左堆顶 / (左堆顶 + 右堆顶) / 2

- **时间**：addNum O(log n)，findMedian O(1)

```java
class KthLargest {

    int k;
```

### 16.5 滑动窗口模板最终版（背下来）

```java
// ==================== 固定窗口 ====================
void fixedWindow(int[] nums, int k) {
    // 1. 初始化窗口
    int windowSum = 0;
    for (int i = 0; i < k; i++) windowSum += nums[i];
    // 2. 处理结果
    process(windowSum);
    // 3. 滑动
    for (int i = k; i < nums.length; i++) {
        windowSum += nums[i] - nums[i - k]; // 右进左出
        process(windowSum);
    }
}

// ==================== 可变窗口-求最长 ====================
int maxWindow(int[] nums, Predicate condition) {
    int left = 0, maxLen = 0;
    int state = 0;
    for (int right = 0; right < nums.length; right++) {
        state += nums[right];           // 扩展右边界
        while (!condition.test(state)) { // 窗口不合法
            state -= nums[left++];      // 收缩左边界
        }
        maxLen = Math.max(maxLen, right - left + 1);
    }
    return maxLen;
}

// ==================== 可变窗口-求最短 ====================
int minWindow(int[] nums, int target) {
    int left = 0, minLen = Integer.MAX_VALUE;
    int state = 0;
    for (int right = 0; right < nums.length; right++) {
        state += nums[right];           // 扩展右边界
        while (state >= target) {       // 窗口满足条件
            minLen = Math.min(minLen, right - left + 1);
            state -= nums[left++];      // 尝试收缩
        }
    }
    return minLen == Integer.MAX_VALUE ? 0 : minLen;
}
```

## 10 道面试高频题

### Q1：滑动窗口的时间复杂度为什么是 O(n)？

**答**：虽然外层 `for` 循环遍历 `right` 为 O(n)，内层 `while` 循环收缩 `left`，但 `left` 总共最多移动 n 次（从 0 到 n），不会回退。所以两个指针各遍历一次，总移动次数 ≤ 2n，时间复杂度 O(n)。

### Q2：无重复字符的最长子串，为什么用 HashMap 而不是 HashSet？

**答**：HashMap 可以记录字符**上次出现的位置**，直接将 `left` 跳到 `lastIndex + 1`，避免逐个收缩。如果用 HashSet，遇到重复时需要逐个移除 `left` 到重复字符之后，效率较低但结果相同。HashMap 是更优解，O(n) 而非 O(2n)。

### Q3：最小覆盖子串中 `valid` 变量的作用？

**答**：`valid` 记录窗口中**满足需求量的字符种类数**。例如 `t = "AAB"`，需求 `need = {A:2, B:1}`，共 2 个种类。当窗口中 A ≥ 2 且 B ≥ 1 时 `valid = 2 = need.size()`，表示全覆盖。用 `valid` 可以在 O(1) 时间内判断是否覆盖，而不需要每次遍历整个 `need`。

### Q4：滑动窗口最大值为什么用单调递减队列？

**答**：因为我们需要队首始终是当前窗口最大值。如果队列递减，新元素来时从队尾弹出所有比它小的（它们不可能是后续窗口的最大值），队首永远是最大的。当队首索引超出窗口范围时弹出。每个元素入队出队各一次，O(n)。

### Q5：三数之和为什么要排序？

**答**：排序后可以用对撞双指针，将找两数之和从 O(n²) 降为 O(n)，整体 O(n²)。另外排序后相同的数相邻，方便去重。如果不排序，需要嵌套循环 O(n³) 或用额外空间。

### Q6：接雨水的双指针解法为什么正确？

**答**：`leftMax` 和 `rightMax` 分别记录左右两侧的最大高度。当 `height[left] < height[right]` 时，`leftMax` 一定 ≤ `rightMax`（因为 `right` 这边更高），所以 `left` 位置的雨水量 = `leftMax - height[left]`，只取决于左侧最大值。同理处理右侧。

### Q7：N 皇后的时间复杂度？

**答**：O(n!)。第一行有 n 种选择，第二行最多 n-1 种（不能同列/对角线），以此类推。虽然不是严格 n!，但量级是 O(n!)。通过剪枝大幅减少实际搜索量。

### Q8：并查集的路径压缩和按秩合并的作用？

**答**：
- **路径压缩**：`find` 时将路径上所有节点直接指向根，将树高度压缩到接近 1，后续查询 O(1)。
- **按秩合并**：合并时将矮树挂到高树下，避免树退化成链表。
- 两者结合，`find` 和 `union` 的均摊时间复杂度为 O(α(n))，α 是反阿克曼函数，对任意 n < 10^80 都有 α < 5，实际 O(1)。

### Q9：数据流中位数为什么用两个堆？

**答**：大顶堆存较小一半，小顶堆存较大一半。两个堆顶就是"中间的两个数"。插入时交替维护平衡（大小差 ≤ 1），保证中位数始终在堆顶。`addNum` O(log n)，`findMedian` O(1)。比排序 O(n log n) 或有序链表 O(n) 更高效。

### Q10：寻找两个正序数组中位数为什么在较短数组上二分？

**答**：设短数组长度为 `m`，长数组为 `n`。在短数组上二分 O(log m) 次，每次判断 O(1)。如果 `m < n`，则 `log m < log n`，效率更高。另外可以保证 `j = (m+n+1)/2 - i ≥ 0`，不会越界。如果 `m > n`，`j` 可能为负数导致错误。
