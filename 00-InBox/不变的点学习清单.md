## 二、不变一：数据结构模型（5 种核心结构）

每种掌握标准：能脱稿回答「底层是什么」+「为什么这个场景用它不用另一个」

- [ ] 哈希表：散列函数 + 冲突解决（拉链法/开放寻址）+ 扩容 + 负载因子
  - 映射：HashMap / ConcurrentHashMap / Redis Hash / HashSet / 布隆过滤器
- [ ] 跳表：O(log n)，支持范围查询，天然适合并发
  - 映射：Redis ZSet / ConcurrentSkipListMap
- [ ] B+Tree：磁盘友好，范围查询高效
  - 映射：MySQL InnoDB 索引
  - 检验：关掉资料，白板上画插入过程并边讲
- [ ] LSM Tree：写入极快，读取稍慢，适合写多读少
  - 映射：RocksDB / LevelDB / HBase
- [ ] 布隆过滤器：可能误判，一定不漏判
  - 映射：Redis 缓存穿透防护

## 七、六块底层地基（按推进节奏）

### 第 1-3 周：数据结构 + 数据库（跟 Java 面试直接挂钩）

#### 数据结构与算法（30 年未变）

- [ ] 哈希表 trade-off：O(1) 查询，空间换时间
- [ ] 跳表 trade-off：O(log n)，实现简单，支持范围查询
- [ ] B+Tree trade-off：磁盘友好，范围查询高效
- [ ] LSM Tree trade-off：写入极快，读取稍慢
- [ ] 布隆过滤器 trade-off：可能误判，一定不漏判

#### 数据库原理（40 年未变）

- [ ] ACID + MVCC：隔离级别的实现原理
- [ ] B+Tree 索引：聚簇 vs 非聚簇，最左前缀
- [ ] WAL：先写日志再写数据，崩溃恢复
- [ ] 锁粒度：行锁/间隙锁/临键锁，不同隔离级别下锁的范围
- [ ] Buffer Pool：内存缓存数据页，LRU 淘汰
- [ ] 每条 SQL 写完强制跑 EXPLAIN（习惯）

---

### 第 4-6 周：操作系统 + 分布式（稍微抽象但权重极高）

#### 操作系统（50 年未变）

- [ ] 进程 vs 线程 vs 协程：隔离成本递减，调度粒度递减
- [ ] 虚拟内存：每个进程独立地址空间 → OOM / 堆外内存 / mmap
- [ ] IO 多路复用：一个线程管多个连接 → BIO → NIO → Netty
- [ ] 零拷贝：CPU 不参与数据搬运 → Kafka sendfile / NIO transferTo
- [ ] CPU 缓存行：伪共享 → Disruptor / @Contended

#### 分布式系统（30 年未变）

- [ ] CAP 理论：三者不可兼得，可取舍
- [ ] 共识算法（Paxos/Raft）：多节点如何就一个值达成一致
- [ ] 数据分片 + 复制：分片解决容量，复制解决可用性
- [ ] 分布式事务：2PC / TCC / Saga
- [ ] 限流 / 熔断 / 降级：保护系统的三个层次
- [ ] 每个分布式中间件能回答：CAP 选了哪两个？一致性保证到什么级别？挂了会发生什么？

---

### 第 7-8 周：网络 + 编译运行时（学完让前面四块提升一个层次）

#### 计算机网络（40 年未变）

- [ ] TCP 三次握手/四次挥手：为什么是三次不是两次
- [ ] TCP 拥塞控制：慢启动 / 拥塞避免 / 快重传
- [ ] HTTP 演进：HTTP/1.1 → HTTP/2 → HTTP/3（队头阻塞 → 多路复用 → QUIC）
- [ ] DNS：递归查询 + 缓存

#### 编译与运行时（20 年未变）

- [ ] 类加载机制：双亲委派，加载→链接→初始化
- [ ] 字节码：中间表示，可被改写 → AOP / Lombok / ASM / CGLIB
- [ ] JIT 编译：热点代码编译为本地代码
- [ ] GC 算法链：标记-清除 → 标记-整理 → 分代 → G1 → ZGC
