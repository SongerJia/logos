|知识点|笔记时重点写什么|
|---|---|
|**Interceptor 插件接口**|热 三个方法：`intercept()`（拦截逻辑）、`plugin()`（包装目标对象为代理，通常调 `Plugin.wrap(target, this)`）、`setProperties()`（读取插件配置属性）。`@Intercepts` + `@Signature` 注解声明拦截哪个对象的哪个方法|
|**四大可拦截对象及签名**|Executor（query / queryCursor / update / flushStatements）、StatementHandler（prepare / parameterize / batch / update / query）、ParameterHandler（setParameter）、ResultSetHandler（handleResultSets / handleOutputParameters）。**分页插件拦截的就是 Executor.query()**|
|**PageHelper 分页原理**|热 使用 ThreadLocal 存储分页参数（pageNum / pageSize）→ 拦截 Executor 的 query 方法 → 在原 SQL 前面拼 COUNT 查询总数 → 在原 SQL 后面加 LIMIT offset, size → 清除 ThreadLocal。**注意：PageHelper.startPage() 必须紧跟在 Mapper 查询方法之前**（同一个线程上下文）|
|**自定义插件实战思路**|典型场景：①SQL 执行耗时日志打印（拦截 StatementHandler.query() 记录时间）②SQL 权限过滤（自动追加 WHERE 条件限制数据范围）③加密解密（拦截 ParameterHandler 对敏感字段加解密）|

> **连接点提醒**：插件的代理模式和你 Spring Core 学过的 JDK 动态代理 / CGLIB 是同一套东西。MP 的分页插件也是基于这套拦截机制实现的。
