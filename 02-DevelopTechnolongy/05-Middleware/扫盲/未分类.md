## 学习策略总览

### 优先级排序

```
第一梯队（重点深挖）：
  S1 Canal (8点)    → 数据同步场景高频
  S3 Prometheus (9点) → 监控是必答题
  S4 ZooKeeper (7点) → 经典分布式考点
  
第二梯队（掌握核心用法）：
  S2 OSS/MinIO (6点) → 项目基本都会用到
  
第三梯队（建立概念即可）：
  S5 其他速览 (6点)  → 防止面试冷场
```

### ⚠️ 写笔记特别提醒

1. **这个模块的策略是"广度优先，点到为止"**。每个知识点不需要像 AT 模式那样画完整时序图，而是整理成**一张卡片**：一句话定义 + 一句话核心原理 + 一个应用场景 + 一道常见面试题
2. **S4.5（ZK vs Nacos vs Etcd vs Consul）** 这道对比题强烈建议做成表格！面试官最爱问"你为什么选 X 不选 Y"
3. **S3（Prometheus + Grafana）** 如果你的项目里确实没有用过，建议本地搭一套 demo：Spring Boot + Micrometer + Prometheus + Grafana，跑通一个完整的"埋点→采集→查询→展示→告警"流程。这比背 100 道题都有用

### 扫盲模块与其他方向的关联

```
S1 Canal ──→ MySQL(Binlog) ──→ Redis(缓存失效) ──→ MQ(增量投递) ──→ ES(索引)
S2 OSS   ──→ Nginx(静态服务) ──→ CDN(加速) ──→ 安全(签名/权限)
S3 监控  ──→ JVM(GC指标) ──→ Spring Boot(Actuator) ──→ SkyWalking(APM) ──→ ELK(日志)
S4 ZK    ──→ 分布式理论(CAP/ZAB) ──→ 注册中心(Nacos对比) ──→ 分布式锁(Redis对比)
S5 速览  ──→ 架构方向(RPC/安全/ServiceMesh/混沌工程) 的前置知识
```
