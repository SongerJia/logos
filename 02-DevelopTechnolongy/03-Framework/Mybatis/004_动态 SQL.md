|知识点|笔记时重点写什么|
|---|---|
|**if / choose-when-otherwise**|if 单条件判断（test 表达式用 OGNL）；choose 类似 switch-case（when + otherwise）。典型用法：多条件组合查询，用户可能传也可能不传某些参数|
|**where / set 标签**|where 自动处理第一个 AND/OR（去掉多余的）；set 自动处理最后一个逗号。这两个是日常开发最常用的，**能写出正确的 where 条件拼接就算过关了**|
|**foreach 循环**|热 五个属性：collection（集合/数组名）、item（当前元素变量）、index（索引/key）、open（前缀字符串）、close（后缀字符串）、separator（分隔符）。典型场景：IN 查询（`id IN (1,2,3)`）、批量插入（`VALUES (..), (..), (..)`）。**foreach + 批量 insert 是性能优化考点**|
|**sql 片段抽取 & include**|`<sql id="baseColumns">id, name, create_time</sql>` 定义可复用的 SQL 片段，`<include refid="baseColumns">` 引用。可以配合 `<if>` 在 include 时动态增减字段|
|**bind 绑定变量**|`<bind name="pattern" value="'%' + keyword + '%'" />` 创建一个本地变量用于 OGNL 表达式。用于模糊查询的 LIKE 拼接（避免手动拼接 % 导致的问题）|

> **笔记提示**：动态 SQL 这块不需要太深，重点是**能正确写出常见场景的 XML**。建议每种标签配一个实际业务示例（如商品多条件搜索、批量更新订单状态），比纯概念记忆有效得多。
