## 四、驼背纠正专项

> 驼背本质：**前侧太紧（胸、肩前束）+ 后侧太弱（中下斜方肌、菱形肌、深层颈屈肌）**  
> 解决思路：松解前侧 → 强化后侧 → 建立日常习惯

### 驼背根源自查

| 你现在的状态 | 对应问题 |
|-------------|----------|
| 圆肩（肩膀往前扣） | 胸大肌/胸小肌过紧 |
| 头前伸（下巴往前探） | 枕下肌群紧张、深层颈屈肌无力 |
| 上背拱起 | 胸椎灵活性差、中下斜方肌无力 |
| 长期电脑/手机使用 | 所有问题的加速器 |

### 每日必做：驼背纠正 5 动作（10分钟）

> 🔄 以下动作 **每天做，不分训练日/休息日**。可以穿插在工间休息时做。

| 动作 | 要点 | 组数 × 次数/时长 |
|------|------|-----------------|
| 1️⃣ **门框胸肌拉伸** | 双手扶门框两侧，肘与肩同高，身体前倾，感受胸肌牵拉 | 30秒 × 3组 |
| 2️⃣ **下巴后缩（收下颌）** | 背靠墙站，后脑勺贴墙，下巴水平后收（像做双下巴），保持后脑勺不离开墙 | 10次 × 3组 |
| 3️⃣ **YTWL 肩背激活** | 俯身45°，双臂依次做Y→T→W→L四个字母形状，每个位置停顿2秒 | 每个字母8次 × 2组 |
| 4️⃣ **墙壁天使** | 背/臀/后脑勺贴墙，双臂屈肘贴墙，像天使翅膀一样上下滑动，手背全程贴墙 | 10次 × 3组 |
| 5️⃣ **猫牛式胸椎活动** | 四足跪姿，吸气塌腰抬头（牛式），呼气拱背低头（猫式），重点是上背部的弧度 | 10次 × 2组 |

#### 动作细节补充

**YTWL（不需要器械，徒手即可）**
```
Y — 双臂伸直上举呈Y字，拇指朝天，肩胛骨向内夹紧
T — 双臂侧平举呈T字，拇指朝天，肩胛骨收紧
W — 屈肘下拉呈W字，肩胛骨用力夹
L — 屈肘90°外旋，像招财猫姿势
```

**墙壁天使：** 如果手背无法贴墙，说明你的肩胸灵活度很差，这正是要练的。从能做到的幅度开始，不要硬掰。目标是8周后全程贴墙。

### 融入现有训练：驼背动作嵌入方案

| 训练类型 | 加入时机 | 加入什么 |
|----------|----------|----------|
| 所有训练日 | **热身环节替代** | 猫牛式（10次 × 2组）→ 下巴后缩（10次 × 2组）作为热身 |
| 所有训练日 | **冷却收尾** | 门框胸肌拉伸（30秒 × 2组）+ 墙壁天使（10次 × 2组） |
| 力量日 B（上肢日） | **额外增加** | YTWL（每个字母8次 × 2组），放在俯卧撑之后 |
| 有氧日 | **跑步/跳绳后** | 门框胸肌拉伸 + 下巴后缩 |
| 休息日 | **任何时间** | 完整5动作过一遍（约10分钟） |

### 日常姿势习惯（比训练更重要）

| 场景 | 该怎么做 |
|------|----------|
| 💻 **电脑办公** | 屏幕顶部与视线平齐（垫高显示器/笔记本），椅子坐满，腰后放靠垫 |
| 📱 **看手机** | 手机举到眼睛高度，**绝不低头看** |
| 🚶 **走路** | 想象头顶有根线往上拉，胸口微微挺出，下巴微收 |
| 🛏️ **睡觉** | 枕头高度 = 一侧肩宽（侧睡时头颈与脊柱成直线）。不要趴睡 |
| 🚗 **开车/坐车** | 头枕调至后脑勺高度，后脑勺轻轻靠住 |

### 办公室微习惯（每小时做1次）

> 设个闹钟，每工作 45-60 分钟：

```
1. 站起来，做10次下巴后缩（10秒）
2. 双手背后交握，向后伸展打开胸腔（15秒）
3. 耸肩上提到最高→用力下沉到最低，重复5次（10秒）
```
