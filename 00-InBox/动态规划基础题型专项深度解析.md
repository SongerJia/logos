# 第一章：DP 核心思想

## 1. 什么是动态规划？与贪心/分治的区别

### 动态规划的本质

**动态规划 = 状态 + 状态转移方程 + 备忘录**

核心思想：**将大问题拆成小问题，先解决小问题，再把小问题的最优解组合成大问题的最优解**。关键在于小问题的解会被反复使用，所以需要存储下来避免重复计算。

### 与其他算法的区别

| 特征 | 贪心 | 分治 | 动态规划 |
|------|------|------|----------|
| **子问题独立性** | 无子问题 | 子问题独立 | 子问题重叠 |
| **最优子结构** | 不保证全局最优 | 各自最优组合 | 小问题最优→大问题最优 |
| **选择策略** | 每步选当前最优 | 递归求解后合并 | 每步考虑所有选择 |
| **能否回退** | 不能 | — | 能（通过备忘录） |
| **典型问题** | Huffman编码 | 归并排序 | 背包、LCS |
| **反例** | 背包问题贪心不对 | 子问题重叠时重复计算 | — |

```
贪心: 每一步选「看起来最好」的 → 不回头 → 可能全局不是最优
      例: 背包问题中按单位价值排序贪心，可能因为容量浪费而非最优

分治: 大问题拆成独立子问题 → 递归解决 → 合并
      例: 归并排序：左半排序、右半排序、合并
      关键: 子问题之间没有重叠，不需要备忘录

DP:   大问题拆成重叠子问题 → 先存小问题的解 → 用小问题解组合大问题解
      例: 爬楼梯 f(n) = f(n-1) + f(n-2)
      f(n-1) 和 f(n-2) 都会被多次用到 → 存到数组避免重复计算
```

### 什么时候用 DP？

**两个必要条件**：
1. **最优子结构**：大问题的最优解包含小问题的最优解
2. **重叠子问题**：小问题会被反复计算

**常见信号**：
- 求「最大/最小/最长/最短/最优」
- 求「方案数/组合数」
- 题目能拆成更小规模的同类问题
- 决策有后效性（不能贪心）

## 2. DP 解题四步法

### 第一步：定义状态（最关键）

**状态 = 描述子问题的变量集合**

状态定义的好坏直接决定解题难度。好的状态定义让转移方程简单自然。

常见状态定义模式：
```
dp[i]        → 以位置 i 结尾的... 的最优值
dp[i][j]     → 在区间 [i,j] 内的... 的最优值
dp[i][j]     → 从位置 i 到位置 j 的... 的方案数
dp[i][k]     → 第 i 步，状态为 k 时的最优值
```

### 第二步：推导状态转移方程

**转移方程 = 当前状态如何从之前的状态推导而来**

问自己：**要得到 dp[当前]，需要哪些更小的子问题？它们之间是什么关系？**

```
爬楼梯: dp[n] = dp[n-1] + dp[n-2]
             ↑ 到达n阶，要么从n-1阶跨1步，要么从n-2阶跨2步

打家劫舍: dp[i] = max(dp[i-1], dp[i-2] + nums[i])
              ↑ 第i家：不偷（dp[i-1]）vs 偷（dp[i-2]+nums[i]）

0-1背包: dp[i][w] = max(dp[i-1][w], dp[i-1][w-weight[i]] + value[i])
             ↑ 第i个物品：不放（dp[i-1][w]）vs 放（dp[i-1][w-wi]+vi）
```

### 第三步：确定初始条件和边界

**初始条件 = 最小的子问题的解（不需要转移方程就能直接得出）**

```
爬楼梯: dp[0]=1, dp[1]=1
打家劫舍: dp[0]=nums[0], dp[1]=max(nums[0], nums[1])
0-1背包: dp[0][w]=0（不选任何物品价值为0）
```

### 第四步：确定计算顺序

**计算顺序 = 保证计算 dp[当前] 时，dp[之前] 已经算好了**

- 一维 DP：从小到大 `for i = 1 → n`
- 二维 DP：从左到右、从上到下
- 区间 DP：从小区间到大区间 `for len = 1 → n; for i = 0 → n-len`

# 第二章：一维 DP（线性 DP）

## 4. 爬楼梯（Fibonacci 变种）

### 题目

每次可以爬 1 或 2 个台阶，爬到 n 阶有多少种不同的方法？

```
n=2: 2种（1+1, 2）
n=3: 3种（1+1+1, 1+2, 2+1）
```

### 状态定义与转移方程

**dp[i] = 爬到第 i 阶的方法数**

到达第 i 遍，要么从第 i-1 遍跨 1 步上来，要么从第 i-2 遍跨 2 步上来：

```
dp[i] = dp[i-1] + dp[i-2]

初始条件:
dp[0] = 1  (站在地面，1种方法——不动)
dp[1] = 1  (只有跨1步这一种方法)
```

### 代码实现

```java
// 方法一：标准 DP 数组
public int climbStairs(int n) {
    if (n <= 1) return 1;

    int[] dp = new int[n + 1];
    dp[0] = 1;
    dp[1] = 1;

    for (int i = 2; i <= n; i++) {
        dp[i] = dp[i - 1] + dp[i - 2];
    }

    return dp[n];
}

// 方法二：空间优化（只存前两个值）
public int climbStairsOptimized(int n) {
    if (n <= 1) return 1;

    int prev2 = 1;  // dp[0]
    int prev1 = 1;  // dp[1]

    for (int i = 2; i <= n; i++) {
        int curr = prev1 + prev2;
        prev2 = prev1;
        prev1 = curr;
    }

    return prev1;
}
```

### 复杂度

| 方法 | 时间 | 空间 |
|------|------|------|
| DP数组 | O(n) | O(n) |
| 空间优化 | O(n) | O(1) |

### 面试追问

**Q：如果每次可以爬 1、2 或 3 个台阶呢？**

转移方程变成 `dp[i] = dp[i-1] + dp[i-2] + dp[i-3]`，初始条件 `dp[0]=1, dp[1]=1, dp[2]=2`。一般化：如果可以爬 k 种步数，dp[i] = Σdp[i-step]。

**Q：如果有些台阶是坏的（不能踩）呢？**

加一个布尔数组 `broken[]`，转移时判断：
```java
dp[i] = 0;  // 坏台阶，方法数为0
if (!broken[i]) {
    dp[i] = (i>=1 && !broken[i-1] ? dp[i-1] : 0)
          + (i>=2 && !broken[i-2] ? dp[i-2] : 0);
}
```

**Q：为什么 dp[0] = 1 而不是 0？**

dp[0] 表示"站在地面的方法数"。站在原地也是一种"方法"（起点）。如果 dp[0]=0，那 dp[2] = dp[1]+dp[0] = 1+0 = 1，但实际上 n=2 有 2 种方法（1+1 和 2），会出错。

## 5. 打家劫舍系列

### 5.1 打家劫舍 I — 相邻不能偷

### 题目

数组表示每家的金额，相邻的家不能同时偷，求最大金额。

```
nums = [2, 7, 9, 3, 1]
偷2、9、1 → 2+9+1=12 ✓（不相邻）
偷7、3 → 7+3=10 ✗（不如12）
```

### 状态定义与转移方程

**dp[i] = 考虑前 i 家，能偷到的最大金额**

对于第 i 家（下标 i-1）：
- **不偷**：dp[i] = dp[i-1]（和前 i-1 家一样）
- **偷**：dp[i] = dp[i-2] + nums[i-1]（偷第i家，加上前i-2家的最优）

```
dp[i] = max(dp[i-1], dp[i-2] + nums[i-1])

初始条件:
dp[0] = 0           （没有家，金额0）
dp[1] = nums[0]     （只有1家，必须偷）
```

### 代码实现

```java
public int rob(int[] nums) {
    if (nums == null || nums.length == 0) return 0;
    if (nums.length == 1) return nums[0];

    int prev2 = 0;           // dp[i-2]
    int prev1 = nums[0];     // dp[i-1]

    for (int i = 2; i <= nums.length; i++) {
        int curr = Math.max(prev1, prev2 + nums[i - 1]);
        prev2 = prev1;
        prev1 = curr;
    }

    return prev1;
}
```

### 复杂度

- 时间：O(n)
- 空间：O(1)

### 5.2 打家劫舍 II — 环形排列

### 题目

房屋环形排列（第一家和最后一家相邻），仍然不能偷相邻的。

### 思路分析

环形意味着第一家和最后一家不能同时偷。拆成两个子问题：
1. **不偷第一家**：考虑 nums[1..n-1]
2. **不偷最后一家**：考虑 nums[0..n-2]

取两者最大值。

```
环形: [2, 3, 2]
拆成: [3, 2] → max=3     [2, 3] → max=3
结果: max(3, 3) = 3

完整环形偷2和2不行（第一和最后相邻），只能偷3
```

### 代码实现

```java
public int rob2(int[] nums) {
    if (nums.length == 1) return nums[0];

    // 情况1：不偷第一家，范围 [1, n-1]
    int case1 = robRange(nums, 1, nums.length - 1);
    // 情况2：不偷最后一家，范围 [0, n-2]
    int case2 = robRange(nums, 0, nums.length - 2);

    return Math.max(case1, case2);
}

private int robRange(int[] nums, int start, int end) {
    if (start == end) return nums[start];

    int prev2 = 0;
    int prev1 = nums[start];

    for (int i = start + 1; i <= end; i++) {
        int curr = Math.max(prev1, prev2 + nums[i]);
        prev2 = prev1;
        prev1 = curr;
    }

    return prev1;
}
```

### 5.3 打家劫舍 III — 树形 DP

### 题目

房屋排成二叉树，相邻（父子）不能同时偷。

### 思路分析

**树形 DP**：后序遍历，每个节点返回两个值：
- `rob`：偷当前节点时的最大金额
- `notRob`：不偷当前节点时的最大金额

```
偷当前: rob = node.val + left.notRob + right.notRob
不偷当前: notRob = max(left.rob, left.notRob) + max(right.rob, right.notRob)
          ↑ 不偷当前，子节点可偷可不偷，取各自最大
```

### 代码实现

```java
public int rob3(TreeNode root) {
    int[] result = dfs(root);
    return Math.max(result[0], result[1]);
}

// 返回 [偷当前节点最大值, 不偷当前节点最大值]
private int[] dfs(TreeNode node) {
    if (node == null) return new int[]{0, 0};

    int[] left = dfs(node.left);
    int[] right = dfs(node.right);

    // 偷当前节点：子节点不能偷
    int rob = node.val + left[1] + right[1];
    // 不偷当前节点：子节点可偷可不偷，取较大值
    int notRob = Math.max(left[0], left[1]) + Math.max(right[0], right[1]);

    return new int[]{rob, notRob};
}
```

### 面试追问

**Q：为什么树形DP要用后序遍历？**

因为当前节点的状态依赖于子节点的状态。必须先计算子节点（左、右），才能计算当前节点。后序遍历天然保证「左右根」顺序。

**Q：打家劫舍系列的核心区别？**

| 变体 | 数据结构 | 特殊约束 | 解法 |
|------|----------|----------|------|
| I | 数组（线性） | 相邻不偷 | 一维DP |
| II | 数组（环形） | 首尾也相邻 | 拆成两个线性DP |
| III | 二叉树 | 父子不偷 | 树形DP（后序） |

## 6. 最大子数组和（Kadane 算法）

### 题目

找到数组中连续子数组的最大和。

```
nums = [-2, 1, -3, 4, -1, 2, 1, -5, 4]
最大子数组: [4, -1, 2, 1] = 6
```

### 状态定义与转移方程

**dp[i] = 以 nums[i] 结尾的最大子数组和**

对于位置 i：
- **延续前面的子数组**：dp[i] = dp[i-1] + nums[i]（前面贡献正，延续）
- **从 i 重新开始**：dp[i] = nums[i]（前面贡献负，不如重新开始）

```
dp[i] = max(dp[i-1] + nums[i], nums[i])
     = nums[i] + max(dp[i-1], 0)  ← 如果dp[i-1]是负数，不如不加

最终答案: max(dp[0], dp[1], ..., dp[n-1])
```

### 代码实现

```java
public int maxSubArray(int[] nums) {
    int maxSum = nums[0];
    int currSum = nums[0];  // dp[i]，即以当前元素结尾的最大和

    for (int i = 1; i < nums.length; i++) {
        // dp[i] = max(dp[i-1] + nums[i], nums[i])
        currSum = Math.max(currSum + nums[i], nums[i]);
        maxSum = Math.max(maxSum, currSum);
    }

    return maxSum;
}
```

### 复杂度

- 时间：O(n)
- 空间：O(1)

### 面试追问

**Q：如果要求返回最大子数组的起止位置？**

```java
public int[] maxSubArrayWithIndex(int[] nums) {
    int maxSum = nums[0], currSum = nums[0];
    int start = 0, end = 0, tempStart = 0;

    for (int i = 1; i < nums.length; i++) {
        if (currSum + nums[i] < nums[i]) {
            // 从 i 重新开始
            currSum = nums[i];
            tempStart = i;
        } else {
            currSum += nums[i];
        }

        if (currSum > maxSum) {
            maxSum = currSum;
            start = tempStart;
            end = i;
        }
    }

    return new int[]{maxSum, start, end};
}
```

**Q：如果是环形数组呢？**

两种情况：
1. 最大子数组不跨越首尾 → 正常 Kadane
2. 最大子数组跨越首尾 → 总和 - 最小子数组（中间那段去掉）

注意全负数的特殊情况：最大子数组 = 最大元素（不能是总和-最小子数组=0）。

```java
public int maxSubarraySumCircular(int[] nums) {
    int totalSum = 0;
    int maxNormal = nums[0], currMax = 0;
    int minNormal = nums[0], currMin = 0;

    for (int num : nums) {
        totalSum += num;
        // Kadane 求最大
        currMax = Math.max(currMax + num, num);
        maxNormal = Math.max(maxNormal, currMax);
        // 反向 Kadane 求最小
        currMin = Math.min(currMin + num, num);
        minNormal = Math.min(minNormal, currMin);
    }

    // 全负数：maxNormal 就是答案
    if (maxNormal < 0) return maxNormal;

    // 正常情况：max(不跨越, 跨越)
    return Math.max(maxNormal, totalSum - minNormal);
}
```

## 7. 零钱兑换

### 7.1 零钱兑换 — 最少硬币数

### 题目

给定硬币面值 coins 和金额 amount，凑出 amount 所需的最少硬币数。

```
coins = [1, 2, 5], amount = 11
5+5+1 = 3枚 → 答案3
```

### 状态定义与转移方程

**dp[i] = 凑出金额 i 所需的最少硬币数**

对于金额 i，尝试每种硬币：
- 使用硬币 c：dp[i] = dp[i-c] + 1

```
dp[i] = min(dp[i - coins[j]] + 1)  对所有 coins[j] <= i

初始条件:
dp[0] = 0  （金额0需要0枚硬币）
dp[i] = Integer.MAX_VALUE  （初始设为不可能）
```

### 代码实现

```java
public int coinChange(int[] coins, int amount) {
    int[] dp = new int[amount + 1];
    Arrays.fill(dp, amount + 1);  // 初始化为不可能的大值
    dp[0] = 0;

    for (int i = 1; i <= amount; i++) {
        for (int coin : coins) {
            if (coin <= i) {
                dp[i] = Math.min(dp[i], dp[i - coin] + 1);
            }
        }
    }

    return dp[amount] > amount ? -1 : dp[amount];
}
```

### 复杂度

- 时间：O(amount × n)，n 是硬币种类数
- 空间：O(amount)

### 7.2 零钱兑换 II — 方案数

### 题目

凑出 amount 的组合数（不同顺序算同一组合）。

```
coins = [1, 2, 5], amount = 5
组合: 5=5, 5=2+2+1, 5=2+1+1+1, 5=1+1+1+1+1 → 4种
```

### 思路分析

**关键**：外层循环遍历硬币，内层遍历金额。

如果外层遍历金额、内层遍历硬币 → 不同顺序会算成不同组合（排列数）。
外层遍历硬币 → 保证每种硬币只被"有序"使用一次 → 组合数。

```
coins=[1,2], amount=4
外层硬币1: dp[1]=1, dp[2]=1, dp[3]=1, dp[4]=1  (只用1)
外层硬币2: dp[2]+=dp[0]=1→2, dp[4]+=dp[2]=2→3  (加入2)
组合数: dp[4]=3 ({1,1,1,1}, {1,1,2}, {2,2})
```

### 代码实现

```java
public int change(int amount, int[] coins) {
    int[] dp = new int[amount + 1];
    dp[0] = 1;  // 金额0有1种组合（不选任何硬币）

    // 外层遍历硬币（保证组合数而非排列数）
    for (int coin : coins) {
        for (int i = coin; i <= amount; i++) {
            dp[i] += dp[i - coin];
        }
    }

    return dp[amount];
}
```

### 面试追问

**Q：最少硬币数 vs 组合数，循环顺序为什么不同？**

最少硬币数：求最优值，不管顺序，内外层顺序不影响结果（因为 `min` 操作不区分排列/组合）。

组合数：求方案数，必须外层遍历硬币，内层遍历金额。否则 `1+2` 和 `2+1` 会算成两种不同的方案，变成排列数。

```
对比:
外层金额 + 内层硬币 → 排列数 dp[3]=3 (1+1+1, 1+2, 2+1)
外层硬币 + 内层金额 → 组合数 dp[3]=2 (1+1+1, 1+2)
```

**Q：零钱兑换本质是什么背包？**

- 最少硬币数 → **完全背包求最小值**（每种硬币可用无限次）
- 组合数 → **完全背包求方案数**（每种硬币可用无限次）

# 第三章：背包问题

## 8. 0-1 背包

### 题目

n 个物品，每个有重量 w[i] 和价值 v[i]，背包容量 W。每个物品只能选或不选（0或1），求最大价值。

```
物品: [(w=1,v=1), (w=2,v=6), (w=3,v=10)]
容量W=5
最优: 选物品2(w=2,v=6) + 物品3(w=3,v=10) = 16
```

### 状态定义与转移方程

**dp[i][w] = 考虑前 i 个物品，容量为 w 时的最大价值**

```
对于第i个物品:
不选: dp[i][w] = dp[i-1][w]                   （和前i-1个一样）
选择: dp[i][w] = dp[i-1][w-w[i]] + v[i]       （选了第i个，容量减少w[i]）

dp[i][w] = max(dp[i-1][w], dp[i-1][w-w[i]] + v[i])   (当 w >= w[i])
dp[i][w] = dp[i-1][w]                                  (当 w < w[i]，选不了)

初始条件:
dp[0][w] = 0  （不选任何物品，价值为0）
```

### 代码实现

```java
// 二维 DP
public int knapsack01(int[] weights, int[] values, int W) {
    int n = weights.length;
    int[][] dp = new int[n + 1][W + 1];

    for (int i = 1; i <= n; i++) {
        for (int w = 0; w <= W; w++) {
            // 不选第i个物品
            dp[i][w] = dp[i - 1][w];
            // 选第i个物品（容量够才行）
            if (w >= weights[i - 1]) {
                dp[i][w] = Math.max(dp[i][w],
                    dp[i - 1][w - weights[i - 1]] + values[i - 1]);
            }
        }
    }

    return dp[n][W];
}

// 一维 DP 空间优化（逆序遍历！）
public int knapsack01Optimized(int[] weights, int[] values, int W) {
    int[] dp = new int[W + 1];

    for (int i = 0; i < weights.length; i++) {
        // 关键：逆序遍历容量，保证 dp[w-weights[i]] 是上一轮的值
        for (int w = W; w >= weights[i]; w--) {
            dp[w] = Math.max(dp[w], dp[w - weights[i]] + values[i]);
        }
    }

    return dp[W];
}
```

### 为什么逆序遍历？

**0-1 背包一维优化必须逆序**，因为每个物品只能选一次。

```
正序遍历的问题:
物品(w=2,v=6), W=4
w=2: dp[2] = max(dp[2], dp[0]+6) = 6   ← 选了
w=4: dp[4] = max(dp[4], dp[2]+6) = 12  ← dp[2]已经是更新后的！
                                           相当于物品2被选了两次！

逆序遍历:
w=4: dp[4] = max(dp[4], dp[2]+6) = 6   ← dp[2]是上一轮的值
w=2: dp[2] = max(dp[2], dp[0]+6) = 6   ← 物品2只选了一次 ✓
```

### 复杂度

| 方法 | 时间 | 空间 |
|------|------|------|
| 二维DP | O(nW) | O(nW) |
| 一维优化 | O(nW) | O(W) |

### 面试追问

**Q：如果要求恰好装满背包呢？**

初始化不同：
- 不要求恰好装满：`dp[0] = 0, dp[w] = 0`（容量没用完也行）
- 恰好装满：`dp[0] = 0, dp[w] = -∞`（容量没用完不合法）

最后 `dp[W]` 如果是 `-∞` 说明无法恰好装满。

**Q：0-1背包的应用场景？**

所有「每个物品只能选一次」的问题都可以转化：
- 分割等和子集：能否分成两个和相同的子集 → 背包容量=sum/2，物品=数组元素，价值=重量
- 目标和：给数组加+/-使结果等于target → 正数组和=负数组和+target → 背包

## 9. 完全背包

### 题目

与 0-1 背包相同，但每个物品可以选**无限次**。

### 状态定义与转移方程

与 0-1 背包相同，但转移方程不同：

```
0-1背包: dp[i][w] = max(dp[i-1][w], dp[i-1][w-w[i]] + v[i])
         ↑ 不选i     ↑ 选i，但参考的是i-1（i只能选一次）

完全背包: dp[i][w] = max(dp[i-1][w], dp[i][w-w[i]] + v[i])
          ↑ 不选i      ↑ 选i，参考的是i（i可以再选）
```

**关键区别**：选第 i 个物品时，`dp[i-1]` → `dp[i]`，因为选完 i 后还可以再选 i。

### 代码实现

```java
// 二维 DP
public int knapsackComplete(int[] weights, int[] values, int W) {
    int n = weights.length;
    int[][] dp = new int[n + 1][W + 1];

    for (int i = 1; i <= n; i++) {
        for (int w = 0; w <= W; w++) {
            dp[i][w] = dp[i - 1][w];  // 不选
            if (w >= weights[i - 1]) {
                dp[i][w] = Math.max(dp[i][w],
                    dp[i][w - weights[i - 1]] + values[i - 1]);  // 注意dp[i]不是dp[i-1]
            }
        }
    }

    return dp[n][W];
}

// 一维 DP 空间优化（正序遍历！）
public int knapsackCompleteOptimized(int[] weights, int[] values, int W) {
    int[] dp = new int[W + 1];

    for (int i = 0; i < weights.length; i++) {
        // 关键：正序遍历容量，因为物品可以选多次
        for (int w = weights[i]; w <= W; w++) {
            dp[w] = Math.max(dp[w], dp[w - weights[i]] + values[i]);
        }
    }

    return dp[W];
}
```

### 为什么正序遍历？

**完全背包一维优化必须正序**，因为物品可以选多次。

```
物品(w=2,v=6), W=4
正序遍历:
w=2: dp[2] = max(dp[2], dp[0]+6) = 6   ← 选了一次
w=4: dp[4] = max(dp[4], dp[2]+6) = 12  ← dp[2]已更新，选了两次 ✓
```

### 0-1 背包 vs 完全背包 核心区别

| 特征 | 0-1 背包 | 完全背包 |
|------|----------|----------|
| 物品数量 | 每种最多1个 | 每种无限 |
| 二维转移 | `dp[i-1][w-wi]+vi` | `dp[i][w-wi]+vi` |
| 一维遍历顺序 | **逆序** | **正序** |
| 原因 | 防止同一物品被重复选 | 允许同一物品被多次选 |

## 10. 背包九种变体速查

| 变体 | 问题 | 循环顺序 | 初始化 | 典型题 |
|------|------|----------|--------|--------|
| **0-1背包 求最大值** | 每种选或不选 | 外物品内容量(逆序) | dp[0]=0,其余0 | 分割等和子集 |
| **0-1背包 求方案数** | 组合数 | 外物品内容量(逆序) | dp[0]=1,其余0 | 目标和 |
| **0-1背包 求最小值** | 最少物品数 | 外物品内容量(逆序) | dp[0]=0,其余∞ | — |
| **完全背包 求最大值** | 每种可选无限 | 外物品内容量(正序) | dp[0]=0,其余0 | — |
| **完全背包 求方案数** | 组合数 | 外物品内容量(正序) | dp[0]=1,其余0 | 零钱兑换II |
| **完全背包 求最小值** | 最少物品数 | 外物品内容量(正序) | dp[0]=0,其余∞ | 零钱兑换 |
| **多重背包** | 每种选s[i]次 | 二进制拆分→0-1 | 同0-1 | — |
| **分组背包** | 每组选一个 | 外组内物品+容量逆序 | 同0-1 | — |
| **二维费用背包** | 两种容量限制 | 三维→二维逆序 | dp[0][0]=0 | — |

### 多重背包二进制拆分

每种物品可选 s[i] 次。把 s[i] 拆成 1+2+4+...+剩余，变成若干个 0-1 背包物品。

```
物品有13个 → 拆成1,2,4,6(13-1-2-4=6)
→ 4个0-1背包物品: (w,v,1), (2w,2v,1), (4w,4v,1), (6w,6v,1)

原理: 1+2+4+6=13，任何1~13的数量都能由这些组合出来
例: 选5个 = 1+4, 选7个 = 1+2+4, 选10个 = 4+6
```

# 第四章：二维 DP（网格 / 路径）

## 11. 不同路径

### 题目

从 m×n 网格左上角走到右下角，只能向右或向下，有多少条路径？

```
m=3, n=7 → 28条路径
```

### 状态定义与转移方程

**dp[i][j] = 从 (0,0) 到 (i,j) 的路径数**

到达 (i,j) 只能从 (i-1,j) 向下走或从 (i,j-1) 向右走：

```
dp[i][j] = dp[i-1][j] + dp[i][j-1]

初始条件:
dp[0][j] = 1  （第一行只有向右一条路）
dp[i][0] = 1  （第一列只有向下一条路）
```

### 代码实现

```java
// 二维 DP
public int uniquePaths(int m, int n) {
    int[][] dp = new int[m][n];

    // 第一行和第一列初始化为1
    for (int i = 0; i < m; i++) dp[i][0] = 1;
    for (int j = 0; j < n; j++) dp[0][j] = 1;

    for (int i = 1; i < m; i++) {
        for (int j = 1; j < n; j++) {
            dp[i][j] = dp[i - 1][j] + dp[i][j - 1];
        }
    }

    return dp[m - 1][n - 1];
}

// 一维优化（只保留一行）
public int uniquePathsOptimized(int m, int n) {
    int[] dp = new int[n];
    Arrays.fill(dp, 1);  // 第一行全是1

    for (int i = 1; i < m; i++) {
        for (int j = 1; j < n; j++) {
            dp[j] = dp[j] + dp[j - 1];
            // dp[j] = 上一行的dp[j]（从上方来） + 当前行的dp[j-1]（从左方来）
        }
    }

    return dp[n - 1];
}

// 数学公式: C(m+n-2, m-1)
public int uniquePathsMath(int m, int n) {
    long result = 1;
    for (int i = 1; i <= Math.min(m - 1, n - 1); i++) {
        result = result * (m + n - 1 - i) / i;
    }
    return (int) result;
}
```

### 复杂度

| 方法 | 时间 | 空间 |
|------|------|------|
| 二维DP | O(mn) | O(mn) |
| 一维优化 | O(mn) | O(n) |
| 数学公式 | O(min(m,n)) | O(1) |

### 面试追问

**Q：如果有些格子有障碍物呢？**

障碍物格子的路径数设为 0（不可达）。

```java
public int uniquePathsWithObstacles(int[][] obstacleGrid) {
    int m = obstacleGrid.length, n = obstacleGrid[0].length;
    int[] dp = new int[n];
    dp[0] = obstacleGrid[0][0] == 0 ? 1 : 0;

    for (int i = 0; i < m; i++) {
        for (int j = 0; j < n; j++) {
            if (obstacleGrid[i][j] == 1) {
                dp[j] = 0;  // 有障碍，不可达
            } else if (j > 0) {
                dp[j] += dp[j - 1];
            }
        }
    }

    return dp[n - 1];
}
```

## 12. 最小路径和

### 题目

网格每个格子有数值，从左上到右下，只能向右或向下，求路径上数值的最小和。

```
grid = [[1,3,1],
        [1,5,1],
        [4,2,1]]
最小路径: 1→3→1→1→1 = 7
```

### 状态定义与转移方程

**dp[i][j] = 从 (0,0) 到 (i,j) 的最小路径和**

```
dp[i][j] = grid[i][j] + min(dp[i-1][j], dp[i][j-1])

初始条件:
dp[0][0] = grid[0][0]
dp[0][j] = dp[0][j-1] + grid[0][j]   （第一行只能从左来）
dp[i][0] = dp[i-1][0] + grid[i][0]   （第一列只能从上来）
```

### 代码实现

```java
// 二维 DP
public int minPathSum(int[][] grid) {
    int m = grid.length, n = grid[0].length;
    int[][] dp = new int[m][n];

    dp[0][0] = grid[0][0];
    for (int j = 1; j < n; j++) dp[0][j] = dp[0][j - 1] + grid[0][j];
    for (int i = 1; i < m; i++) dp[i][0] = dp[i - 1][0] + grid[i][0];

    for (int i = 1; i < m; i++) {
        for (int j = 1; j < n; j++) {
            dp[i][j] = grid[i][j] + Math.min(dp[i - 1][j], dp[i][j - 1]);
        }
    }

    return dp[m - 1][n - 1];
}

// 一维优化
public int minPathSumOptimized(int[][] grid) {
    int m = grid.length, n = grid[0].length;
    int[] dp = new int[n];

    dp[0] = grid[0][0];
    for (int j = 1; j < n; j++) dp[j] = dp[j - 1] + grid[0][j];

    for (int i = 1; i < m; i++) {
        dp[0] += grid[i][0];  // 第一列
        for (int j = 1; j < n; j++) {
            dp[j] = grid[i][j] + Math.min(dp[j], dp[j - 1]);
        }
    }

    return dp[n - 1];
}
```

### 复杂度

- 时间：O(mn)
- 空间：O(n) 一维优化

### 面试追问

**Q：不同路径 vs 最小路径和的区别？**

不同路径求**方案数**（加法），最小路径和求**最优值**（min+加法）。转移方程结构相似，但一个是求路径数量，一个是求路径权值。

# 第五章：序列 DP

## 13. 最长递增子序列（LIS）

### 题目

找到数组中最长严格递增子序列的长度（子序列不需要连续）。

```
nums = [10, 9, 2, 5, 3, 7, 101, 18]
LIS: [2, 3, 7, 101] → 长度4
```

### 方法一：DP O(n²)

**dp[i] = 以 nums[i] 结尾的 LIS 长度**

```
dp[i] = max(dp[j] + 1)  对所有 j < i 且 nums[j] < nums[i]
dp[i] = 1              如果没有 j < i 使得 nums[j] < nums[i]

初始条件:
dp[i] = 1  （每个元素自身构成长度1的子序列）
```

### 方法二：贪心+二分 O(n log n)

维护一个数组 `tails`：`tails[k]` = 长度为 k+1 的递增子序列的最小末尾元素。

遇到新元素 x：
- 如果 x > tails 的最后一个元素 → 直接追加（LIS长度+1）
- 否则 → 用二分找到 tails 中第一个 ≥ x 的位置，替换为 x（保持末尾最小）

```
nums = [10, 9, 2, 5, 3, 7, 101, 18]

tails变化:
10 → [10]
9  → [9]      (9替换10，长度1的子序列末尾更小)
2  → [2]      (2替换9)
5  → [2, 5]   (5 > 2,追加，LIS长度+1)
3  → [2, 3]   (3替换5，长度2的子序列末尾更小)
7  → [2, 3, 7] (7 > 3,追加)
101→ [2, 3, 7, 101]
18 → [2, 3, 7, 18]  (18替换101)

LIS长度 = tails长度 = 4
```

### 代码实现

```java
// 方法一：DP O(n²)
public int lengthOfLIS_DP(int[] nums) {
    int n = nums.length;
    int[] dp = new int[n];
    Arrays.fill(dp, 1);
    int maxLen = 1;

    for (int i = 1; i < n; i++) {
        for (int j = 0; j < i; j++) {
            if (nums[j] < nums[i]) {
                dp[i] = Math.max(dp[i], dp[j] + 1);
            }
        }
        maxLen = Math.max(maxLen, dp[i]);
    }

    return maxLen;
}

// 方法二：贪心+二分 O(n log n)
public int lengthOfLIS(int[] nums) {
    int[] tails = new int[nums.length];
    int len = 0;  // tails的有效长度

    for (int num : nums) {
        // 二分查找第一个 ≥ num 的位置
        int left = 0, right = len;
        while (left < right) {
            int mid = left + (right - left) / 2;
            if (tails[mid] < num) {
                left = mid + 1;
            } else {
                right = mid;
            }
        }
        tails[left] = num;
        if (left == len) len++;  // num比所有都大，LIS长度+1
    }

    return len;
}
```

### 复杂度

| 方法 | 时间 | 空间 |
|------|------|------|
| DP | O(n²) | O(n) |
| 贪心+二分 | O(n log n) | O(n) |

### 面试追问

**Q：贪心+二分法为什么 tails 的长度就是 LIS 的长度？**

tails[k] 存的是所有长度为 k+1 的递增子序列中末尾元素最小的那个。保持末尾最小可以让后续更多元素接上来。每当一个元素大于所有 tails 值时，说明它可以接在最长的子序列后面，LIS 长度增加 1。

注意：tails 数组本身不一定是有效的 LIS，但它保证了"长度 k 的递增子序列一定存在"。

**Q：如果要求 LIS 的具体序列？**

DP 方法更容易还原路径：记录每个 dp[i] 是从哪个 j 转移来的，最后从最大 dp 值的位置回溯。

## 14. 最长公共子序列（LCS）

### 题目

找到两个字符串的最长公共子序列的长度。

```
text1 = "abcde", text2 = "ace"
LCS: "ace" → 长度3
```

### 状态定义与转移方程

**dp[i][j] = text1 前 i 个字符和 text2 前 j 个字符的 LCS 长度**

```
如果 text1[i-1] == text2[j-1]:
    dp[i][j] = dp[i-1][j-1] + 1    ← 匹配，LCS长度+1

如果 text1[i-1] != text2[j-1]:
    dp[i][j] = max(dp[i-1][j], dp[i][j-1])  ← 不匹配，取删掉一个字符的较大值

初始条件:
dp[0][j] = 0  （text1为空，LCS=0）
dp[i][0] = 0  （text2为空，LCS=0）
```

```
填表过程（text1="abcde", text2="ace"）:

      ""  a  c  e
  ""   0  0  0  0
  a    0  1  1  1    ← 'a'匹配，dp[1][1]=dp[0][0]+1=1
  b    0  1  1  1    ← 'b'≠'a', max(dp[0][1],dp[1][0])=1
  c    0  1  2  2    ← 'c'匹配, dp[3][2]=dp[2][1]+1=2
  d    0  1  2  2    ← 'd'≠'c', max(dp[2][2],dp[3][1])=2
  e    0  1  2  3    ← 'e'匹配, dp[5][3]=dp[4][2]+1=3

答案: dp[5][3] = 3 ✓
```

### 代码实现

```java
public int longestCommonSubsequence(String text1, String text2) {
    int m = text1.length(), n = text2.length();
    int[][] dp = new int[m + 1][n + 1];

    for (int i = 1; i <= m; i++) {
        for (int j = 1; j <= n; j++) {
            if (text1.charAt(i - 1) == text2.charAt(j - 1)) {
                dp[i][j] = dp[i - 1][j - 1] + 1;
            } else {
                dp[i][j] = Math.max(dp[i - 1][j], dp[i][j - 1]);
            }
        }
    }

    return dp[m][n];
}

// 空间优化：只保留两行
public int longestCommonSubsequenceOptimized(String text1, String text2) {
    int m = text1.length(), n = text2.length();
    int[] prev = new int[n + 1];
    int[] curr = new int[n + 1];

    for (int i = 1; i <= m; i++) {
        for (int j = 1; j <= n; j++) {
            if (text1.charAt(i - 1) == text2.charAt(j - 1)) {
                curr[j] = prev[j - 1] + 1;
            } else {
                curr[j] = Math.max(prev[j], curr[j - 1]);
            }
        }
        int[] temp = prev;
        prev = curr;
        curr = temp;
        Arrays.fill(curr, 0);
    }

    return prev[n];
}
```

### 复杂度

| 方法 | 时间 | 空间 |
|------|------|------|
| 二维DP | O(mn) | O(mn) |
| 两行优化 | O(mn) | O(n) |

### 面试追问

**Q：LCS 和最长公共子串的区别？**

- **子序列（subsequence）**：不要求连续，字符之间可以跳过
- **子串（substring）**：必须连续

LCS 用 `dp[i-1][j-1]+1` 匹配和 `max(dp[i-1][j], dp[i][j-1])` 不匹配。
最长公共子串：不匹配时 `dp[i][j] = 0`（断了），最后取所有 dp 值的最大值。

```java
// 最长公共子串
public int longestCommonSubstring(String text1, String text2) {
    int m = text1.length(), n = text2.length();
    int[][] dp = new int[m + 1][n + 1];
    int maxLen = 0;

    for (int i = 1; i <= m; i++) {
        for (int j = 1; j <= n; j++) {
            if (text1.charAt(i - 1) == text2.charAt(j - 1)) {
                dp[i][j] = dp[i - 1][j - 1] + 1;
                maxLen = Math.max(maxLen, dp[i][j]);
            } else {
                dp[i][j] = 0;  // 不连续就断开！
            }
        }
    }

    return maxLen;
}
```

## 15. 编辑距离

### 题目

将 word1 转换成 word2 所需的最少操作数（插入、删除、替换）。

```
word1 = "horse", word2 = "ros"
horse → rorse (替换h→r)
rorse → rose  (删除r)
rose  → ros   (删除e)
答案: 3
```

### 状态定义与转移方程

**dp[i][j] = word1 前 i 个字符变成 word2 前 j 个字符的最少操作数**

```
如果 word1[i-1] == word2[j-1]:
    dp[i][j] = dp[i-1][j-1]  ← 字符相同，不需要操作

如果 word1[i-1] != word2[j-1]:
    dp[i][j] = min(
        dp[i-1][j] + 1,      ← 删除word1[i-1]（word1少一个字符）
        dp[i][j-1] + 1,      ← 插入word2[j-1]到word1（word1多一个字符）
        dp[i-1][j-1] + 1     ← 替换word1[i-1]为word2[j-1]
    )

初始条件:
dp[0][j] = j  （word1为空，需要插入j个字符变成word2）
dp[i][0] = i  （word2为空，需要删除i个字符）
```

```
填表（word1="horse", word2="ros"）:

      ""  r  o  s
  ""   0  1  2  3
  h    1  1  2  3    ← h≠r, min(1+1, 1+1, 0+1)=1(替换)
  o    2  2  1  2    ← o≠r, min(2+1, 1+1, 1+1)=2(删h或插o→h左)
                    ← o==o, dp[2][2]=dp[1][1]+0=1
  r    3  2  2  2
  s    4  3  3  2
  e    5  4  4  3

答案: dp[5][3] = 3 ✓
```

### 代码实现

```java
public int minDistance(String word1, String word2) {
    int m = word1.length(), n = word2.length();
    int[][] dp = new int[m + 1][n + 1];

    // 初始化
    for (int i = 0; i <= m; i++) dp[i][0] = i;
    for (int j = 0; j <= n; j++) dp[0][j] = j;

    for (int i = 1; i <= m; i++) {
        for (int j = 1; j <= n; j++) {
            if (word1.charAt(i - 1) == word2.charAt(j - 1)) {
                dp[i][j] = dp[i - 1][j - 1];  // 相同，不操作
            } else {
                dp[i][j] = Math.min(
                    dp[i - 1][j] + 1,      // 删除
                    Math.min(
                        dp[i][j - 1] + 1,    // 插入
                        dp[i - 1][j - 1] + 1  // 替换
                    )
                );
            }
        }
    }

    return dp[m][n];
}
```

### 复杂度

- 时间：O(mn)
- 空间：O(mn)，可优化到 O(min(m,n))

### 面试追问

**Q：删除和插入怎么区分？**

dp[i-1][j]+1：word1 多了一个字符，删除它就变成 word2 前 j 个。
dp[i][j-1]+1：word2 多了一个字符，在 word1 插入这个字符。

对称性：删除 word1 的字符 = 在 word2 插入字符，本质相同。

**Q：如果只允许插入和删除，不允许替换？**

修改转移方程：
```java
if (word1.charAt(i-1) == word2.charAt(j-1)) {
    dp[i][j] = dp[i-1][j-1];
} else {
    dp[i][j] = Math.min(dp[i-1][j] + 1, dp[i][j-1] + 1);
    // 没有替换选项！不相等只能删一个或插一个
}
```

**Q：编辑距离的实际应用？**

- 拼写检查/纠错（计算拼写错误的编辑距离，推荐最接近的词）
- DNA 序列比对
- diff 工具（计算文件差异）
- 搜索引擎模糊匹配

## 16. 最长回文子串

### 题目

找到字符串中最长的回文子串。

```
s = "babad"
答案: "bab" 或 "aba"（长度3）
```

### 思路分析

**方法一：区间 DP**

**dp[i][j] = s[i..j] 是否是回文**

```
如果 s[i] == s[j]:
    dp[i][j] = dp[i+1][j-1]  ← 两端相同，看内部是否回文
    特殊: j-i <= 2 时 dp[i][j] = true（长度1或2，两端相同就回文）
如果 s[i] != s[j]:
    dp[i][j] = false

计算顺序: 从短到长 → 先计算长度1、2、3...的子串
```

**方法二：中心扩展**

以每个字符（或每两个字符间隙）为中心，向两边扩展。

```
s = "babad"
中心b(0): b → 单字符回文
中心ba(0,1): ba不是
中心a(1): a → bab ← 向两边扩展，找到长度3
中心ab(1,2): 不是
...
```

**方法三：Manacher 算法 O(n)**

面试不常考，了解即可。

### 代码实现

```java
// 方法一：区间 DP
public String longestPalindromeDP(String s) {
    int n = s.length();
    boolean[][] dp = new boolean[n][n];
    int maxLen = 1, start = 0;

    // 长度1的子串都是回文
    for (int i = 0; i < n; i++) dp[i][i] = true;

    // 长度2
    for (int i = 0; i < n - 1; i++) {
        if (s.charAt(i) == s.charAt(i + 1)) {
            dp[i][i + 1] = true;
            maxLen = 2;
            start = i;
        }
    }

    // 长度3及以上
    for (int len = 3; len <= n; len++) {
        for (int i = 0; i <= n - len; i++) {
            int j = i + len - 1;
            if (s.charAt(i) == s.charAt(j) && dp[i + 1][j - 1]) {
                dp[i][j] = true;
                if (len > maxLen) {
                    maxLen = len;
                    start = i;
                }
            }
        }
    }

    return s.substring(start, start + maxLen);
}

// 方法二：中心扩展（更常用）
public String longestPalindrome(String s) {
    if (s == null || s.length() == 0) return "";

    int start = 0, maxLen = 1;

    for (int i = 0; i < s.length(); i++) {
        // 偶数长度回文（以i和i+1之间的间隙为中心）
        int len1 = expandAroundCenter(s, i, i);
        // 奇数长度回文（以i为中心）
        int len2 = expandAroundCenter(s, i, i + 1);

        int len = Math.max(len1, len2);
        if (len > maxLen) {
            maxLen = len;
            start = i - (len - 1) / 2;
        }
    }

    return s.substring(start, start + maxLen);
}

private int expandAroundCenter(String s, int left, int right) {
    while (left >= 0 && right < s.length() && s.charAt(left) == s.charAt(right)) {
        left--;
        right++;
    }
    return right - left - 1;  // 回文长度
}
```

### 复杂度

| 方法 | 时间 | 空间 |
|------|------|------|
| 区间DP | O(n²) | O(n²) |
| 中心扩展 | O(n²) | O(1) |
| Manacher | O(n) | O(n) |

### 面试追问

**Q：区间DP的计算顺序为什么是按长度递增？**

因为 `dp[i][j]` 依赖 `dp[i+1][j-1]`（内部子串），内部子串长度 = j-i-1 < j-i。必须先算短子串，才能算长子串。按长度从小到大计算保证依赖已就绪。

## 17. 最长回文子序列

### 题目

找到字符串中最长回文子序列的长度（子序列不要求连续）。

```
s = "bbbab"
LPS: "bbbb" → 长度4
```

### 状态定义与转移方程

**dp[i][j] = s[i..j] 中最长回文子序列的长度**

```
如果 s[i] == s[j]:
    dp[i][j] = dp[i+1][j-1] + 2  ← 两端匹配，LPS长度+2
    特殊: i == j → dp[i][j] = 1  （单字符回文）
如果 s[i] != s[j]:
    dp[i][j] = max(dp[i+1][j], dp[i][j-1])  ← 两端不匹配，去掉一端

计算顺序: 从短到长
初始条件: dp[i][i] = 1
```

### 代码实现

```java
public int longestPalindromeSubseq(String s) {
    int n = s.length();
    int[][] dp = new int[n][n];

    // 长度1
    for (int i = 0; i < n; i++) dp[i][i] = 1;

    // 长度2到n
    for (int len = 2; len <= n; len++) {
        for (int i = 0; i <= n - len; i++) {
            int j = i + len - 1;
            if (s.charAt(i) == s.charAt(j)) {
                dp[i][j] = dp[i + 1][j - 1] + 2;
            } else {
                dp[i][j] = Math.max(dp[i + 1][j], dp[i][j - 1]);
            }
        }
    }

    return dp[0][n - 1];
}
```

### 面试追问

**Q：最长回文子串 vs 最长回文子序列的区别？**

| | 子串 | 子序列 |
|---|---|---|
| 连续性 | 必须 | 不必须 |
| 转移 | `s[i]==s[j] && dp[i+1][j-1]` → boolean | `s[i]==s[j] → dp[i+1][j-1]+2` → 长度 |
| 不匹配时 | false（断了） | `max(dp[i+1][j], dp[i][j-1])`（去掉一端） |

**Q：LPS 和 LCS 的关系？**

`s` 的最长回文子序列 = `s` 和 `reverse(s)` 的最长公共子序列！

```java
public int longestPalindromeSubseqByLCS(String s) {
    String reversed = new StringBuilder(s).reverse().toString();
    return longestCommonSubsequence(s, reversed);
}
```

# 第七章：股票买卖系列

## 18. 买卖股票的最佳时机（6 种状态）

### 题目全景

| # | 条件 | 题目 |
|---|------|------|
| I | 只能交易1次 | 最大利润 |
| II | 可以交易无限次 | 最大利润 |
| III | 最多交易2次 | 最大利润 |
| IV | 最多交易k次 | 最大利润 |
| V | 含冷冻期1天 | 最大利润 |
| VI | 含手续费 | 最大利润 |

### 状态机模型

定义三种状态：

```
dp[i][0] = 第i天结束后，持有0股的最大利润（不持有）
dp[i][1] = 第i天结束后，持有1股的最大利润（持有）

状态转移:
dp[i][0] = max(dp[i-1][0], dp[i-1][1] + prices[i])
           ↑ 继续不持有   ↑ 今天卖出（持有→不持有）

dp[i][1] = max(dp[i-1][1], dp[i-1][0] - prices[i])
           ↑ 继续持有     ↑ 今天买入（不持有→持有）
```

### I — 只能交易一次

```java
public int maxProfit_I(int[] prices) {
    int minPrice = Integer.MAX_VALUE;
    int maxProfit = 0;

    for (int price : prices) {
        minPrice = Math.min(minPrice, price);
        maxProfit = Math.max(maxProfit, price - minPrice);
    }

    return maxProfit;
}
// 或用状态机:
// 买入时 dp[i-1][0]=0（之前没交易过，利润为0）
// dp[i][1] = max(dp[i-1][1], -prices[i])  ← 只能从0利润开始买
```

### II — 可以交易无限次

```java
public int maxProfit_II(int[] prices) {
    int hold = -prices[0];     // dp[0][1]
    int notHold = 0;           // dp[0][0]

    for (int i = 1; i < prices.length; i++) {
        int newNotHold = Math.max(notHold, hold + prices[i]);
        int newHold = Math.max(hold, notHold - prices[i]);
        notHold = newNotHold;
        hold = newHold;
    }

    return notHold;
}

// 简化版：所有上涨的都吃
public int maxProfit_II_Simple(int[] prices) {
    int profit = 0;
    for (int i = 1; i < prices.length; i++) {
        if (prices[i] > prices[i - 1]) {
            profit += prices[i] - prices[i - 1];
        }
    }
    return profit;
}
```

### III — 最多交易 2 次

需要记录第几次交易。扩展为 4 个状态：

```
dp[i][1] = 第1次持有
dp[i][2] = 第1次不持有（完成第1次交易）
dp[i][3] = 第2次持有
dp[i][4] = 第2次不持有（完成第2次交易）

dp[i][1] = max(dp[i-1][1], -prices[i])             ← 第1次买入
dp[i][2] = max(dp[i-1][2], dp[i-1][1]+prices[i])   ← 第1次卖出
dp[i][3] = max(dp[i-1][3], dp[i-1][2]-prices[i])   ← 第2次买入
dp[i][4] = max(dp[i-1][4], dp[i-1][3]+prices[i])   ← 第2次卖出
```

```java
public int maxProfit_III(int[] prices) {
    int buy1 = -prices[0], sell1 = 0;
    int buy2 = -prices[0], sell2 = 0;

    for (int i = 1; i < prices.length; i++) {
        buy1 = Math.max(buy1, -prices[i]);
        sell1 = Math.max(sell1, buy1 + prices[i]);
        buy2 = Math.max(buy2, sell1 - prices[i]);
        sell2 = Math.max(sell2, buy2 + prices[i]);
    }

    return sell2;
}
```

### IV — 最多交易 k 次

```java
public int maxProfit_IV(int k, int[] prices) {
    int n = prices.length;
    if (n == 0 || k == 0) return 0;

    // k >= n/2 时等同于无限次交易
    if (k >= n / 2) return maxProfit_II_Simple(prices);

    // dp[j][0] = 第j次持有, dp[j][1] = 第j次不持有
    int[][] dp = new int[k + 1][2];
    for (int j = 1; j <= k; j++) {
        dp[j][0] = -prices[0];
    }

    for (int i = 1; i < n; i++) {
        for (int j = 1; j <= k; j++) {
            dp[j][0] = Math.max(dp[j][0], dp[j - 1][1] - prices[i]);
            dp[j][1] = Math.max(dp[j][1], dp[j][0] + prices[i]);
        }
    }

    return dp[k][1];
}
```

### V — 含冷冻期 1 天

卖出后下一天不能买入：

```
dp[i][0] = max(dp[i-1][0], dp[i-1][1] + prices[i])    ← 不变
dp[i][1] = max(dp[i-1][1], dp[i-2][0] - prices[i])    ← 买入时要看i-2天（冷冻期）
                                                         不是dp[i-1][0]！

初始条件需要额外处理dp[-1]的情况:
dp[0][0] = 0, dp[0][1] = -prices[0]
dp[1][0] = max(0, -prices[0]+prices[1]), dp[1][1] = max(-prices[0], -prices[1])
```

```java
public int maxProfit_V(int[] prices) {
    if (prices.length <= 1) return 0;

    int notHold = 0, hold = -prices[0];
    int prevNotHold = 0;  // dp[i-2][0]

    for (int i = 1; i < prices.length; i++) {
        int temp = notHold;  // 保存当前 notHold，作为下轮的 prevNotHold
        notHold = Math.max(notHold, hold + prices[i]);
        hold = Math.max(hold, prevNotHold - prices[i]);  // 冷冻期！
        prevNotHold = temp;
    }

    return notHold;
}
```

### VI — 含手续费

买入或卖出时扣除手续费 fee：

```java
public int maxProfit_VI(int[] prices, int fee) {
    int notHold = 0, hold = -prices[0] - fee;  // 买入时扣fee

    for (int i = 1; i < prices.length; i++) {
        int newNotHold = Math.max(notHold, hold + prices[i]);
        int newHold = Math.max(hold, notHold - prices[i] - fee);
        notHold = newNotHold;
        hold = newHold;
    }

    return notHold;
}
```

### 面试追问

**Q：股票系列的通用模板是什么？**

```
状态机三要素:
dp[i][k][0] = 第i天，第k次交易，不持有
dp[i][k][1] = 第i天，第k次交易，持有

通用转移:
dp[i][k][0] = max(dp[i-1][k][0], dp[i-1][k][1] + price)   卖出
dp[i][k][1] = max(dp[i-1][k][1], dp[i-1][k-1][0] - price) 买入（第k次买入依赖第k-1次卖出）

特殊情况:
冷冻期: dp[i][1] = max(dp[i-1][1], dp[i-2][0] - price)
手续费: 买入时减fee 或 卖出时减fee
```

# 第八章：字符串 DP

## 19. 单词拆分

### 题目

判断字符串 s 是否能被拆分成字典 wordDict 中的单词。

```
s = "leetcode", wordDict = ["leet", "code"]
答案: true（"leet" + "code"）
```

### 状态定义与转移方程

**dp[i] = s[0..i-1]（前i个字符）是否能被拆分**

```
dp[i] = true  如果存在 j < i 使得:
    dp[j] == true  且  s[j..i-1] 在 wordDict 中

初始条件:
dp[0] = true  （空字符串可以被拆分）

最终答案: dp[s.length()]
```

```
s = "leetcode", dict = ["leet", "code"]

dp[0] = true
dp[4] = true  ← dp[0]=true, s[0..3]="leet" 在dict中
dp[8] = true  ← dp[4]=true, s[4..7]="code" 在dict中

答案: true ✓
```

### 代码实现

```java
public boolean wordBreak(String s, List<String> wordDict) {
    Set<String> wordSet = new HashSet<>(wordDict);
    int n = s.length();
    boolean[] dp = new boolean[n + 1];
    dp[0] = true;

    // 优化：只尝试 dict 中单词的长度
    int maxWordLen = 0;
    for (String word : wordDict) {
        maxWordLen = Math.max(maxWordLen, word.length());
    }

    for (int i = 1; i <= n; i++) {
        // j 从 i-maxWordLen 开始，避免无效检查
        for (int j = Math.max(0, i - maxWordLen); j < i; j++) {
            if (dp[j] && wordSet.contains(s.substring(j, i))) {
                dp[i] = true;
                break;  // 找到一种拆分方式即可
            }
        }
    }

    return dp[n];
}
```

### 复杂度

- 时间：O(n × maxWordLen × substringCost) ≈ O(n²)
- 空间：O(n)

### 面试追问

**Q：如果要求返回所有拆分方式？**

需要用回溯 + 记忆化：

```java
public List<String> wordBreakII(String s, List<String> wordDict) {
    Set<String> wordSet = new HashSet<>(wordDict);
    Map<Integer, List<String>> memo = new HashMap<>();
    return backtrack(s, 0, wordSet, memo);
}

private List<String> backtrack(String s, int start, Set<String> wordSet,
                                Map<Integer, List<String>> memo) {
    if (memo.containsKey(start)) return memo.get(start);

    List<String> result = new ArrayList<>();
    if (start == s.length()) {
        result.add("");  // 空字符串作为终止标记
        return result;
    }

    for (int end = start + 1; end <= s.length(); end++) {
        String word = s.substring(start, end);
        if (wordSet.contains(word)) {
            List<String> subResults = backtrack(s, end, wordSet, memo);
            for (String sub : subResults) {
                result.add(word + (sub.isEmpty() ? "" : " " + sub));
            }
        }
    }

    memo.put(start, result);
    return result;
}
```

## 20. 正则表达式匹配

### 题目

实现正则表达式匹配，支持 `.` 和 `*`：
- `.` 匹配任意单个字符
- `*` 匹配前一个字符零次或多次

```
s = "aab", p = "c*a*b" → true（c*匹配0个c, a*匹配2个a, b匹配b）
```

### 状态定义与转移方程

**dp[i][j] = s 前 i 个字符和 p 前 j 个字符是否匹配**

```
如果 p[j-1] 不是 '*':
    dp[i][j] = dp[i-1][j-1] && (s[i-1]==p[j-1] || p[j-1]=='.')

如果 p[j-1] 是 '*':
    p[j-1]='*'，前面的字符是 p[j-2]
    
    情况1: 匹配0次（忽略 p[j-2]* 这个组合）
        dp[i][j] = dp[i][j-2]
    
    情况2: 匹配1次或多次（s[i-1]必须匹配p[j-2]）
        dp[i][j] = dp[i-1][j] && (s[i-1]==p[j-2] || p[j-2]=='.')
        ↑ dp[i-1][j]: s少一个字符，p的*仍然在（可以继续匹配）

初始条件:
dp[0][0] = true  （空字符串匹配空模式）
dp[0][j] = dp[0][j-2]  如果 p[j-1]=='*'（空字符串可以被 x* 匹配0次）
dp[i][0] = false  （非空字符串不能匹配空模式）
```

### 代码实现

```java
public boolean isMatch(String s, String p) {
    int m = s.length(), n = p.length();
    boolean[][] dp = new boolean[m + 1][n + 1];

    dp[0][0] = true;

    // 初始化：空字符串匹配 a*b* 这类模式
    for (int j = 2; j <= n; j++) {
        if (p.charAt(j - 1) == '*') {
            dp[0][j] = dp[0][j - 2];
        }
    }

    for (int i = 1; i <= m; i++) {
        for (int j = 1; j <= n; j++) {
            char sc = s.charAt(i - 1);
            char pc = p.charAt(j - 1);

            if (pc == '*') {
                // 匹配0次：忽略 x*
                dp[i][j] = dp[i][j - 2];
                // 匹配1+次：当前字符匹配 x，且去掉当前字符后仍匹配
                if (sc == p.charAt(j - 2) || p.charAt(j - 2) == '.') {
                    dp[i][j] = dp[i][j] || dp[i - 1][j];
                }
            } else {
                // 非*：直接匹配
                dp[i][j] = dp[i - 1][j - 1]
                    && (sc == pc || pc == '.');
            }
        }
    }

    return dp[m][n];
}
```

### 复杂度

- 时间：O(mn)
- 空间：O(mn)

### 面试追问

**Q：为什么 `*` 的匹配1+次是 `dp[i-1][j]` 而不是 `dp[i-1][j-1]`？**

因为 `*` 可以匹配多次。`dp[i-1][j]` 表示 s 去掉当前字符后，p 仍然停留在 `*` 的位置（可能还会继续匹配）。而 `dp[i-1][j-1]` 表示用完 `*`，后面就不能再匹配了。

**Q：`dp[0][j]` 的初始化为什么只处理 `*`？**

空字符串只能被「匹配0次」的模式匹配。`a*` 匹配0次→空，`a*b*` 匹配0次→空。非 `*` 的字符不可能匹配空字符串。

# 第九章：总结

## 21. DP 技巧总结与速查表

### DP 解题思维框架

```
第一步: 定义状态
  ┌─ 一维: dp[i] 表示什么？
  ├─ 二维: dp[i][j] 表示什么？
  ├─ 三维: dp[i][j][k] 表示什么？
  └─ 关键: 状态定义要能自然推导转移方程

第二步: 推导转移方程
  ┌─ 问自己: dp[当前] 从哪些 dp[之前] 推导？
  ├─ 什么条件下选择什么？
  └─ 用 max/min/+ 来组合

第三步: 初始条件
  ┌─ 最小子问题的直接答案
  ├─ dp[0] = ?
  └─ dp[边界] = ?

第四步: 计算顺序
  ┌─ 保证计算当前状态时依赖已就绪
  ├─ 一维: 从小到大
  ├─ 二维: 从左到右、从上到下
  └─ 区间: 从短到长
```

### 空间优化规则

```
一维DP → 两个变量滚动（爬楼梯、打家劫舍）
二维DP[m][n] → 一维[n]（不同路径、最小路径和、LCS）
二维DP[m][n] → 两行滚动（编辑距离、LCS）
0-1背包 → 一维逆序遍历
完全背包 → 一维正序遍历
区间DP → 一般无法优化（dp[i][j]依赖四个方向）
```

### 常见陷阱

```
陷阱1: 状态定义不清晰，转移方程推导困难
解决: 先想清楚dp[i]的含义，再推导转移

陷阱2: 0-1背包一维优化正序遍历（物品被选多次）
解决: 必须逆序遍历容量

陷阱3: 完全背包求方案数时内外循环顺序错误
解决: 外层物品内层容量→组合数；外层容量内层物品→排列数

陷阱4: 区间DP计算顺序错误
解决: 按区间长度从小到大，因为dp[i][j]依赖dp[i+1][j-1]（内部更短）

陷阱5: 初始化搞错
解决: dp[0]要看情况——方案数题dp[0]=1（空也算一种），最值题dp[0]=0或∞

陷阱6: 回文子串vs子序列混淆
解决: 子串不匹配=false（断开），子序列不匹配=max（去掉一端）

陷阱7: 零钱兑换dp初始化用Integer.MAX_VALUE导致+1溢出
解决: 用amount+1作为"不可能"的初始值，或用INF=amount+1
```

### 题型 → 转移方程速查

| 题型 | 状态定义 | 转移方程 |
|------|----------|----------|
| **Fibonacci类** | dp[i]=到达i的方法数 | `dp[i]=dp[i-1]+dp[i-2]` |
| **打家劫舍** | dp[i]=前i家最大金额 | `dp[i]=max(dp[i-1], dp[i-2]+nums[i])` |
| **最大子数组** | dp[i]=以i结尾的最大和 | `dp[i]=max(dp[i-1]+nums[i], nums[i])` |
| **0-1背包** | dp[i][w]=前i物品容量w最大值 | `max(dp[i-1][w], dp[i-1][w-wi]+vi)` |
| **完全背包** | dp[i][w]=前i物品容量w最大值 | `max(dp[i-1][w], dp[i][w-wi]+vi)` |
| **不同路径** | dp[i][j]=到(i,j)的路径数 | `dp[i-1][j]+dp[i][j-1]` |
| **最小路径** | dp[i][j]=到(i,j)最小和 | `grid[i][j]+min(dp[i-1][j],dp[i][j-1])` |
| **LIS** | dp[i]=以i结尾的LIS长度 | `max(dp[j]+1) ∀j<i,nums[j]<nums[i]` |
| **LCS** | dp[i][j]=前i前j的LCS长度 | 匹配:`dp[i-1][j-1]+1`; 不匹配:`max(dp[i-1][j],dp[i][j-1])` |
| **编辑距离** | dp[i][j]=word1前i变word2前j最少操作 | 匹配:`dp[i-1][j-1]`; 不匹配:`min(删+1,插+1,换+1)` |
| **回文子串** | dp[i][j]=s[i..j]是否回文 | `s[i]==s[j]&&dp[i+1][j-1]` |
| **回文子序列** | dp[i][j]=s[i..j]的LPS长度 | 匹配:`dp[i+1][j-1]+2`; 不匹配:`max(dp[i+1][j],dp[i][j-1])` |
| **单词拆分** | dp[i]=前i字符能否拆分 | `dp[j]&&s[j..i-1]∈dict` |
| **正则匹配** | dp[i][j]=s前i匹配p前j | 非*:`dp[i-1][j-1]&&(匹配)`; *:`dp[i][j-2]||(匹配&&dp[i-1][j])` |
| **股票买卖** | dp[i][k][0/1]=第i天第k次交易持有/不持有 | 卖:`dp[i-1][k][1]+price`; 买:`dp[i-1][k-1][0]-price` |

## 22. 10 道面试高频题

### Q1：动态规划和贪心的核心区别是什么？什么时候用 DP？

**答**：贪心每步做局部最优选择，不能回头，不保证全局最优。DP 考虑所有可能选择，存储子问题最优解，通过组合得到全局最优。

用 DP 的信号：
1. 求「最优值」（最大/最小/最长）
2. 问题有重叠子问题（同一子问题被多次计算）
3. 有后效性——当前选择影响后续结果（贪心无法处理）
4. 问题可以自然拆成规模更小的同类问题

反例：贪心适用的场景——活动选择问题、Huffman 编码——每步最优不影响后续最优。

---

### Q2：0-1 背包和完全背包的核心区别？一维优化时遍历顺序为什么不同？

**答**：0-1 背包每种物品最多选一次，完全背包每种物品可选无限次。

二维 DP 的区别在转移方程：
- 0-1：选第 i 物品时参考 `dp[i-1][w-wi]`（上一行的值，i 只选一次）
- 完全：选第 i 物品时参考 `dp[i][w-wi]`（当前行的值，i 可以再选）

一维优化时：
- 0-1 必须逆序遍历容量——正序会导致 `dp[w-wi]` 已经被当前物品更新过，相当于选了两次
- 完全必须正序遍历容量——正序恰好允许 `dp[w-wi]` 被当前物品更新，代表选了多次

---

### Q3：零钱兑换最少硬币数和方案数，为什么循环顺序不同？

**答**：最少硬币数求的是最优值（min），不管排列还是组合，结果一样。内外层顺序不影响。

方案数求的是方案数，顺序敏感：
- 外层物品、内层金额 → 组合数（每种硬币按"出现顺序"只贡献一次）
- 外层金额、内层物品 → 排列数（同一组硬币的不同排列被算成不同方案）

比如 `coins=[1,2], amount=3`：
- 组合数=2：{1,1,1}, {1,2}
- 排列数=3：{1,1,1}, {1,2}, {2,1}

题目要求组合数，所以外层遍历硬币。

---

### Q4：最长递增子序列（LIS）两种方法的时间复杂度？贪心+二分的 tails 数组含义？

**答**：DP 方法 O(n²)，贪心+二分 O(n log n)。

tails[k] = 所有长度为 k+1 的递增子序列中末尾元素的最小值。维护 tails 保证：末尾越小，后续元素越容易接上来，LIS 可以更长。

遇到新元素 x：
- x > tails 所有值 → 追加，LIS 长度+1
- x ≤ tails 某个值 → 替换那个值（保持末尾最小）

tails 的长度就是 LIS 的长度。但 tails 本身不一定是有效的 LIS 序列。

---

### Q5：编辑距离的三种操作怎么理解？为什么对称？

**答**：三种操作对应三种转移：
- `dp[i-1][j]+1`：删除 word1 的字符 → word1 缩短
- `dp[i][j-1]+1`：在 word1 插入字符 → word1 增长（相当于 word2 缩短）
- `dp[i-1][j-1]+1`：替换 word1 的字符 → 两者同时缩短

对称性：删除 word1[i] 等价于在 word2 对应位置插入 word1[i]。`dp[i-1][j]+1` 和 `dp[i][j-1]+1` 是对称的操作，只是视角不同。

---

### Q6：最长回文子串和子序列的 DP 有什么区别？

**答**：

子串（连续）：
- 状态：`dp[i][j] = s[i..j] 是否回文`（boolean）
- 不匹配时：`dp[i][j] = false`（断了，不能继续）
- 找最大：遍历所有 dp[i][j]=true 中 j-i 最大的

子序列（不连续）：
- 状态：`dp[i][j] = s[i..j] 的 LPS 长度`（int）
- 不匹配时：`dp[i][j] = max(dp[i+1][j], dp[i][j-1])`（去掉一端继续）
- 找最大：`dp[0][n-1]`

核心区别：不匹配时子串直接断（false），子序列可以跳过一个端继续（max）。

---

### Q7：股票买卖系列怎么统一处理？

**答**：用状态机模型。定义两个状态：
- `hold`：持有股票的最大利润
- `notHold`：不持有股票的最大利润

每天两个状态各有两种转移：
- notHold → hold（买入）：`hold = max(hold, notHold - price)`
- hold → notHold（卖出）：`notHold = max(notHold, hold + price)`

各种变体只需修改：
- 最多 k 次：用 k 组 hold/notHold 状态
- 冷冻期：买入时参考 i-2 天的 notHold
- 手续费：买入或卖出时额外减 fee
- 只能一次：hold 初始化为 -prices[0]，不可从之前的 notHold 买入

---

### Q8：区间 DP 的计算顺序为什么特殊？

**答**：区间 DP 的状态 `dp[i][j]` 依赖 `dp[i+1][j-1]`（内部子区间）。内部子区间长度比当前区间短，所以必须先算短区间再算长区间。

计算方式：按区间长度 len 从 1 到 n 遍历，对每个 len 遍历所有起点 i。

```
for len = 1 → n:
    for i = 0 → n-len:
        j = i + len - 1
        dp[i][j] = ...
```

这保证了计算 `dp[i][j]` 时，`dp[i+1][j-1]`（长度 len-2）已经算好了。

---

### Q9：DP 空间优化的一般规则？

**答**：
- 一维 DP → 两个/三个变量滚动（如爬楼梯只需 prev1, prev2）
- 二维 DP 依赖上一行 → 一维数组（如网格路径、LCS）
- 二维 DP 依赖上一行和上一列 → 两行数组（如编辑距离）
- 0-1 背包一维优化 → 容量逆序遍历
- 完全背包一维优化 → 容量正序遍历
- 区间 DP → 通常无法空间优化（dp[i][j] 依赖四个方向的值）

关键判断：看转移方程依赖哪些位置。如果只依赖上一行/前几个值，就可以优化。

---

### Q10：如何判断一道题是 DP 而不是其他算法？

**答**：看三个特征：
1. **最优子结构**：大问题最优解包含小问题最优解 → DP 可行
2. **重叠子问题**：小问题被反复计算 → DP 有意义（否则用分治）
3. **后效性**：当前决策影响后续 → 不能贪心 → 可能是 DP

典型 DP 信号词：
- 「最大/最小/最长/最短」
- 「有多少种方法/方案数」
- 「能否达到/是否可能」
- 「所有可能的…」

不是 DP 的信号：
- 只需要局部最优 → 贪心
- 子问题独立无重叠 → 分治
- 搜索所有可能性 → 回溯/DFS
- 最短路径（图） → BFS/Dijkstra

> **学习建议**：
> 1. **先掌握四步法**：定义状态 → 推转移方程 → 初始条件 → 计算顺序。这是所有DP题的通用框架。
> 2. **DP入门路线**：爬楼梯 → 打家劫舍 → 最大子数组 → 0-1背包 → 完全背包 → 不同路径 → LCS → 编辑距离 → 回文 → 股票。
> 3. **背包是核心**：0-1背包和完全背包是面试最常考的DP题型，一定要理解正序/逆序的区别。
> 4. **空间优化是加分项**：面试中写出二维DP即可，但能写出空间优化版本会加分。
> 5. **状态定义是最关键一步**：好的状态定义让转移方程自然推导。如果转移方程推导困难，大概率是状态定义不够好，重新定义。
> 6. **多画表格**：填几个小例子帮助理解转移方程，尤其是二维DP。
