> **FlowPulse 智能限流架构（创新点四）**

```
                     HTTP Request 进入
                           │
                    ┌──────▼──────┐
                    │ 白名单检查?   │ ──Yes──→ 直接放行
                    └──────┬──────┘
                           │ No
                    ┌──────▼──────┐
                    │ 提取限流Key   │
                    │ 优先级: userId > apikey > ip
                    └──────┬──────┘
                           │
              ┌────────────▼────────────┐
              │  第一级: 令牌桶 (用户维度) │
              │  capacity = userTier × 100 │
              │  refillRate = 动态调整     │
              │  ├─ VIP用户: 500 QPS      │
              │  ├─ 普通用户: 200 QPS      │
              │  └─ 匿名用户: 50 QPS       │
              └────────────┬────────────┘
                           │ 通过?
                   ┌───────┴───────┐
                   Yes             No → 429 Too Many Requests
                   │               + Retry-After: X秒
              ┌────▼────┐
              │ 第二级:  │
              │ 漏桶(IP) │ ← 兜底！防止单IP多账号绕过
              │ rate=    │   用户维度限流
              │ 30 req/s │
              └────┬────┘
                   │ 通过?
            ┌──────┴──────┐
            Yes             No → 429 + IP封禁警告
            │
     ┌────────▼────────┐
     │  动态阈值引擎      │
     │  基于:            │
     │  · 历史流量趋势    │
     │  · 当前系统负载    │
     │  · 时间段特征     │
     │  · 业务事件日历    │
     │  输出: 新refillRate│
     └────────┬────────┘
             │
             ▼
      放行到后端服务
```
