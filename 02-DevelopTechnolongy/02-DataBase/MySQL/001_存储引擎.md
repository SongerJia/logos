|知识点|笔记时重点写什么|
|---|---|
|**InnoDB vs MyISAM 对比**|热 做一张完整对比表：事务支持、行级锁、外键、崩溃恢复、MVCC、存储方式（聚簇 vs 非聚簇）、索引实现（B+树 vs B树）。**MySQL 5.5 之后默认 InnoDB，MyISAM 已基本淘汰，但对比题仍然必问**|
|**InnoDB 数据页结构**|核 一页默认 16KB。内部：File Header / Page Header / Infimum + Supremum 虚拟记录 / User Data（实际数据记录） / Free Space / Page Directory（槽） / File Tailer。**理解页结构是理解 B+ 树的基础**|
|**InnoDB 表空间与段区页**|表空间（.ibd 文件）→ 段（数据段/索引段/回滚段）→ 区（64 个连续页 = 1MB）→ 页（16KB）→ 行。这个层级关系面试常用来考查对底层组织的理解程度|
|**Memory / TokuDB / MyRocks 简介**|Memory（堆表，Hash 索引，适合临时表/字典表）、TokuDB（Fractal Tree 压缩率高，适合日志归档场景）、MyRocks（LSM-Tree 结构，写入性能好）。了解即可，知道选型依据|
