对象存储几乎是每个 Java 项目的标配——存头像、文件、图片、备份。

|#|知识点|重要度|笔记三层建议|跨模块关联|
|---|---|---|---|---|
|2.1|**对象存储基本概念**|🟡 应掌握|① Object = 文件 + 元数据（Key/ContentType/Size/LastModified）；Bucket = 容器 ② 与文件系统区别：扁平命名（无目录层级）、海量小文件优化、RESTful API 访问 ③ 面试：对象存储和普通文件服务器有什么区别？什么时候选哪个？|→ Nginx 静态资源服务（M4 缓存）|
|2.2|**阿里云 OSS 使用实践**|🟡 应掌握|① SDK 核心 API：putObject（上传）/ getObject（下载）/ generatePresignedUrl（签名 URL，前端直传）② 前端直传流程：后端签 STS Token → 前端直接上传 OSS → 回调通知后端 ③ 安全要点：Bucket 权限控制、URL 签名过期时间、防盗链 Referer|→ JWT/OAuth2（S5 安全认证）|
|2.3|**MinIO 自建对象存储**|🟡 应掌握|① MinIO：Go 写的高性能兼容 S3 协议的对象存储，支持分布式部署 ② 典型场景：私有化部署（无法用云 OSS）/ 开发测试环境 / K8s 存储 ③ 和云 OSS 对比：自运维成本 vs 费用灵活 vs 功能完整性 ④ 面试：什么情况下会选择自建 MinIO 而不是用云 OSS？|→ Docker/K8s 运维|
|2.4|**大文件分片上传**|🟡 应掌握|① 流程：初始化分片 uploadId → 分片上传 part（并行）→ 合并 completeUpload ② 断点续传：记录已上传的分片编号，网络中断后续传 ③ 面试：大文件（如 1GB 视频）上传怎么做？如何实现断点续传？|→ HTTP 协议（Range 请求头）|
|2.5|**CDN 加速与成本优化**|🟢 了解|① OSS + CDN 组合：OSS 作为源站 → CDN 边缘节点就近分发静态资源 ② 成本优化：选择合适的存储类型（标准/低频/归档）、生命周期策略自动降冷 ③ 面试：你们的静态资源架构是怎样的？CDN 命中率多少？|→ Nginx CDN 架构（M4.3）|
|2.6|**安全最佳实践**|🟢 了解|① 最小权限原则（RAM 子账号 + Policy 细粒度授权）② 数据加密（服务端 SSE / 客户端 CSE）③ 访问日志与审计 ④ 面试：OSS 存敏感文件（用户身份证照），你怎么做安全防护？|→ 安全架构方向|
