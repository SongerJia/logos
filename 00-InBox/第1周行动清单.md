# 第1周行动清单

> 2026/6/3 — 6/9 · 四线并行 · 目标体重 155斤

---

## 每日固定底线

- **饮食**：早餐按模板 · 午餐按模板 · 晚餐无主食 · 不碰含糖饮料/酒精/零食/夜宵 · 喝水 2L+ · 23:00前睡
- **驼背纠正5动作**：门框胸肌拉伸 + 下巴后缩 + YTWL + 墙壁天使 + 猫牛式（约10分钟，工间/随时做）
- **标签说明**：`减脂` · `说话` · `软考` · `雅思`

---

## 周三 6/3 · 今天 · ⚡训练日

### 起床后

- [ ] `说话` 口腔训练：吧啪嘛发各10遍 + 嘚嘚嘚30下 + 绕口令慢速练1条
- [ ] `减脂` 驼背纠正5动作（10分钟）

### 通勤 / 午休

- [ ] `说话` 复述训练：读1篇技术文章（掘金/InfoQ），关掉后录音用自己的话讲1-2分钟，回听纠错
- [ ] `雅思` 口语Part 2：随机抽1张话题卡，准备1min关键词，录音说满2min，回听纠错再录一遍
- [ ] `说话` 主动跟同事说一句话（随便找理由开口）

### 下班后

- [ ] `减脂` 力量训练（45分钟）
  - 开合跳 30秒×3组
  - 高抬腿 30秒×2组
  - 徒手深蹲 15次×3组
  - 跪姿俯卧撑 10次×3组
  - 臀桥 15次×3组
  - 死虫式 每侧10次×3组
  - 平板支撑 20秒×3组
  - 快走/慢跑 15min 心率130-140
- [ ] `软考` 刷选择题30-40题（45min）→ 立刻对答案，错的搞懂 → 错题记入错题本（30min）→ 看案例分析1道只读不写（15min）

### 晚间

- [ ] `雅思` 听力精听：做1个Section（10min）→ 逐句暂停默写对照原文（25min）→ 影子跟读（10min）
- [ ] `雅思` 阅读：限时20min做1篇文章 → 10min复盘错题
- [ ] `雅思` 写作（奇数日）：写1篇大作文提纲（Intro + 2个Body段中心句 + Conclusion），对照范文比论点
- [ ] `说话` 语速控制：找段文章，正常读→刻意放慢到180字/分钟→标点处停半拍，录音回听

### 睡前

- [ ] `减脂` 腹肌附加训练（10min）：卷腹20×3 + 仰卧举腿15×3 + 俄罗斯转体每侧15×3 + 平板支撑力竭×2
- [ ] 23:00前睡觉
