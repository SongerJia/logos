### ⚠️ 写笔记特别提醒

1. **M2.4（proxy_pass 带/不带/）+ M3.1（Location 优先级）+ M3.2（last vs break）** 这三个知识点强烈建议自己动手写 Nginx 配置并测试！纯文字记忆永远记不住，必须实操验证。面试官最爱出这种"给一段配置问结果"的题目
2. **画两张图放在笔记首页**：① Master-Worker + epoll 事件循环图 ② Client → Nginx → Upstream 完整请求链路图（标注每一步可能出的问题）
3. **Nginx 对 Java 后端的意义**：你不是运维，不需要精通所有模块。重点掌握「请求如何经过 Nginx 到达你的 Spring Boot」这条主线上的知识即可。其他（如邮件模块、流媒体）了解即可

### Seata 与其他模块的关联网络

```
Nginx ←→ Java 并发 (epoll vs 线程池 / 异步非阻塞)
     ←→ Spring Cloud (Gateway vs Nginx / XID 透传 Header)
     ←→ MySQL (慢查询导致 504 / 连接池类比)
     ←→ Redis (缓存层级: Browser → Nginx → Redis → DB)
     ←→ HTTPS/TLS (证书 / 安全Header)
     ←→ Docker/K8s (Ingress Controller 就是 Nginx)
     ←→ SkyWalking ($request_id 链路透传)
```
