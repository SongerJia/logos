## ⚠️ 写笔记特别提醒

1. **N1.2（Reactor 三种模型）+ N2.3（零拷贝两种含义）+ N3.2（四种拆包器）** 这三个知识点**必须画图**！纯文字记忆效率极低，面试官也最喜欢让你"在白板上画一下 Reactor 模型"
    
2. **N3.3（自定义协议设计）** 强烈建议自己设计一个简单的二进制协议（比如一个 Chat 消息协议），然后用 Netty 实现编解码器。这是能展示"不只是会用 API"的绝佳素材
    
3. **和已有知识的关联是最大亮点**：
    
    - Netty 零拷贝 ↔ Kafka/RocketMQ 零拷贝（对比学习，面试加分）
    - Netty EventLoop 单线程模型 ↔ Redis 单线程事件循环（类比）
    - Netty Pipeline 责任链 ↔ Spring MVC 拦截器链（设计模式复用）
4. **实战项目建议**：用 Netty 实现一个简单的 RPC 框架（参考 Dubbo 的简化版），包含：自定义协议 + 编解码 + 动态代理 + 服务注册发现。这个项目能同时覆盖 Netty/Dubbo RPC/注册中心 三个方向！

## Netty 与其他模块的关联网络

```
Netty 
  ←→ Java NIO (Selector/Channel/Buffer 是直接前驱知识)
  ←→ Kafka (零拷贝 sendfile / PageCache 读写)
  ←→ RocketMQ (Netty 作为通信层 / 零拷贝 MMap)
  ←→ Redis (单线程事件循环模型类比)
  ←→ Dubbo (Netty 作为底层通信框架 / 自定义协议)
  ←→ gRPC (同样基于 Netty + HTTP/2)
  ←→ Elasticsearch (Transport 层用 Netty)
  ←→ 设计模式 (责任链/观察者/策略模式在 Netty 里的应用)
```
