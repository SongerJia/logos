### 为什么这个模块

**SSO 是企业级应用的标配**，也是面试中体现"做过真实项目"的好话题。

| --- | ------------------------ | ----- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ----------------------------------------------- |
| 6.1 | **SSO 原理 & 实现方案**        | 🟡应掌握 | ① **CAS（Central Authentication Service）**：经典 SSO 方案（TGT/ST 票据模型），一次登录生成 TGT（全局票据），访问各应用时用 TGT 换 ST（服务票据）② **基于 OAuth2/OpenID Connect 的 SSO**：更现代的方案（OIDC 在 OAuth2 上增加了身份层 id_token）③ **Cookie + 域共享**：简单方案，同父域下共享 Cookie（安全性较低）④ 面试：SSO 的原理是什么？你们用的哪种方案？ | → OAuth2（S5）/ Cookie / Domain                   |
| 6.2 | **OWASP Top 10 常见攻击及防御** | 🟡应掌握 | ① **XSS（跨站脚本）**：输入过滤 + 输出编码 + CSP 头 ② **CSRF（跨站请求伪造）**：CSRF Token / SameSite Cookie / 验证 Referer ③ **SQL 注入**：参数化查询 / MyBatis #{} vs ${} ④ **越权访问**：水平越权（操作别人数据）+ 垂直越权（普通用户操作管理员功能）→ 严格权限校验 ⑤ 面试：你了解 OWASP Top 10 吗？说说你项目里做了哪些安全防护？                      | → SQL 注入（MySQL）/ Spring MVC 参数绑定（天然防注入）         |
| 6.3 | **密码安全最佳实践**             | 🟡应掌握 | ① **存储**：绝对不能明文存储！用 BCrypt/Argon2 哈希 + 盐 ② **传输**：全程 HTTPS（TLS 1.2+），禁止明文传密码 ③ **复杂度策略**：长度≥8 + 大小写+数字+特殊字符 ③ **登录限制**：连续失败锁定 / 图形验证码 / IP 黑名单 ④ 面试：用户的密码应该怎么安全地存储和处理？                                                                                   | → BCryptPasswordEncoder（S2.3）/ HTTPS（Nginx SSL） |
| 6.4 | **API 安全：接口鉴权 & 限流**     | 🟡应掌握 | ① **接口鉴权**：Gateway 层统一校验 Token → 服务间调用用内部 Token（mTLS 或签名） ② **接口限流**：防止暴力破解 / 防止爬虫（Sentinel / Gateway 限流） ③ **参数签名**：关键接口加签（timestamp + nonce + sign），防篡改防重放 ④ 面试：你们的 API 安全方案是怎样的？怎么防刷接口？                                                               | → Sentinel（熔断限流）/ Spring Cloud Gateway（统一鉴权）    |
