|#|知识点|重要度|三层笔记建议|面试追问|FlowPulse 结合|
|---|---|---|---|---|---|
|A1-01|**Docker 核心概念与架构**|★★★|L1: 镜像(Image，只读模板) → 容器(Container，运行实例) → 仓库(Registry，存储镜像)；L2: Client-Server架构：CLI → dockerd(Daemon守护进程) → containerd/runc(运行时)；L3: Namespace隔离(UTS/PID/Network/Mount/User/IPC) + CGroups资源限制(CPU/Memory/IO)|Container和VM的区别？Namespace有哪些类型？CGroup v1 vs v2？|**FlowPulse全面容器化部署的基础**|
|A1-02|**Dockerfile 最佳实践**|★★★|L1: 基础镜像选择(eclipse-temurin:17-jre-slim精简版) / .dockerignore排除不必要文件 / 分层缓存利用(频繁变化的放后面)；L2: 多阶段构建(Multi-stage Build)：编译阶段(maven:3.9-eclipse-temurin-17) → 运行阶段(eclipse-temurin:17-jre-slim)；L3: 安全扫描(trivy/dockle) + 最小权限原则(rootless container)|多阶段构建能减少多少体积？RUN COPY指令顺序怎么优化？|**FlowPulse每个微服务的Dockerfile标准化**|
|A1-03|**镜像分层与缓存策略**|★★★|L1: 每个Dockerfile指令一层(Layer)，相同层的hash相同则复用(Cache Hit)；L2: UnionFS(联合文件系统)：Overlay2驱动将多层合并为统一视图；L3. 缓存失效：某一层变化则后续层全部重建 → 优化：maven依赖COPY在前(pom.xml单独COPY→mvn dependency:resolve→COPY src)|为什么COPY . .不好？怎么最大化利用缓存？|FlowPulse CI/CD流水线中的镜像构建优化|
|A1-04|**Docker 网络**|★★☆|L1: Bridge(默认，容器间通过docker0网桥通信) / Host(共享主机网络) / None(无网络) / Overlay(跨主机)；L2: 端口映射(-p 8080:80)的iptables NAT原理；L3. 容器DNS(embedded DNS server, --link已废弃用--network alias)|容器间怎么通信？Bridge网络和Host网络的性能差异？|FlowPulse微服务间容器网络通信|
|A1-05|**Docker 存储驱动**|★☆☆|L1: Overlay2(默认，Copy-on-Write写时复制) / fuse-overlay2(FUSE用户态) / vfs(简单但性能差)；L2: 卷(Volume，持久化数据) vs 绑定挂载(Bind Mount，宿主机目录映射) vs tmpfs(内存临时存储)；L3. Volume生命周期独立于容器(docker rm -v才删)|数据存在哪层？Volume和Bind Mount选哪个？|**FlowPulse日志和数据使用Volume持久化**|
|A1-06|**Docker Compose**|★★☆|L1: docker-compose.yml定义多容器应用(服务/网络/卷)；L2. up -d后台启动 / logs查看日志 / scale横向扩展；L3: 与K8s的关系——开发环境用Compose，生产环境用K8s|Compose和K8s的区别？什么时候用Compose就够了？|**FlowPulse开发环境一键启动：App + MySQL + Redis + Nacos + RocketMQ**|
|A1-07|**容器安全基线**|★★☆|L1: 基础镜像安全(官方镜像定期更新/避免latest标签/扫描CVE漏洞)；L2: 容器内非root运行(USER指令)/只读文件系统(read_only: true)/Capability限制(drop ALL按需添加)；L3. Runtime安全(runc/seccomp/AppArmor限制系统调用)|容器逃逸漏洞怎么防？seccomp配置复杂吗？|FlowPulse容器安全合规要求|
|A1-08|**Docker 性能调优**|★☆☆|L1. I/O性能：–storage-opt size限制容器磁盘 / –device-read-bps限制读取速率；L2. CPU限制(–cpus 2.0 或 –cpu-period + –cpu-quota) / Memory限制(-m 512M + –memory-swap控制Swap)；L3. 性能监控(docker stats / cadvisor指标采集)|容器和原生性能差距多大？cgroup限制对JVM的影响？|FlowPulse容器资源配额规划|
