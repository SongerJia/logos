## 话题二：volatile 与原子性（10分钟）

**面试官：volatile 能保证原子性吗？为什么？**

→ 你回答（不能、只能保证可见性和有序性）...

**追问1：** i++ 操作为什么不是原子的？如果 i 是 volatile 的，i++ 是线程安全的吗？

→ 你回答（不是、读取+修改+写回三步）...

**追问2：** 如果有一个 volatile 的 boolean 变量 flag，一个线程写 flag = true，另一个线程读 flag，能保证读到 true 吗？

→ 你回答...

**追问3：** volatile 的内存语义是什么？写 volatile 和读 volatile 分别做了什么？

→ 你回答（写：刷新到主内存、读：从主内存读取）...

**追问4：** 在单例模式的双重检查锁中，如果 instance 不加 volatile，会出现什么问题？用 JMM 的角度解释。

→ 你回答（指令重排、半初始化状态）...

**追问5：** 除了 volatile，还有什么方式可以保证变量的可见性？

→ 你回答（synchronized、Lock、Atomic、final）...
