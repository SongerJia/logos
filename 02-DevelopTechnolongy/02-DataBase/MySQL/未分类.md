## MySQL 整体优先级

```
P0 必考（源码级深度，每轮面试必问）：
  02 索引(B+树/聚簇/最左前缀/ICP)  >  03 事务与锁(MVCC/隔离级别/Next-Key)
  >  05 日志系统(redo/binlog两阶段提交)

P1 高频问答（原理 + 工程实践）：
  04 SQL优化(EXPLAIN/慢SQL/深分页)  >  06 主从复制(GTID/延迟)
  >  08 实战专题(字符集/数据类型/DDL)

P2 架构加分项：
  07 高可用(MHA/MGR/读写分离)
  
P3 基础了解：
  01 存储引擎
```

**推荐笔记顺序**：`01 → 02 → 04 → 03(A+B) → 05 → 06 → 08 → 07`

理由：先快速过一遍存储引擎建立概念(01)，然后直接进入最重的索引模块(02)，紧接着学 SQL 优化(04)（这两块日常开发最常用），然后花最多时间攻克事务与锁(03)（依赖索引知识），接着学底层可靠性保障(05)，再到主从复制(06)，补充实战细节(08)，最后看高可用架构(07)。

## MySQL 与其它模块的关键连接点

```
MySQL                              Redis
─────                              ────
索引加速查询                       → 缓存穿透/击穿/雪崩
事务 ACID                          → 缓存一致性（先更DB还是先删缓存？）
binlog 主从复制                    → Redis 主从 / Sentinel 哨兵
死锁检测                           → 分布式锁（Redission / setnx）
慢查询                             → 热点 Key 发现

MySQL                              Elasticsearch
─────                              ─────────────
全量数据源                         → ES 同步策略（Canal 解析 binlog）
LIKE 模糊搜索                     → ES 全文检索替代
复杂聚合查询                      → ES 聚合能力增强

MySQL                              分库分表
─────                              ────────
索引设计                           → 分片键选择（必须命中索引）
事务                               → 分布式事务（Seata）
主从复制                           → 数据中间件路由（ShardingSphere）

MySQL                              框架
─────                              ────
一级缓存(SqlSession级)             → Spring整合后事务内共用SqlSession
事务隔离级别                        → Spring @Transactional(isolation = ...)
连接池(HikariCP)                   → DataSourceAutoConfiguration 自动装配
```
