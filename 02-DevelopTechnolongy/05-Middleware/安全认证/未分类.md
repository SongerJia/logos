### 推荐学习顺序

```
S1 FilterChain架构(5点) → S2 认证流程(5点)
→ S4 JWT无状态认证(5点) ★ 面试最高频
→ S3 授权流程RBAC(5点)
→ S5 OAuth2授权框架(4点)
→ [按需] S6 SSO&安全实践(4点)
```

### 面试最高频 Top 5 考点

1. **JWT 结构 + 双 Token 机制** — 几乎必问，必须能手写 JWT Filter
2. **OAuth2 授权码完整流程**（code 换 token）— 画图题高频
3. **Spring Security FilterChain**（15 个 Filter 的职责分工）— 架构基础题
4. **JWT vs Session-Cookie 方案选型** + 安全风险防御
5. **RBAC 权限模型设计** + @PreAuthorize 方法级权限

### 安全认证与其他模块的关联网络

```
安全认证 ←→ Spring Cloud Gateway (统一鉴权 / Token透传 Header)
         ←→ Redis (Session共享 / RefreshToken 存储)
         ←→ Nginx HTTPS/SSL (传输层安全)
         ←→ MyBatis (#{} 防 SQL 注入)
         ←→ Spring AOP (@PreAuthorize 注解底层原理)
         ←→ Dubbo (服务间内部调用鉴权 / mTLS)
```
