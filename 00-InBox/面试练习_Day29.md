## 话题一：Java 对象与内存（10分钟）

**面试官：一个 Java 对象在内存里长什么样？说说对象头里都有什么？**

你回答（Mark Word、Klass Pointer、实例数据、对齐填充）...

**追问1：** Mark Word 里存什么信息？32位和64位有什么区别？

你回答（hashCode、GC年龄、锁状态标志、线程ID）...

**追问2：** 锁升级过程中，Mark Word 是怎么变化的？从无锁到偏向锁到轻量级锁到重量级锁，每一步 Mark Word 改了什么？

你回答...

**追问3：** 对象的内存布局和锁有关系吗？为什么 synchronized 要基于对象头实现？

你回答（Monitor、对象头记录锁信息、避免每个对象都关联一个Monitor）...

**追问4：** 你知道什么是指针压缩吗？为什么要做指针压缩？

## 话题二：ConcurrentHashMap 原理（10分钟）

**面试官：ConcurrentHashMap 在 JDK 8 里是怎么实现线程安全的？**

你回答（CAS + synchronized + 分段锁演进）...

**追问1：** JDK 7 的分段锁和 JDK 8 的实现有什么区别？为什么要改？

你回答（Segment数组→Node数组+CAS+synchronized、锁粒度更细、去掉Segment层）...

**追问2：** JDK 8 的 ConcurrentHashMap，put 操作的具体流程是什么？

你回答（空表初始化→hash定位桶→桶为空CAS插入→桶非空synchronized插入→链表转红黑树）...

**追问3：** 它的 size() 方法是怎么实现的？为什么不直接用 baseCount？

你回答（baseCount + CounterCell数组、减少CAS竞争）...

**追问4：** ConcurrentHashMap 的扩容是怎么做的？多个线程能同时扩容吗？

你回答（transfer、ForwardingNode、多线程协助迁移）...

**追问5：** ConcurrentHashMap 能不能存 null key 或 null value？为什么？

你回答（不能、二义性问题、空指针歧义）...

## 话题四：Spring Bean 生命周期（10分钟）

**面试官：Spring Bean 的生命周期说一下，从实例化到销毁的全过程。**

你回答（实例化→属性填充→初始化→使用→销毁）...

**追问1：** BeanPostProcessor 在生命周期的哪个阶段介入的？before 和 after 分别在什么时候？

你回答（初始化前后、beforeInitialization 和 afterInitialization）...

**追问2：** @PostConstruct、InitializingBean 的 afterPropertiesSet、init-method，这三个的执行顺序是什么？

你回答（@PostConstruct → afterPropertiesSet → init-method）...

**追问3：** AOP 的代理对象是在生命周期的哪个阶段创建的？为什么不能更早？

你回答（afterInitialization阶段、需要等Bean初始化完成才能包代理）...

**追问4：** 如果一个 Bean 是循环依赖的，三级缓存是怎么解决的？@Async 的 Bean 能解决循环依赖吗？

你回答（三级缓存提前暴露ObjectFactory、@Async异步代理导致循环依赖失败、需要加@Lazy）...

**追问5：** prototype 作用域的 Bean 有循环依赖，Spring 能解决吗？为什么？

你回答（不能、prototype不缓存、每次都创建新实例）...

## 话题五：MySQL 事务隔离与 MVCC（12分钟）

**面试官：MySQL 的四个事务隔离级别分别解决了什么问题？**

你回答（读未提交、读已提交、可重复读、串行化、脏读/不可重复读/幻读）...

**追问1：** MySQL 的可重复读能完全解决幻读吗？什么场景下还会出现幻读？

你回答（快照读用MVCC解决、当前读需要间隙锁、快照读后更新可能触发幻读）...

**追问2：** MVCC 是怎么实现的？ReadView 是什么？在 RC 和 RR 下 ReadView 的生成时机有什么不同？

你回答（undo log版本链、ReadView事务ID列表、RC每次select生成、RR第一次select生成）...

**追问3：** 间隙锁是什么？给你一个场景：表里有 id=1,5,10,15，事务A执行 `SELECT * FROM t WHERE id BETWEEN 5 AND 10 FOR UPDATE`，会锁哪些间隙？

你回答（锁(1,5]、(5,10]、(10,15)的间隙）...

**追问4：** 两个事务并发，事务A加了间隙锁，事务B想插入一条数据到这个间隙里，会发生什么？

你回答（阻塞、等待间隙锁释放）...

**追问5：** 你在实际项目中遇到过死锁吗？是怎么排查和解决的？说说具体的死锁场景。

你回答（间隙锁交叉、show engine innodb status、加锁顺序一致）...

## 话题六：Redis 数据结构与底层实现（10分钟）

**面试官：Redis 的 ZSet 底层是怎么实现的？**

你回答（ziplist + skiplist、小数据用ziplist大数据用skiplist）...

**追问1：** ziplist 和 skiplist 的切换阈值是多少？为什么要设计两种结构？

你回答（128元素/64字节、ziplist省内存但查找慢、skiplist查找快但占内存）...

**追问2：** 跳表是怎么实现的？为什么 Redis 选跳表而不选红黑树？

你回答（多层链表、概率均衡、实现简单、范围查询友好、内存可调）...

**追问3：** Redis 7.0 的 ziplist 被换成了 listpack，你知道为什么吗？

你回答（ziplist的连锁更新问题、cascade update）...

**追问4：** 你在项目里用 ZSet 做过排行榜吗？如果排行榜有百万用户，怎么保证性能？

你回答（ZREVRANGE分页、只缓存TopN、冷数据异步同步）...

**追问5：** 如果两个人分数一样，排行榜怎么排序？ZSet 的 score 相同时怎么处理？

你回答（score相同时按member字典序、需要额外加时间戳区分）...

## 二面话题一：分布式锁方案对比（12分钟）

**面试官：你们项目里用分布式锁吗？用的什么方案？**

你回答（Redis Redisson / ZK / 数据库）...

**追问1：** Redis 分布式锁的底层原理是什么？SETNX 有什么问题？

你回答（SET key value NX EX、原子性、过期时间防死锁）...

**追问2：** 如果锁过期了但业务还没执行完，怎么办？Redisson 的 Watchdog 机制是怎么实现的？

你回答（看门狗定时续期、默认30秒、每10秒续到30秒）...

**追问3：** RedLock 算法了解吗？它解决什么问题？有什么争议？

你回答（多节点 majority、解决单点故障、争议：时钟漂移、GC暂停）...

**追问4：** Redis 分布式锁和 ZooKeeper 分布式锁，各自的优缺点？什么场景选哪个？

你回答（Redis性能高但非强一致、ZK强一致但性能低、CP vs AP）...

**追问5：** 如果让你设计一个银行转账场景的分布式锁，你会怎么设计？需要注意什么？

你回答（锁粒度、超时时间、可重入、死锁预防、幂等）...
