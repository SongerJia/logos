|序号|知识点|笔记写什么|重要度|
|---|---|---|---|
|P1.1|PostgreSQL vs MySQL 定位差异|PG = 学术派/标准SQL/可扩展性强 / OLAP友好；MySQL = 工程派/简单易用 / OLTP为主 / 生态成熟；一句话总结定位|🔥🔥 **面试开场必问**|
|P1.2|进程模型 vs 线程模型|PostgreSQL 每连接一个进程（fork模式）；MySQL 每连接一个线程；进程模型的优缺点（隔离性好 vs 开销大）；连接池对PG的重要性|核|
|P1.3|MVCC 实现差异|PG用 **XID + Multi-Version**（新旧版本共存同一表，VACUUM回收）；MySQL InnoDB 用 **Undo Log**（回滚段）；PG的元组膨胀(tuple bloating)问题|🔥🔥🔥 **深度对比考点**|
|P1.4|事务隔离级别实现差异|PG的Serializable用SSI(快照隔离验证)；READ COMMITTED 是默认（vs MySQL RR是默认）；不同隔离级别的行为差异案例|核|
