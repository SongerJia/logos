## 1. 反转链表（迭代 + 递归）

### 题目

给你单链表的头节点 `head`，反转链表，返回反转后的链表。

```
输入：1 → 2 → 3 → 4 → 5 → null
输出：5 → 4 → 3 → 2 → 1 → null
```

### 思路分析

**迭代法**：用三个指针 `prev`、`curr`、`next`，逐个节点翻转指向。

```
null ← 1    2 → 3 → 4 → 5 → null
       ↑    ↑
      prev curr

null ← 1 ← 2    3 → 4 → 5 → null
            ↑    ↑
           prev curr
```

**递归法**：递归到链表末尾，回溯时将下一个节点的 next 指向当前节点。

```
递归到底: 5 → null，返回节点5
回溯到4: 4.next.next = 4，即 5 → 4，然后 4.next = null
回溯到3: 3.next.next = 3，即 5 → 4 → 3，然后 3.next = null
...
```

### 代码实现

```java
// ========== 迭代法 ==========
public ListNode reverseList(ListNode head) {
    ListNode prev = null;
    ListNode curr = head;
    while (curr != null) {
        ListNode next = curr.next;  // 暂存下一个节点
        curr.next = prev;           // 翻转指向
        prev = curr;                // prev 前进
        curr = next;                // curr 前进
    }
    return prev;  // prev 是新的头节点
}

// ========== 递归法 ==========
public ListNode reverseListRecursive(ListNode head) {
    // base case：空链表或只有一个节点
    if (head == null || head.next == null) {
        return head;
    }
    // 递归反转后面的部分，返回新的头节点
    ListNode newHead = reverseListRecursive(head.next);
    // 关键：head.next 是反转后子链表的尾节点
    // head.next.next = head 把 head 接到尾部
    head.next.next = head;
    head.next = null;  // 断开原来的指向
    return newHead;
}
```

### 复杂度

| 方法 | 时间 | 空间 |
|------|------|------|
| 迭代 | O(n) | O(1) |
| 递归 | O(n) | O(n) 递归栈 |

### 面试追问

**Q：递归法 `head.next.next = head` 为什么不会出错？**

递归回到当前层时，`head.next` 还没被修改（还是原来的下一个节点），而 `head.next.next` 就是让下一个节点反向指向自己。执行完后 `head.next` 指向的节点的 next 已经指向了 head，此时再把 `head.next = null` 断开旧链接。

**Q：如果要求只反转 [m, n] 区间怎么办？**

找到第 m-1 个节点（pre），然后反转 m 到 n 的子链表，最后接回去。

```java
public ListNode reverseBetween(ListNode head, int m, int n) {
    ListNode dummy = new ListNode(0, head);
    ListNode pre = dummy;
    // 走到 m-1 位置
    for (int i = 1; i < m; i++) {
        pre = pre.next;
    }
    ListNode curr = pre.next;  // m 位置的节点
    // 反转 [m, n] 区间，头插法
    for (int i = 0; i < n - m; i++) {
        ListNode next = curr.next;
        curr.next = next.next;
        next.next = pre.next;
        pre.next = next;
    }
    return dummy.next;
}
```

## 2. 合并两个有序链表

### 题目

将两个升序链表合并为一个新的升序链表。

```
输入：1 → 2 → 4,  1 → 3 → 4
输出：1 → 1 → 2 → 3 → 4 → 4
```

### 思路分析

用**哨兵节点（dummy）**简化头节点处理，双指针比较，小的接入结果链表。

```
list1: 1 → 2 → 4
list2: 1 → 3 → 4
         ↓
dummy → 1 → 1 → 2 → 3 → 4 → 4
```

### 代码实现

```java
public ListNode mergeTwoLists(ListNode l1, ListNode l2) {
    ListNode dummy = new ListNode(0);  // 哨兵节点
    ListNode tail = dummy;             // 尾指针

    while (l1 != null && l2 != null) {
        if (l1.val <= l2.val) {
            tail.next = l1;
            l1 = l1.next;
        } else {
            tail.next = l2;
            l2 = l2.next;
        }
        tail = tail.next;
    }
    // 接上剩余部分
    tail.next = (l1 != null) ? l1 : l2;
    return dummy.next;
}
```

### 复杂度

- 时间：O(n + m)
- 空间：O(1)（原地合并，复用原节点）

### 面试追问

**Q：为什么用 dummy 节点？**

不用 dummy 的话，头节点需要特殊处理（第一次比较时确定头是谁），代码会有额外的 if-else。dummy 统一了处理逻辑，最后返回 `dummy.next` 即可。

**Q：递归写法？**

```java
public ListNode mergeTwoListsRecursive(ListNode l1, ListNode l2) {
    if (l1 == null) return l2;
    if (l2 == null) return l1;
    if (l1.val <= l2.val) {
        l1.next = mergeTwoListsRecursive(l1.next, l2);
        return l1;
    } else {
        l2.next = mergeTwoListsRecursive(l1, l2.next);
        return l2;
    }
}
```

## 3. 环形链表（检测环 + 找入环节点）

### 题目

给定链表头节点，判断是否有环。如果有环，找到入环节点。

```
输入：3 → 2 → 0 → -4
              ↑_____↓
输出：true，入环节点 val=2
```

### 思路分析

**检测环 — 快慢指针（Floyd 判圈法）**：

快指针每次走 2 步，慢指针每次走 1 步。如果有环，快慢指针一定会在环内相遇。如果无环，快指针先到 null。

```
慢: 3 → 2 → 0 → -4
快: 3 → 0 → 0 → -4 → 0 → -4 ...
              相遇点
```

**找入环节点 — 数学推导**：

设：
- 链表头到入环点距离 = a
- 入环点到相遇点距离 = b
- 相遇点到入环点距离 = c（环长 = b + c）

慢指针走了 `a + b` 步，快指针走了 `a + b + n(b+c)` 步（n≥1，快指针至少多走一圈）。

快指针速度是慢指针 2 倍：`2(a+b) = a + b + n(b+c)`

化简：`a = (n-1)(b+c) + c`

即：**从头节点走 a 步 = 从相遇点走 c 步 + (n-1) 圈**。

所以让一个指针从头开始，另一个从相遇点开始，都每次走 1 步，相遇的地方就是入环点！

### 代码实现

```java
// ========== 检测环 ==========
public boolean hasCycle(ListNode head) {
    ListNode slow = head, fast = head;
    while (fast != null && fast.next != null) {
        slow = slow.next;
        fast = fast.next.next;
        if (slow == fast) {
            return true;  // 相遇，有环
        }
    }
    return false;  // 快指针到 null，无环
}

// ========== 找入环节点 ==========
public ListNode detectCycle(ListNode head) {
    ListNode slow = head, fast = head;
    // 第一阶段：快慢指针找相遇点
    while (fast != null && fast.next != null) {
        slow = slow.next;
        fast = fast.next.next;
        if (slow == fast) {
            // 第二阶段：找入环点
            ListNode ptr = head;
            while (ptr != slow) {
                ptr = ptr.next;
                slow = slow.next;
            }
            return ptr;  // 相遇点就是入环点
        }
    }
    return null;  // 无环
}
```

### 复杂度

- 时间：O(n)
- 空间：O(1)

### 面试追问

**Q：为什么快慢指针一定会在环内相遇？**

快指针比慢指针快 1 步/次。进入环后，两者的距离每次缩小 1，最终一定会缩小到 0（相遇）。不会跳过，因为每步缩小 1，不会从正变负。

**Q：如果快指针走 3 步，慢指针走 1 步，还能相遇吗？**

不一定。如果环长是偶数，快慢可能永远跳过对方。差 2 步时，可能永远差 2 → 跳过。所以快走 2、慢走 1 是最安全的。

**Q：如果要求用 O(n) 空间怎么做？**

用 HashSet 记录访问过的节点，遇到已访问的节点就是入环点。简单但空间 O(n)。

## 4. 相交链表

### 题目

两个单链表可能在某个节点相交（交点后的部分完全相同），找到相交的起始节点。

```
A: 4 → 1 ↘
              8 → 4 → 5
B: 5 → 6 → 1 ↗
```

### 思路分析

**双指针走对方路法**：

两个指针分别从 A 和 B 出发，走到 null 时切换到对方的头。如果两链表长度不同，走完一遍后补齐长度差，第二次遍历必然在交点相遇。

```
ptrA: 4 → 1 → 8 → 4 → 5 → null → 切到B: 5 → 6 → 1 → 8(相遇!)
ptrB: 5 → 6 → 1 → 8 → 4 → 5 → null → 切到A: 4 → 1 → 8(相遇!)
```

原理：ptrA 走了 `a + c + b` 步，ptrB 走了 `b + c + a` 步，走的一样多，终点对齐。

### 代码实现

```java
public ListNode getIntersectionNode(ListNode headA, ListNode headB) {
    if (headA == null || headB == null) return null;

    ListNode pA = headA, pB = headB;
    // 最多走两圈，如果无交点则同时到 null
    while (pA != pB) {
        pA = (pA != null) ? pA.next : headB;  // A走完切到B
        pB = (pB != null) ? pB.next : headA;  // B走完切到A
    }
    return pA;  // 相交节点 或 null（无交点）
}
```

### 复杂度

- 时间：O(m + n)
- 空间：O(1)

### 面试追问

**Q：如果两个链表不相交，会死循环吗？**

不会。两指针各走 `m + n` 步后同时到达 null，`pA == pB == null` 退出循环。

**Q：为什么不能只遍历一次？**

因为两链表长度不同，从各自头出发同时走，第一次不会在交点对齐。走对方路可以天然补齐长度差。

## 5. 删除链表倒数第 N 个节点

### 题目

删除链表的倒数第 n 个节点，返回链表头。

```
输入：1 → 2 → 3 → 4 → 5, n = 2
输出：1 → 2 → 3 → 5（删除了倒数第2个，即4）
```

### 思路分析

**快慢指针 + dummy 节点**：

1. 快指针先走 n 步
2. 快慢指针同时走，快指针到 null 时，慢指针正好在倒数第 n+1 个节点（要删除节点的前一个）
3. `slow.next = slow.next.next` 删除

用 dummy 节点处理删除头节点的特殊情况。

```
dummy → 1 → 2 → 3 → 4 → 5 → null, n=2
                ↑              ↑
              slow            fast  （fast先走n步后）

        slow             fast
dummy → 1 → 2 → 3 → [4] → 5 → null
              ↑               ↑
            slow            fast  （同时走到底后）

slow.next = slow.next.next  删除节点4
```

### 代码实现

```java
public ListNode removeNthFromEnd(ListNode head, int n) {
    ListNode dummy = new ListNode(0, head);
    ListNode fast = dummy, slow = dummy;

    // 快指针先走 n 步（含dummy，所以实际走 n+1 的间隔）
    for (int i = 0; i < n; i++) {
        fast = fast.next;
    }

    // 快慢同时走，fast 到 null 时 slow 在待删节点前一个
    while (fast.next != null) {
        fast = fast.next;
        slow = slow.next;
    }

    // 删除
    slow.next = slow.next.next;
    return dummy.next;
}
```

### 复杂度

- 时间：O(n)
- 空间：O(1)

### 面试追问

**Q：为什么用 `fast.next != null` 而不是 `fast != null`？**

用 `fast.next` 判断可以让 slow 停在待删节点的前一个，方便执行 `slow.next = slow.next.next`。如果用 `fast != null`，slow 会停在待删节点本身，需要额外处理。

**Q：如果 n 大于链表长度怎么办？**

题目保证 n 有效。如果要防御性编程，可以在快指针走 n 步时检查是否已到 null。

## 6. 回文链表

### 题目

判断链表是否为回文。

```
输入：1 → 2 → 2 → 1
输出：true

输入：1 → 2 → 1
输出：true
```

### 思路分析

**最优解 — 找中点 + 反转后半部分 + 比较**：

1. 快慢指针找链表中点（慢指针到达中点）
2. 反转后半部分
3. 双指针比较前后两半
4. （可选）恢复链表

```
原始: 1 → 2 → 2 → 1
中点:     slow↑ (指向第二个2)
反转: 1 → 2    1 ← 2
比较: 1 vs 1 ✓, 2 vs 2 ✓ → true
```

### 代码实现

```java
public boolean isPalindrome(ListNode head) {
    if (head == null || head.next == null) return true;

    // 1. 快慢指针找中点（慢指针在左中点）
    ListNode slow = head, fast = head;
    while (fast.next != null && fast.next.next != null) {
        slow = slow.next;
        fast = fast.next.next;
    }
    // slow 在左半部分的末尾

    // 2. 反转后半部分
    ListNode secondHalf = reverseList(slow.next);

    // 3. 比较
    ListNode p1 = head, p2 = secondHalf;
    boolean result = true;
    while (p2 != null) {  // 后半部分长度 ≤ 前半部分
        if (p1.val != p2.val) {
            result = false;
            break;
        }
        p1 = p1.next;
        p2 = p2.next;
    }

    // 4. （可选）恢复链表
    // slow.next = reverseList(secondHalf);

    return result;
}

private ListNode reverseList(ListNode head) {
    ListNode prev = null, curr = head;
    while (curr != null) {
        ListNode next = curr.next;
        curr.next = prev;
        prev = curr;
        curr = next;
    }
    return prev;
}
```

### 复杂度

- 时间：O(n)
- 空间：O(1)

### 面试追问

**Q：为什么不用栈？**

用栈可以：遍历一遍入栈，再遍历一遍和栈顶比较。但空间 O(n)，不满足进阶要求 O(1)。

**Q：找中点时为什么用 `fast.next != null && fast.next.next != null`？**

这样可以保证慢指针停在左中点（偶数链表时），方便后续反转和比较。如果用 `fast != null && fast.next != null`，慢指针会停在右中点，不影响正确性但恢复时要注意。

## 7. 复制带随机指针的链表

### 题目

深拷贝一个带 random 指针的链表。random 可以指向任意节点或 null。

```
原始: 7 → 13 → 11 → 10 → 1
       ↓     ↓     ↓     ↓     ↓
      null  7     1     11    7
```

### 思路分析

**方法一：HashMap（两次遍历）**

第一遍：创建所有新节点，存入 `Map<原节点, 新节点>`。
第二遍：根据原节点的 next 和 random，从 Map 取对应新节点连接。

**方法二：原地插入（三次遍历，O(1) 空间）**

1. 在每个原节点后插入它的复制：A → A' → B → B' → C → C'
2. 设置 random：`copy.random = original.random.next`
3. 拆分：分离出复制链表

```
步骤1: 7 → 7' → 13 → 13' → 11 → 11' → 10 → 10' → 1 → 1'
步骤2: 7'.random = 7.random.next (如果7.random存在)
步骤3: 分离: 7 → 13 → 11 → 10 → 1  和  7' → 13' → 11' → 10' → 1'
```

### 代码实现

```java
// ========== 方法一：HashMap ==========
public Node copyRandomList(Node head) {
    if (head == null) return null;

    Map<Node, Node> map = new HashMap<>();

    // 第一遍：创建所有新节点
    Node curr = head;
    while (curr != null) {
        map.put(curr, new Node(curr.val));
        curr = curr.next;
    }

    // 第二遍：连接 next 和 random
    curr = head;
    while (curr != null) {
        Node copy = map.get(curr);
        copy.next = map.get(curr.next);      // null 也安全
        copy.random = map.get(curr.random);
        curr = curr.next;
    }

    return map.get(head);
}

// ========== 方法二：原地插入 O(1) 空间 ==========
public Node copyRandomListO1(Node head) {
    if (head == null) return null;

    // 步骤1：在每个节点后插入复制节点
    Node curr = head;
    while (curr != null) {
        Node copy = new Node(curr.val);
        copy.next = curr.next;
        curr.next = copy;
        curr = copy.next;
    }

    // 步骤2：设置 random
    curr = head;
    while (curr != null) {
        if (curr.random != null) {
            curr.next.random = curr.random.next;
        }
        curr = curr.next.next;
    }

    // 步骤3：拆分
    Node dummy = new Node(0);
    Node copyCurr = dummy;
    curr = head;
    while (curr != null) {
        copyCurr.next = curr.next;    // 取出复制节点
        curr.next = curr.next.next;   // 恢复原链表
        copyCurr = copyCurr.next;
        curr = curr.next;
    }

    return dummy.next;
}
```

### 复杂度

| 方法 | 时间 | 空间 |
|------|------|------|
| HashMap | O(n) | O(n) |
| 原地插入 | O(n) | O(1) |

### 面试追问

**Q：原地插入法步骤2为什么 `curr.next.random = curr.random.next`？**

原节点 curr 的后面就是它的复制 curr.next。curr.random 是原链表中 random 指向的节点，而 `curr.random.next` 就是那个原节点的复制，正是复制节点应该指向的 random。

**Q：HashMap 方法中 `map.get(null)` 返回什么？**

返回 null，所以不需要额外判断 next 和 random 是否为 null。

## 8. 两两交换链表中的节点

### 题目

两两交换相邻节点，返回交换后的链表。

```
输入：1 → 2 → 3 → 4
输出：2 → 1 → 4 → 3
```

### 思路分析

用 dummy 节点 + 迭代。每次处理一对节点：prev → a → b → ...

```
dummy → 1 → 2 → 3 → 4
        a   b
prev →

交换后: dummy → 2 → 1 → 3 → 4
                prev→ a   b
```

三步操作：
1. `prev.next = b`（prev 指向 b）
2. `a.next = b.next`（a 指向下一对）
3. `b.next = a`（b 指向 a）

### 代码实现

```java
public ListNode swapPairs(ListNode head) {
    ListNode dummy = new ListNode(0, head);
    ListNode prev = dummy;

    while (prev.next != null && prev.next.next != null) {
        ListNode a = prev.next;
        ListNode b = prev.next.next;

        // 交换
        prev.next = b;       // prev → b
        a.next = b.next;      // a → 下一对
        b.next = a;           // b → a

        prev = a;  // prev 移到交换后的第二个节点
    }

    return dummy.next;
}
```

### 复杂度

- 时间：O(n)
- 空间：O(1)

### 面试追问

**Q：递归写法？**

```java
public ListNode swapPairsRecursive(ListNode head) {
    if (head == null || head.next == null) return head;

    ListNode newHead = head.next;  // 第二个节点变成新的头
    head.next = swapPairsRecursive(newHead.next);  // 递归处理后面的
    newHead.next = head;  // 新头指向原来的头

    return newHead;
}
```

递归更简洁，但空间 O(n)。

## 9. K 个一组反转链表

### 题目

每 k 个节点一组进行反转，不足 k 个的不反转。

```
输入：1 → 2 → 3 → 4 → 5, k = 2
输出：2 → 1 → 4 → 3 → 5
```

### 思路分析

1. 先数 k 个节点，如果能凑够 k 个，就反转这 k 个
2. 反转后连接到前面的结果上
3. 如果不够 k 个，直接接上剩余部分

```
第一组: [1 → 2] → 3 → 4 → 5  →反转→  2 → 1  连到 3 → 4 → 5
第二组: [3 → 4] → 5         →反转→  4 → 3  连到 5
剩余:   5 (不足k个) → 不反转
结果:   2 → 1 → 4 → 3 → 5
```

### 代码实现

```java
public ListNode reverseKGroup(ListNode head, int k) {
    ListNode dummy = new ListNode(0, head);
    ListNode prevGroupEnd = dummy;

    while (true) {
        // 1. 检查是否还有 k 个节点
        ListNode groupEnd = prevGroupEnd;
        for (int i = 0; i < k; i++) {
            groupEnd = groupEnd.next;
            if (groupEnd == null) {
                return dummy.next;  // 不足 k 个，结束
            }
        }

        // 2. 记录下一组的起点
        ListNode nextGroupStart = groupEnd.next;
        // 3. 记录当前组的起点（反转后会变成这组的尾）
        ListNode groupStart = prevGroupEnd.next;

        // 4. 反转当前组（先断开 groupEnd.next）
        groupEnd.next = null;
        reverseList(groupStart);

        // 5. 连接
        prevGroupEnd.next = groupEnd;      // 前一组的尾 → 反转后的头
        groupStart.next = nextGroupStart;  // 反转后的尾 → 下一组的头

        // 6. 更新 prevGroupEnd
        prevGroupEnd = groupStart;
    }
}

private ListNode reverseList(ListNode head) {
    ListNode prev = null, curr = head;
    while (curr != null) {
        ListNode next = curr.next;
        curr.next = prev;
        prev = curr;
        curr = next;
    }
    return prev;
}
```

### 复杂度

- 时间：O(n)（每个节点最多被访问 2 次）
- 空间：O(1)

### 面试追问

**Q：为什么先要 `groupEnd.next = null` 断开？**

因为 `reverseList` 是反转整个链表的函数，如果不断开，会把后面的节点也反转了。反转后再重新连接。

**Q：这题和反转链表 II（区间反转）的区别？**

区间反转只反转一次连续区间。K 个一组是多次反转，每次 k 个，需要循环处理。

## 10. LRU 缓存（链表 + HashMap）

### 题目

设计并实现 LRU（最近最少使用）缓存。`get` 和 `put` 都要 O(1)。

```
LRUCache cache = new LRUCache(2);
cache.put(1, 1);
cache.put(2, 2);
cache.get(1);       // 返回 1
cache.put(3, 3);    // 淘汰 key=2（最久未用）
cache.get(2);       // 返回 -1
cache.put(4, 4);    // 淘汰 key=1
cache.get(1);       // 返回 -1
cache.get(3);       // 返回 3
cache.get(4);       // 返回 4
```

### 思路分析

**核心数据结构：双向链表 + HashMap**

- **HashMap**：O(1) 查找 key 对应的节点
- **双向链表**：O(1) 维护访问顺序（最近使用的在头部，最久未用的在尾部）

**为什么用双向链表而不是单向？**

删除节点时需要知道前驱节点。单向链表找前驱要 O(n)，双向链表通过 `prev` 指针 O(1)。

```
HashMap: {key1: Node1, key2: Node2, ...}

双向链表:
HEAD ↔ Node1(key1) ↔ Node2(key2) ↔ ... ↔ TAIL
       ↑ 最近使用                最久未用 ↑
```

### 代码实现

```java
class LRUCache {
    // 双向链表节点
    private class DLinkedNode {
        int key;
        int value;
        DLinkedNode prev;
        DLinkedNode next;
        DLinkedNode() {}
        DLinkedNode(int key, int value) { this.key = key; this.value = value; }
    }

    private int capacity;
    private int size;
    private Map<Integer, DLinkedNode> cache = new HashMap<>();
    private DLinkedNode head, tail;  // 虚拟头尾节点

    public LRUCache(int capacity) {
        this.capacity = capacity;
        this.size = 0;
        head = new DLinkedNode();
        tail = new DLinkedNode();
        head.next = tail;
        tail.prev = head;
    }

    public int get(int key) {
        DLinkedNode node = cache.get(key);
        if (node == null) return -1;
        // 访问后移到头部（最近使用）
        moveToHead(node);
        return node.value;
    }

    public void put(int key, int value) {
        DLinkedNode node = cache.get(key);
        if (node != null) {
            // 已存在，更新值并移到头部
            node.value = value;
            moveToHead(node);
        } else {
            // 新节点
            DLinkedNode newNode = new DLinkedNode(key, value);
            cache.put(key, newNode);
            addToHead(newNode);
            size++;
            // 超容量，淘汰尾部
            if (size > capacity) {
                DLinkedNode removed = removeTail();
                cache.remove(removed.key);  // 别忘了从 HashMap 删除
                size--;
            }
        }
    }

    // ===== 双向链表操作 =====

    private void addToHead(DLinkedNode node) {
        node.prev = head;
        node.next = head.next;
        head.next.prev = node;
        head.next = node;
    }

    private void removeNode(DLinkedNode node) {
        node.prev.next = node.next;
        node.next.prev = node.prev;
    }

    private void moveToHead(DLinkedNode node) {
        removeNode(node);
        addToHead(node);
    }

    private DLinkedNode removeTail() {
        DLinkedNode res = tail.prev;
        removeNode(res);
        return res;
    }
}
```

### 复杂度

- `get`：O(1)
- `put`：O(1)

### 面试追问

**Q：为什么用虚拟头尾节点（dummy head/tail）？**

避免空指针判断。不用虚拟节点的话，添加第一个节点、删除最后一个节点都要特判 `head == null`。有了虚拟节点，所有节点都在 head 和 tail 之间，操作统一。

**Q：Java 的 LinkedHashMap 怎么实现 LRU？**

```java
class LRUCacheByLinkedHashMap extends LinkedHashMap<Integer, Integer> {
    private int capacity;

    public LRUCacheByLinkedHashMap(int capacity) {
        super(capacity, 0.75f, true);  // accessOrder=true 按访问顺序排序
        this.capacity = capacity;
    }

    @Override
    protected boolean removeEldestEntry(Map.Entry<Integer, Integer> eldest) {
        return size() > capacity;  // 超容量时自动淘汰最老的
    }
}
```

LinkedHashMap 底层就是 HashMap + 双向链表，`accessOrder=true` 时访问后自动移到链表尾部。

**Q：LRU 和 LFU 的区别？**

- LRU（Least Recently Used）：淘汰最久没用的。只看时间。
- LFU（Least Frequently Used）：淘汰使用次数最少的。看频率。
- LRU 的问题：偶尔访问一次的冷数据也会被缓存住，热数据可能被挤出去。
- LFU 的问题：早期高频数据后来不再访问，但频率高不会被淘汰。

## 11. 合并 K 个有序链表

### 题目

合并 K 个升序链表，返回合并后的链表。

### 思路分析

**方法一：小顶堆（PriorityQueue）**

把每个链表的头节点放入小顶堆，每次弹出最小的，然后把它的 next 放入堆。时间 O(N log K)，N 是总节点数。

**方法二：分治合并**

两两合并，类似归并排序的合并过程。时间也是 O(N log K)。

```
lists = [L1, L2, L3, L4]
第一轮: merge(L1,L2), merge(L3,L4) → [L12, L34]
第二轮: merge(L12, L34) → [L1234]
```

### 代码实现

```java
// ========== 方法一：小顶堆 ==========
public ListNode mergeKLists(ListNode[] lists) {
    if (lists == null || lists.length == 0) return null;

    // 小顶堆：按节点值排序
    PriorityQueue<ListNode> minHeap = new PriorityQueue<>((a, b) -> a.val - b.val);

    // 每个链表的头节点入堆
    for (ListNode list : lists) {
        if (list != null) {
            minHeap.offer(list);
        }
    }

    ListNode dummy = new ListNode(0);
    ListNode tail = dummy;

    while (!minHeap.isEmpty()) {
        ListNode min = minHeap.poll();    // 取出最小节点
        tail.next = min;
        tail = tail.next;
        if (min.next != null) {
            minHeap.offer(min.next);     // 放入后继节点
        }
    }

    return dummy.next;
}

// ========== 方法二：分治合并 ==========
public ListNode mergeKListsDivide(ListNode[] lists) {
    if (lists == null || lists.length == 0) return null;
    return merge(lists, 0, lists.length - 1);
}

private ListNode merge(ListNode[] lists, int left, int right) {
    if (left == right) return lists[left];
    int mid = left + (right - left) / 2;
    ListNode l = merge(lists, left, mid);
    ListNode r = merge(lists, mid + 1, right);
    return mergeTwoLists(l, r);
}

private ListNode mergeTwoLists(ListNode l1, ListNode l2) {
    ListNode dummy = new ListNode(0);
    ListNode tail = dummy;
    while (l1 != null && l2 != null) {
        if (l1.val <= l2.val) {
            tail.next = l1; l1 = l1.next;
        } else {
            tail.next = l2; l2 = l2.next;
        }
        tail = tail.next;
    }
    tail.next = (l1 != null) ? l1 : l2;
    return dummy.next;
}
```

### 复杂度

| 方法 | 时间 | 空间 |
|------|------|------|
| 小顶堆 | O(N log K) | O(K) 堆空间 |
| 分治合并 | O(N log K) | O(log K) 递归栈 |

### 面试追问

**Q：小顶堆的时间为什么是 O(N log K)？**

每个节点入堆出堆各一次，每次堆操作 O(log K)，共 N 个节点，所以 O(N log K)。

**Q：分治法和堆方法哪个更好？**

分治法空间更优（O(log K) 递归栈 vs O(K) 堆），实际中两者性能接近，面试中分治法更常考。

## 12. 排序链表

### 题目

对链表进行排序，要求 O(n log n) 时间，O(1) 空间。

```
输入：4 → 2 → 1 → 3
输出：1 → 2 → 3 → 4
```

### 思路分析

**归并排序（自底向上）**：

1. 用快慢指针找中点，将链表一分为二
2. 递归排序左半和右半
3. 合并两个有序链表

自底向上的迭代法可以做到 O(1) 空间，但面试中递归法更常写。

```
4 → 2 → 1 → 3
    ↓ 找中点
4 → 2    |    1 → 3
    ↓ 分别排序
2 → 4    |    1 → 3
    ↓ 合并
1 → 2 → 3 → 4
```

### 代码实现

```java
public ListNode sortList(ListNode head) {
    // base case：空或只有一个节点
    if (head == null || head.next == null) {
        return head;
    }

    // 1. 快慢指针找中点（断开前后两半）
    ListNode slow = head, fast = head.next;
    while (fast != null && fast.next != null) {
        slow = slow.next;
        fast = fast.next.next;
    }
    ListNode mid = slow.next;
    slow.next = null;  // 断开

    // 2. 递归排序两半
    ListNode left = sortList(head);
    ListNode right = sortList(mid);

    // 3. 合并
    return mergeTwoLists(left, right);
}

private ListNode mergeTwoLists(ListNode l1, ListNode l2) {
    ListNode dummy = new ListNode(0);
    ListNode tail = dummy;
    while (l1 != null && l2 != null) {
        if (l1.val <= l2.val) {
            tail.next = l1; l1 = l1.next;
        } else {
            tail.next = l2; l2 = l2.next;
        }
        tail = tail.next;
    }
    tail.next = (l1 != null) ? l1 : l2;
    return dummy.next;
}
```

### 复杂度

| 方法 | 时间 | 空间 |
|------|------|------|
| 递归归并 | O(n log n) | O(log n) 递归栈 |
| 迭代归并 | O(n log n) | O(1) |

### 面试追问

**Q：为什么找中点时 `fast = head.next` 而不是 `fast = head`？**

如果从 `fast = head` 开始，当链表有偶数个节点时，slow 会停在中间偏右。断开后左半会比右半多一个节点，不影响正确性但可能多一层递归。从 `fast = head.next` 开始，slow 停在左中点，左半 ≤ 右半，更均匀。

**Q：能用快排吗？**

链表可以用快排，但不如归并排序适合。归并排序天然适合链表（不需要随机访问），且是稳定排序。快排需要随机访问来选 pivot，链表上性能不好。

## 13. 二叉树遍历（前/中/后/层序）

### 题目

实现二叉树的前序、中序、后序遍历（递归 + 迭代），以及层序遍历。

### 思路分析

**递归遍历**最简单，三种顺序只是输出位置不同：

```
前序:  根 → 左 → 右    （先访问根）
中序:  左 → 根 → 右    （根在中间）
后序:  左 → 右 → 根    （最后访问根）
```

**迭代遍历**用栈模拟递归：

- 前序：入栈顺序「右左」，出栈自然「左右根」中的根先出
- 中序：一路向左压栈，弹出时访问，再转向右
- 后序：前序变体「根右左」→ 反转 →「左右根」

**层序遍历**用队列（BFS）。

```
        1
       / \
      2   3
     / \   \
    4   5   6

前序: 1 2 4 5 3 6
中序: 4 2 5 1 3 6
后序: 4 5 2 6 3 1
层序: [[1], [2, 3], [4, 5, 6]]
```

### 代码实现

```java
// ========== 递归 ==========

// 前序遍历（递归）
public List<Integer> preorderTraversal(TreeNode root) {
    List<Integer> result = new ArrayList<>();
    preorder(root, result);
    return result;
}
private void preorder(TreeNode node, List<Integer> result) {
    if (node == null) return;
    result.add(node.val);        // 根
    preorder(node.left, result);  // 左
    preorder(node.right, result); // 右
}

// 中序遍历（递归）
public List<Integer> inorderTraversal(TreeNode root) {
    List<Integer> result = new ArrayList<>();
    inorder(root, result);
    return result;
}
private void inorder(TreeNode node, List<Integer> result) {
    if (node == null) return;
    inorder(node.left, result);   // 左
    result.add(node.val);         // 根
    inorder(node.right, result);  // 右
}

// 后序遍历（递归）
public List<Integer> postorderTraversal(TreeNode root) {
    List<Integer> result = new ArrayList<>();
    postorder(root, result);
    return result;
}
private void postorder(TreeNode node, List<Integer> result) {
    if (node == null) return;
    postorder(node.left, result);   // 左
    postorder(node.right, result);  // 右
    result.add(node.val);           // 根
}

// ========== 迭代 ==========

// 前序遍历（迭代）
public List<Integer> preorderIterative(TreeNode root) {
    List<Integer> result = new ArrayList<>();
    if (root == null) return result;

    Deque<TreeNode> stack = new ArrayDeque<>();
    stack.push(root);

    while (!stack.isEmpty()) {
        TreeNode node = stack.pop();
        result.add(node.val);
        // 先压右再压左，出栈顺序才是左先右后
        if (node.right != null) stack.push(node.right);
        if (node.left != null) stack.push(node.left);
    }
    return result;
}

// 中序遍历（迭代）
public List<Integer> inorderIterative(TreeNode root) {
    List<Integer> result = new ArrayList<>();
    Deque<TreeNode> stack = new ArrayDeque<>();
    TreeNode curr = root;

    while (curr != null || !stack.isEmpty()) {
        // 一路向左压栈
        while (curr != null) {
            stack.push(curr);
            curr = curr.left;
        }
        // 弹出访问
        curr = stack.pop();
        result.add(curr.val);
        // 转向右子树
        curr = curr.right;
    }
    return result;
}

// 后序遍历（迭代 — 反转法）
public List<Integer> postorderIterative(TreeNode root) {
    LinkedList<Integer> result = new LinkedList<>();
    if (root == null) return result;

    Deque<TreeNode> stack = new ArrayDeque<>();
    stack.push(root);

    while (!stack.isEmpty()) {
        TreeNode node = stack.pop();
        result.addFirst(node.val);  // 头插法，相当于最后反转
        // 先左后右，出栈顺序是右先左后，头插后变成左右根
        if (node.left != null) stack.push(node.left);
        if (node.right != null) stack.push(node.right);
    }
    return result;
}
```

### 复杂度

| 方法 | 时间 | 空间 |
|------|------|------|
| 递归 | O(n) | O(h) 递归栈 |
| 迭代 | O(n) | O(h) 显式栈 |

h 为树高，最坏 O(n)，平均 O(log n)。

### 面试追问

**Q：迭代后序遍历的「反转法」是什么原理？**

前序遍历是「根左右」，如果把左右入栈顺序对调，变成「根右左」。再把这个结果反转，就得到「左右根」即后序遍历。`addFirst` 相当于在头部插入，天然反转。

**Q：Morris 遍历是什么？**

Morris 遍历利用叶子节点的空指针，将空闲的 right 指向中序后继，实现 O(1) 空间的中序遍历。代价是会临时修改树结构（遍历完后恢复）。面试中了解即可，一般不要求手写。

```java
// Morris 中序遍历 O(1) 空间
public List<Integer> inorderMorris(TreeNode root) {
    List<Integer> result = new ArrayList<>();
    TreeNode curr = root;
    while (curr != null) {
        if (curr.left == null) {
            result.add(curr.val);
            curr = curr.right;
        } else {
            // 找左子树的最右节点（中序前驱）
            TreeNode prev = curr.left;
            while (prev.right != null && prev.right != curr) {
                prev = prev.right;
            }
            if (prev.right == null) {
                prev.right = curr;  // 建线索
                curr = curr.left;
            } else {
                prev.right = null;  // 恢复
                result.add(curr.val);
                curr = curr.right;
            }
        }
    }
    return result;
}
```

## 14. 翻转二叉树

### 题目

翻转一棵二叉树（镜像翻转）。

```
输入:       4                 输出:       4
           / \                          / \
          2   7                        7   2
         / \ / \                      / \ / \
        1  3 6  9                    9  6 3  1
```

### 思路分析

递归交换每个节点的左右子树。这是一道非常简单的题，但因为 Google 曾用它面试而出了名。

### 代码实现

```java
public TreeNode invertTree(TreeNode root) {
    if (root == null) return null;

    // 交换左右子树
    TreeNode temp = root.left;
    root.left = root.right;
    root.right = temp;

    // 递归翻转
    invertTree(root.left);
    invertTree(root.right);

    return root;
}
```

## 15. 二叉树的最大深度

### 题目

求二叉树的最大深度。

### 代码实现

```java
// 递归
public int maxDepth(TreeNode root) {
    if (root == null) return 0;
    return 1 + Math.max(maxDepth(root.left), maxDepth(root.right));
}

// BFS 层序
public int maxDepthBFS(TreeNode root) {
    if (root == null) return 0;
    Queue<TreeNode> queue = new LinkedList<>();
    queue.offer(root);
    int depth = 0;
    while (!queue.isEmpty()) {
        int size = queue.size();
        depth++;
        for (int i = 0; i < size; i++) {
            TreeNode node = queue.poll();
            if (node.left != null) queue.offer(node.left);
            if (node.right != null) queue.offer(node.right);
        }
    }
    return depth;
}
```

### 复杂度

- 递归：时间 O(n)，空间 O(h)
- BFS：时间 O(n)，空间 O(w)（w 为最大宽度）

### 面试追问

**Q：最小深度怎么求？**

最小深度 = 根到最近叶子节点的距离。

```java
public int minDepth(TreeNode root) {
    if (root == null) return 0;
    // 如果左子树为空，只看右子树
    if (root.left == null) return 1 + minDepth(root.right);
    // 如果右子树为空，只看左子树
    if (root.right == null) return 1 + minDepth(root.left);
    // 两边都不为空，取较小
    return 1 + Math.min(minDepth(root.left), minDepth(root.right));
}
```

注意不能直接 `1 + Math.min(min(left), min(right))`，因为如果一个子树为空，那个方向没有叶子，不能算作路径。

## 16. 对称二叉树

### 题目

判断二叉树是否是镜像对称的。

```
输入:     1              输出: true
         / \
        2   2
       / \ / \
      3  4 4  3
```

### 思路分析

比较左右子树是否互为镜像：左的左 == 右的右，左的右 == 右的左。

```
    root
   /    \
  L      R      ← 比较 L 和 R 是否对称
 / \    / \
LL LR RL RR     ← LL==RR, LR==RL
```

### 代码实现

```java
// 递归
public boolean isSymmetric(TreeNode root) {
    if (root == null) return true;
    return isMirror(root.left, root.right);
}

private boolean isMirror(TreeNode left, TreeNode right) {
    // 都为空，对称
    if (left == null && right == null) return true;
    // 只有一个为空，不对称
    if (left == null || right == null) return false;
    // 值相等，且左右交叉对称
    return left.val == right.val
        && isMirror(left.left, right.right)
        && isMirror(left.right, right.left);
}

// 迭代（BFS）
public boolean isSymmetricIterative(TreeNode root) {
    if (root == null) return true;
    Queue<TreeNode> queue = new LinkedList<>();
    queue.offer(root.left);
    queue.offer(root.right);

    while (!queue.isEmpty()) {
        TreeNode left = queue.poll();
        TreeNode right = queue.poll();

        if (left == null && right == null) continue;
        if (left == null || right == null) return false;
        if (left.val != right.val) return false;

        // 注意入队顺序：左的左 vs 右的右，左的右 vs 右的左
        queue.offer(left.left);
        queue.offer(right.right);
        queue.offer(left.right);
        queue.offer(right.left);
    }
    return true;
}
```

### 复杂度

- 时间：O(n)
- 空间：O(h) 递归 / O(n) BFS队列

## 17. 二叉树的直径

### 题目

二叉树的直径 = 任意两节点之间路径的最大长度（边数）。

```
输入:     1
         / \
        2   3
       / \
      4   5
输出: 3（路径 4 → 2 → 1 → 3 或 5 → 2 → 1 → 3，3条边）
```

### 思路分析

直径 = 经过某节点的「左子树最大深度 + 右子树最大深度」。

在计算深度的过程中，维护一个全局最大值。

```
对于节点1：左深度=2，右深度=1，经过1的路径=2+1=3
对于节点2：左深度=1，右深度=1，经过2的路径=1+1=2
最大值为3
```

### 代码实现

```java
private int maxDiameter = 0;

public int diameterOfBinaryTree(TreeNode root) {
    maxDepth(root);
    return maxDiameter;
}

private int maxDepth(TreeNode root) {
    if (root == null) return 0;

    int leftDepth = maxDepth(root.left);
    int rightDepth = maxDepth(root.right);

    // 经过当前节点的最长路径 = 左深度 + 右深度
    maxDiameter = Math.max(maxDiameter, leftDepth + rightDepth);

    // 返回当前节点的深度
    return 1 + Math.max(leftDepth, rightDepth);
}
```

### 复杂度

- 时间：O(n)
- 空间：O(h)

### 面试追问

**Q：直径是节点数还是边数？**

LeetCode 定义为边数。如果是节点数，就把 `leftDepth + rightDepth` 改成 `leftDepth + rightDepth + 1`。

**Q：为什么不用对每个节点都重新算深度？**

那样是 O(n²)。我们用一个全局变量在计算深度的过程中顺便更新最大直径，保证 O(n)。

## 18. 验证二叉搜索树

### 题目

判断给定的二叉树是否是有效的二叉搜索树（BST）。

BST 性质：左子树所有节点 < 根 < 右子树所有节点。

### 思路分析

**方法一：递归 + 范围约束**

每个节点的值必须在 `(min, max)` 范围内。左子树上限是当前值，右子树下限是当前值。

```
        5
       / \
      1   4
         / \
        3   6

节点5: (-∞, +∞) ✓
节点1: (-∞, 5) ✓
节点4: (5, +∞) ✓
节点3: (5, 4) ✗ ← 3 < 5，不在范围内 → false
```

**方法二：中序遍历必须递增**

BST 的中序遍历是严格递增序列。

### 代码实现

```java
// 方法一：递归 + 范围约束
public boolean isValidBST(TreeNode root) {
    return validate(root, null, null);
}

private boolean validate(TreeNode node, Integer min, Integer max) {
    if (node == null) return true;

    // 检查当前节点是否在范围内
    if (min != null && node.val <= min) return false;
    if (max != null && node.val >= max) return false;

    // 左子树：上限变为当前值
    // 右子树：下限变为当前值
    return validate(node.left, min, node.val)
        && validate(node.right, node.val, max);
}

// 方法二：中序遍历
public boolean isValidBSTInorder(TreeNode root) {
    TreeNode prev = null;
    Deque<TreeNode> stack = new ArrayDeque<>();
    TreeNode curr = root;

    while (curr != null || !stack.isEmpty()) {
        while (curr != null) {
            stack.push(curr);
            curr = curr.left;
        }
        curr = stack.pop();
        // 中序遍历：前一个值必须小于当前值
        if (prev != null && curr.val <= prev.val) {
            return false;
        }
        prev = curr;
        curr = curr.right;
    }
    return true;
}
```

### 复杂度

- 时间：O(n)
- 空间：O(h)

### 面试追问

**Q：为什么用 `Integer` 而不是 `int`？**

因为需要表示 `null`（即没有约束）。如果用 `int` 的极值 `Integer.MIN_VALUE` / `Integer.MAX_VALUE`，当节点值恰好等于极值时会出 bug。

**Q：为什么 BST 中序遍历是递增的？**

中序遍历：左 → 根 → 右。在 BST 中左子树所有值 < 根 < 右子树所有值，所以中序遍历的顺序就是值从小到大的顺序。

## 19. 二叉树的最近公共祖先

### 题目

找到两个节点 p 和 q 在二叉树中的最近公共祖先（LCA）。

```
输入:        3
           /   \
          5     1
         / \   / \
        6   2 0   8
           / \
          7   4
p = 5, q = 1 → 输出: 3
p = 5, q = 4 → 输出: 5
```

### 思路分析

**递归思路**：

1. 如果当前节点是 null 或等于 p 或 q，返回当前节点
2. 递归左子树和右子树
3. 如果左右都非 null，说明 p 和 q 分别在两侧，当前节点就是 LCA
4. 如果只有一边非 null，返回那一边

```
找 p=5, q=4 的 LCA:
节点3: 左=5(找到p), 右=null → 返回5
节点5: 左=null, 右=4(找到q) → 但先看left
  节点6: 返回null
  节点2: 左=7(null), 右=4(找到q) → 返回4
  节点5: left=null, right=4 → 返回4
节点3: left=5, right=1(null)... 

等等，让我重新想。

实际上递归逻辑是：
节点5: left=找p/q在左子树, right=找p/q在右子树
  节点6: 返回null
  节点2: 
    节点7: 返回null
    节点4: 返回4(等于q)
    节点2: left=null, right=4 → 返回4
  节点5: left=null, right=4 → 返回4
不对，节点5等于p，应该直接返回5！

修正：
节点5: 等于p → 直接返回5
节点3: left=5(p找到了), right=找右子树
  右子树中没有p也没有q → 返回null
节点3: left=5, right=null → 返回5
最终LCA = 5
```

### 代码实现

```java
public TreeNode lowestCommonAncestor(TreeNode root, TreeNode p, TreeNode q) {
    // base case：当前节点为空，或者就是p或q
    if (root == null || root == p || root == q) {
        return root;
    }

    // 递归左右子树
    TreeNode left = lowestCommonAncestor(root.left, p, q);
    TreeNode right = lowestCommonAncestor(root.right, p, q);

    // 情况1：左右都找到了，说明 p 和 q 分布在两侧，root 就是 LCA
    if (left != null && right != null) {
        return root;
    }

    // 情况2：只有一边找到了，返回那一边
    return (left != null) ? left : right;
}
```

### 复杂度

- 时间：O(n)
- 空间：O(h)

### 面试追问

**Q：如果 p 是 q 的祖先怎么办？**

比如 p=5, q=4。递归到节点 5 时，直接返回 5（因为 `root == p`）。不会继续往下找 4。但结果是正确的——p 就是 LCA。

**Q：如果是 BST 怎么优化？**

BST 中可以利用性质：如果 p 和 q 的值都小于 root，LCA 在左子树；都大于则在右子树；一左一右则 root 就是 LCA。

```java
public TreeNode lowestCommonAncestorBST(TreeNode root, TreeNode p, TreeNode q) {
    while (root != null) {
        if (root.val > p.val && root.val > q.val) {
            root = root.left;   // 都在左子树
        } else if (root.val < p.val && root.val < q.val) {
            root = root.right;  // 都在右子树
        } else {
            return root;  // 分叉点就是 LCA
        }
    }
    return null;
}
```

时间 O(h)，空间 O(1)。

## 20. 二叉树的层序遍历

### 题目

层序遍历二叉树，返回按层分组的节点值列表。

```
输入:     3
         / \
        9  20
          /  \
         15   7
输出: [[3], [9, 20], [15, 7]]
```

### 思路分析

BFS + 队列。关键是每一层要记录队列大小，按层处理。

```
队列: [3] → 处理1个 → [9, 20] → 处理2个 → [15, 7] → 处理2个
每层: [3]      [9, 20]          [15, 7]
```

### 代码实现

```java
public List<List<Integer>> levelOrder(TreeNode root) {
    List<List<Integer>> result = new ArrayList<>();
    if (root == null) return result;

    Queue<TreeNode> queue = new LinkedList<>();
    queue.offer(root);

    while (!queue.isEmpty()) {
        int levelSize = queue.size();  // 当前层的节点数
        List<Integer> level = new ArrayList<>();

        for (int i = 0; i < levelSize; i++) {
            TreeNode node = queue.poll();
            level.add(node.val);
            if (node.left != null) queue.offer(node.left);
            if (node.right != null) queue.offer(node.right);
        }

        result.add(level);
    }

    return result;
}

// 变体：锯齿形层序遍历（之字形）
public List<List<Integer>> zigzagLevelOrder(TreeNode root) {
    List<List<Integer>> result = new ArrayList<>();
    if (root == null) return result;

    Queue<TreeNode> queue = new LinkedList<>();
    queue.offer(root);
    boolean leftToRight = true;

    while (!queue.isEmpty()) {
        int levelSize = queue.size();
        LinkedList<Integer> level = new LinkedList<>();

        for (int i = 0; i < levelSize; i++) {
            TreeNode node = queue.poll();
            if (leftToRight) {
                level.addLast(node.val);   // 正序
            } else {
                level.addFirst(node.val);  // 逆序
            }
            if (node.left != null) queue.offer(node.left);
            if (node.right != null) queue.offer(node.right);
        }

        result.add(level);
        leftToRight = !leftToRight;  // 下一层翻转方向
    }

    return result;
}
```

### 复杂度

- 时间：O(n)
- 空间：O(n)（最后一层最多 n/2 个节点在队列中）

### 面试追问

**Q：为什么要先记录 `levelSize = queue.size()`？**

因为队列在不断变化（poll 的同时 offer 新节点）。如果用 `while (!queue.isEmpty())` 直接遍历，会把下一层的节点也混进来。先记录当前层的节点数，只处理这么多。

**Q：如何实现自底向上的层序遍历？**

把结果 `Collections.reverse(result)` 即可。

**Q：如何获取每层的平均值？**

每层 sum / levelSize。

## 21. 将有序数组转换为二叉搜索树

### 题目

将升序数组转换为高度平衡的二叉搜索树。

```
输入: [-10, -3, 0, 5, 9]
输出:     0
        /   \
      -3     9
      /     /
    -10    5
```

### 思路分析

**分治法**：取数组中间元素作为根，左半递归构建左子树，右半递归构建右子树。

中间元素的选择：
- 奇数长度：正好中间
- 偶数长度：偏左或偏右都可以，选 `mid = left + (right - left) / 2` 偏左

```
[-10, -3, 0, 5, 9]
       mid=2(0)
      /          \
[-10, -3]        [5, 9]
  mid=0(-10)     mid=0(5)
     \              \
   [-3]             [9]
```

### 代码实现

```java
public TreeNode sortedArrayToBST(int[] nums) {
    return buildBST(nums, 0, nums.length - 1);
}

private TreeNode buildBST(int[] nums, int left, int right) {
    if (left > right) return null;

    int mid = left + (right - left) / 2;
    TreeNode root = new TreeNode(nums[mid]);

    root.left = buildBST(nums, left, mid - 1);
    root.right = buildBST(nums, mid + 1, right);

    return root;
}
```

### 复杂度

- 时间：O(n)
- 空间：O(log n) 递归栈

### 面试追问

**Q：为什么取中间元素作为根？**

中间元素将数组等分，左半都比它小，右半都比它大，天然满足 BST 性质。同时左右子树节点数接近，保证平衡。

**Q：如果要从有序链表构建平衡 BST 呢？**

链表不能 O(1) 随机访问。可以先转成数组 O(n)，再构建 O(n)。或者用快慢指针找中点，但每次找中点 O(n)，总共 O(n log n)。

## 22. 二叉树展开为链表

### 题目

将二叉树按前序遍历展开为单链表（全部右指针连接，左指针为 null）。

```
输入:     1              输出: 1
         / \                   \
        2   5                   2
       / \   \                   \
      3   4   6                   3
                                   \
                                    4
                                     \
                                      5
                                       \
                                        6
```

### 思路分析

**方法一：前序遍历 + 重新连接**

先前序遍历收集所有节点，再逐个连接。

**方法二：后序遍历（右→左→根）原地展开**

从右子树开始展开，维护一个 `prev` 指针指向已展开部分的头。

**方法三：迭代原地展开（最优）**

对每个节点，如果有左子树：
1. 找到左子树的最右节点 `rightMost`
2. 把右子树接到 `rightMost.right`
3. 把左子树移到右边：`root.right = root.left, root.left = null`
4. 移到下一个节点

```
步骤1: 节点1有左子树
       左子树最右节点=4
       4.right = 5(原右子树)
       1.right = 2(原左子树), 1.left = null
       
       1 → 2 → 3 → 4 → 5 → 6
       
步骤2: 节点2有左子树3
       3的最右=3
       3.right = 4(原右子树)
       2.right = 3, 2.left = null
       
       1 → 2 → 3 → 4 → 5 → 6
       
... 节点3、4、5无左子树，跳过
```

### 代码实现

```java
// 方法一：前序遍历 + 重新连接
public void flatten(TreeNode root) {
    List<TreeNode> list = new ArrayList<>();
    preorder(root, list);

    for (int i = 1; i < list.size(); i++) {
        TreeNode prev = list.get(i - 1);
        TreeNode curr = list.get(i);
        prev.left = null;
        prev.right = curr;
    }
}

private void preorder(TreeNode node, List<TreeNode> list) {
    if (node == null) return;
    list.add(node);
    preorder(node.left, list);
    preorder(node.right, list);
}

// 方法二：迭代原地展开
public void flattenIterative(TreeNode root) {
    TreeNode curr = root;
    while (curr != null) {
        if (curr.left != null) {
            // 找左子树的最右节点
            TreeNode rightMost = curr.left;
            while (rightMost.right != null) {
                rightMost = rightMost.right;
            }
            // 右子树接到左子树最右节点的右边
            rightMost.right = curr.right;
            // 左子树变为右子树
            curr.right = curr.left;
            curr.left = null;
        }
        curr = curr.right;  // 移到下一个
    }
}

// 方法三：后序遍历（右→左→根）原地展开
private TreeNode prev = null;
public void flattenPostorder(TreeNode root) {
    if (root == null) return;
    flattenPostorder(root.right);
    flattenPostorder(root.left);
    root.right = prev;
    root.left = null;
    prev = root;
}
```

### 复杂度

| 方法 | 时间 | 空间 |
|------|------|------|
| 前序遍历 | O(n) | O(n) 列表 |
| 迭代原地 | O(n) | O(1) |
| 后序递归 | O(n) | O(h) 递归栈 |

## 23. 路径总和

### 题目

判断树中是否存在根到叶子的路径，使得路径上节点值之和等于 targetSum。

```
输入:       5           targetSum = 22
           / \
          4   8
         /   / \
        11  13  4
       / \       \
      7   2       1

输出: true (5 → 4 → 11 → 2 = 22)
```

### 思路分析

递归到叶子节点，判断剩余值是否等于当前节点值。

### 代码实现

```java
// 路径总和 I：判断是否存在
public boolean hasPathSum(TreeNode root, int targetSum) {
    if (root == null) return false;

    // 叶子节点：判断剩余值是否等于当前值
    if (root.left == null && root.right == null) {
        return root.val == targetSum;
    }

    // 非叶子：递归左右子树，targetSum 减去当前值
    int remaining = targetSum - root.val;
    return hasPathSum(root.left, remaining) || hasPathSum(root.right, remaining);
}

// 路径总和 II：找出所有路径
public List<List<Integer>> pathSum(TreeNode root, int targetSum) {
    List<List<Integer>> result = new ArrayList<>();
    List<Integer> path = new ArrayList<>();
    backtrack(root, targetSum, path, result);
    return result;
}

private void backtrack(TreeNode node, int remaining, List<Integer> path,
                       List<List<Integer>> result) {
    if (node == null) return;

    path.add(node.val);

    // 叶子节点：检查剩余值
    if (node.left == null && node.right == null && remaining == node.val) {
        result.add(new ArrayList<>(path));  // 注意要拷贝
    } else {
        backtrack(node.left, remaining - node.val, path, result);
        backtrack(node.right, remaining - node.val, path, result);
    }

    path.remove(path.size() - 1);  // 回溯
}

// 路径总和 III：任意路径（不需要从根到叶）
// 路径方向只能向下，路径不需要经过根
public int pathSumIII(TreeNode root, int targetSum) {
    // 前缀和 + HashMap
    Map<Long, Integer> prefixSumCount = new HashMap<>();
    prefixSumCount.put(0L, 1);  // 前缀和为0出现1次
    return dfs(root, 0L, targetSum, prefixSumCount);
}

private int dfs(TreeNode node, long currSum, int target,
                Map<Long, Integer> prefixSumCount) {
    if (node == null) return 0;

    currSum += node.val;
    // 看有多少个前缀和等于 currSum - target
    int count = prefixSumCount.getOrDefault(currSum - target, 0);

    // 更新前缀和
    prefixSumCount.merge(currSum, 1, Integer::sum);

    // 递归
    count += dfs(node.left, currSum, target, prefixSumCount);
    count += dfs(node.right, currSum, target, prefixSumCount);

    // 回溯：撤销当前前缀和
    prefixSumCount.merge(currSum, -1, Integer::sum);

    return count;
}
```

### 复杂度

| 变体 | 时间 | 空间 |
|------|------|------|
| 路径总和 I | O(n) | O(h) |
| 路径总和 II | O(n²) 最坏 | O(h) |
| 路径总和 III | O(n) 前缀和 | O(n) HashMap |

### 面试追问

**Q：路径总和 II 中为什么 `result.add(new ArrayList<>(path))`？**

如果直接 `result.add(path)`，加入的是引用。后续 path 会继续修改（add 和 remove），最终所有结果都指向同一个被改空的 list。必须拷贝一份快照。

**Q：路径总和 III 的前缀和思路？**

类似数组的「子数组和等于 K」。`currSum - prefixSum = target` 说明从那个前缀位置到当前节点的路径和等于 target。用 HashMap 记录前缀和出现的次数。

## 24. 从前序与中序遍历序列构造二叉树

### 题目

给定前序遍历和中序遍历，构造二叉树。

```
前序: [3, 9, 20, 15, 7]
中序: [9, 3, 15, 20, 7]

输出:     3
         / \
        9  20
           / \
          15  7
```

### 思路分析

1. **前序第一个元素是根节点**
2. 在中序中找到根的位置，左边是左子树，右边是右子树
3. 递归构建左右子树

```
前序: [3, 9, 20, 15, 7]  → 根=3
中序: [9, 3, 15, 20, 7]  → 根在index=1
        ←左→     ← 右 →

左子树:
  前序: [9]            （前序中根后面，长度=左子树长度）
  中序: [9]

右子树:
  前序: [20, 15, 7]
  中序: [15, 20, 7]
```

### 代码实现

```java
// 用 HashMap 存中序的值→索引，加速查找
private Map<Integer, Integer> inorderIndexMap;
private int preIndex = 0;  // 前序遍历的指针

public TreeNode buildTree(int[] preorder, int[] inorder) {
    inorderIndexMap = new HashMap<>();
    for (int i = 0; i < inorder.length; i++) {
        inorderIndexMap.put(inorder[i], i);
    }
    return build(preorder, 0, inorder.length - 1);
}

// preRootIndex: 前序中的根位置（通过全局 preIndex 控制）
// inLeft, inRight: 中序中当前子树的范围
private TreeNode build(int[] preorder, int inLeft, int inRight) {
    if (inLeft > inRight) return null;

    int rootVal = preorder[preIndex++];
    TreeNode root = new TreeNode(rootVal);

    // 根在中序中的位置
    int inRootIndex = inorderIndexMap.get(rootVal);

    // 先建左子树（前序顺序：根→左→右，所以先左后右）
    root.left = build(preorder, inLeft, inRootIndex - 1);
    root.right = build(preorder, inRootIndex + 1, inRight);

    return root;
}
```

### 复杂度

- 时间：O(n)（HashMap 查找 O(1)）
- 空间：O(n)（HashMap + 递归栈）

### 面试追问

**Q：为什么必须先递归左子树再递归右子树？**

因为 `preIndex` 是全局递增的，前序遍历顺序是「根左右」。如果不先左后右，`preIndex` 会取到错误的值。

**Q：能不能从中序和后序构造？**

可以。后序最后一个元素是根，在中序中找根位置后分左右。递归顺序变为「先右后左」（因为后序是「左右根」，逆着来要先右后左）。

**Q：前序和后序能唯一确定一棵树吗？**

不能。前序和后序无法区分「只有左子树」和「只有右子树」的情况。例如：

```
前序 [1, 2]，后序 [2, 1]
可能是: 1        也可能是: 1
       /                    \
      2                      2
```

## 25. 二叉搜索树中第 K 小的元素

### 题目

给定一棵 BST，找到其中第 K 小的元素。

### 思路分析

**BST 的中序遍历是升序序列**。所以中序遍历到第 K 个就是答案。

```
BST:
    3
   / \
  1   4
   \
    2

中序: 1 → 2 → 3 → 4
k=1 → 1, k=2 → 2, k=3 → 3
```

### 代码实现

```java
// 方法一：中序遍历到第 k 个停止
private int result;
private int count;

public int kthSmallest(TreeNode root, int k) {
    count = k;
    inorder(root);
    return result;
}

private void inorder(TreeNode node) {
    if (node == null || count == 0) return;

    inorder(node.left);

    // 访问当前节点
    count--;
    if (count == 0) {
        result = node.val;
        return;
    }

    inorder(node.right);
}

// 方法二：迭代中序（可以提前终止）
public int kthSmallestIterative(TreeNode root, int k) {
    Deque<TreeNode> stack = new ArrayDeque<>();
    TreeNode curr = root;

    while (curr != null || !stack.isEmpty()) {
        while (curr != null) {
            stack.push(curr);
            curr = curr.left;
        }
        curr = stack.pop();
        k--;
        if (k == 0) return curr.val;
        curr = curr.right;
    }
    return -1;  // 不应该到这里
}
```

### 复杂度

- 时间：O(k)（迭代法可以提前终止）或 O(n)（递归法）
- 空间：O(h)

### 面试追问

**Q：如果频繁查询第 K 小怎么做？**

在节点中维护 `leftCount`（左子树节点数）。查询时：
- 如果 `leftCount == k-1`，当前节点就是第 K 小
- 如果 `leftCount >= k`，去左子树找
- 如果 `leftCount < k-1`，去右子树找，k 减去 `leftCount + 1`

这样每次查询 O(h)，但插入/删除需要维护 leftCount。

**Q：如何找第 K 大？**

中序遍历反过来（右→根→左），就是降序序列。或者找第 `n - k + 1` 小。

### 常见陷阱

```
陷阱1: 修改链表时忘记用 dummy 处理头节点变化
解决: 一律用 dummy，返回 dummy.next

陷阱2: 删除节点后忘记连接前后
解决: 画图，标注 prev/curr/next 三个指针

陷阱3: 反转链表时断链
解决: 先存 next，再改指针

陷阱4: LRU 忘记从 HashMap 删除被淘汰节点
解决: removeTail 后 cache.remove(key)

陷阱5: 回文链表只比较了值，没恢复链表
解决: 面试官可能要求恢复，写上恢复代码
```

### 代码模板

```java
// 反转链表（万能模板）
ListNode reverseList(ListNode head) {
    ListNode prev = null, curr = head;
    while (curr != null) {
        ListNode next = curr.next;
        curr.next = prev;
        prev = curr;
        curr = next;
    }
    return prev;
}

// 快慢指针找中点
ListNode slow = head, fast = head;
while (fast != null && fast.next != null) {
    slow = slow.next;
    fast = fast.next.next;
}
// slow 在中点

// 哨兵节点模板
ListNode dummy = new ListNode(0, head);
// ... 操作 ...
return dummy.next;
```

## 27. 树技巧总结

### 核心技巧

| 技巧 | 适用场景 | 代表题目 |
|------|----------|----------|
| **递归（后序）** | 需要左右子树信息汇总 | 最大深度、直径、LCA |
| **递归（前序）** | 自顶向下传递信息 | 路径总和、翻转 |
| **中序遍历** | BST 相关问题 | 验证BST、第K小、中序 successor |
| **BFS 层序** | 按层处理 | 层序遍历、最小深度、锯齿遍历 |
| **范围约束** | BST 验证 | 验证BST |
| **前缀和** | 路径计数 | 路径总和 III |
| **分治** | 构建树 | 有序数组转BST、前序中序构造 |

### 递归思维框架

```
树的问题大多数可以套这个框架：

1. 明确递归函数的定义（返回什么）
2. Base case（空节点返回什么）
3. 递归左右子树
4. 用左右子树的结果组合出当前节点的结果

例子 — 最大深度：
定义: 返回以 node 为根的树的最大深度
Base: node == null → 返回 0
递归: leftDepth = f(node.left), rightDepth = f(node.right)
组合: return 1 + max(leftDepth, rightDepth)
```

### 常见陷阱

```
陷阱1: 验证 BST 只比较父子，没比较整棵子树
错误: node.left.val < node.val && node.right.val > node.val
正确: 传递 (min, max) 范围约束

陷阱2: LCA 没考虑 p 是 q 祖先的情况
解决: base case 中 root == p || root == q 直接返回

陷阱3: 路径总和 II 中 result.add(path) 没拷贝
解决: result.add(new ArrayList<>(path))

陷阱4: 层序遍历没记录 levelSize，混层
解决: int levelSize = queue.size() 后再 for 循环

陷阱5: 前序+中序构造树，preIndex 顺序错误
解决: 必须先左后右（前序是根左右）
```

### 代码模板

```java
// 通用递归模板
TreeNode dfs(TreeNode node) {
    if (node == null) return;  // base case
    // 前序位置：处理当前节点（自顶向下）
    dfs(node.left);
    // 中序位置：BST 相关
    dfs(node.right);
    // 后序位置：汇总左右子树信息（自底向上）
}

// BFS 层序模板
Queue<TreeNode> queue = new LinkedList<>();
queue.offer(root);
while (!queue.isEmpty()) {
    int size = queue.size();
    for (int i = 0; i < size; i++) {
        TreeNode node = queue.poll();
        // 处理 node
        if (node.left != null) queue.offer(node.left);
        if (node.right != null) queue.offer(node.right);
    }
}

// 中序遍历模板（迭代）
Deque<TreeNode> stack = new ArrayDeque<>();
TreeNode curr = root;
while (curr != null || !stack.isEmpty()) {
    while (curr != null) {
        stack.push(curr);
        curr = curr.left;
    }
    curr = stack.pop();
    // 访问 curr
    curr = curr.right;
}
```

## 28. 10 道面试高频题

### Q1：如何判断链表有环？为什么快慢指针一定相遇？

**答**：用快慢指针，慢指针走 1 步，快指针走 2 步。如果有环，两者一定在环内相遇。因为快指针比慢指针每步多走 1 步，两者的距离每次缩小 1，在环内距离一定会缩小到 0。如果快指针走 3 步则不一定（可能跳过）。

找入环节点：相遇后，一个指针从头出发，另一个从相遇点出发，都走 1 步，再次相遇就是入环节点。数学推导：`a = (n-1)(b+c) + c`，头到入环点距离 = 相遇点到入环点距离 + 整数圈。

---

### Q2：LRU 缓存怎么实现？为什么用双向链表？

**答**：HashMap + 双向链表。HashMap 提供 O(1) 查找，双向链表维护访问顺序。

双向链表的原因：删除节点需要修改前驱的 next 指针，单向链表找前驱要 O(n)，双向链表通过 `node.prev` 直接 O(1)。同时使用虚拟头尾节点，避免空指针特判。

`get`：HashMap 查找 → 找到则移到链表头部 → 返回值。
`put`：HashMap 查找 → 存在则更新值并移到头部 → 不存在则新建节点加到头部，超容量则删除尾部节点（同时从 HashMap 删除）。

---

### Q3：如何反转链表的一段区间？

**答**：找到第 m-1 个节点 pre，然后用头插法反转 [m, n] 区间。核心操作：

```java
for (int i = 0; i < n - m; i++) {
    ListNode next = curr.next;
    curr.next = next.next;
    next.next = pre.next;
    pre.next = next;
}
```

头插法每次把 curr 的下一个节点插到 pre 后面，重复 n-m 次就完成区间反转。K 个一组反转就是反复调用这个逻辑。

---

### Q4：二叉树的三种遍历有什么区别？中序遍历为什么重要？

**答**：
- 前序（根左右）：先处理根，适合「自顶向下」传递信息。
- 中序（左根右）：根在中间，BST 中序遍历是升序序列，这是 BST 题目的核心工具。
- 后序（左右根）：最后处理根，适合「自底向上」汇总信息。

中序遍历重要因为：
1. BST 的中序遍历是有序的，可以用来验证 BST、找第 K 小、找前驱后继。
2. 中序 + 前序（或中序 + 后序）可以唯一构造一棵二叉树。

---

### Q5：如何验证一棵树是 BST？只比较左右子节点够吗？

**答**：不够。只比较 `node.left.val < node.val` 只验证了直接子节点，没有验证整棵子树。

```
错误示例:
    5
   / \
  1   8
     / \
    4   9    ← 4 < 5，不是合法 BST！
```

正确方法：传递 `(min, max)` 范围约束。左子树所有节点值必须 < 当前值，右子树所有节点值必须 > 当前值。或者用中序遍历检查是否严格递增。

---

### Q6：二叉树的最近公共祖先怎么找？

**答**：递归。如果当前节点是 null 或等于 p 或 q，返回当前节点。递归左右子树，如果左右都非 null，当前节点就是 LCA（p 和 q 在两侧）。如果只有一边非 null，返回那一边。

关键理解：递归函数的定义是「在以 root 为根的子树中找 p 和 q 的 LCA」。如果只找到了一个（比如 p），就返回 p 所在的节点。如果 p 是 q 的祖先，递归到 p 时直接返回 p，不需要继续往下找 q。

BST 可以优化为 O(h)：利用 BST 性质，p 和 q 都在左则往左，都在右则往右，分叉点就是 LCA。

---

### Q7：二叉树层序遍历如何按层分组？

**答**：BFS + 记录每层大小。关键是在处理每一层之前先记录 `int levelSize = queue.size()`，然后只出队 levelSize 个节点。因为队列在不断变化（出队的同时入队下一层节点），如果不记录 levelSize，会把下一层的节点混入当前层。

锯齿形遍历：在正常层序基础上，奇数层正序（addLast），偶数层逆序（addFirst），用一个布尔标志控制方向。

---

### Q8：路径总和的三种变体有什么区别？

**答**：
- **路径总和 I**：判断是否存在根到叶路径和等于 target。递归到叶子节点判断剩余值。O(n)。
- **路径总和 II**：找出所有根到叶路径。回溯法，到达叶子时检查，注意 `result.add(new ArrayList<>(path))` 要拷贝。最坏 O(n²)。
- **路径总和 III**：任意路径（不要求根到叶，方向只能向下）。用前缀和 + HashMap，`currSum - prefixSum = target` 说明从那个前缀位置到当前的路径和等于 target。O(n)。

---

### Q9：前序+中序如何构造二叉树？为什么不能只用前序+后序？

**答**：前序第一个是根，在中序中找到根的位置，左边是左子树，右边是右子树。递归构建。

为什么需要中序？因为中序提供了「左右子树分界」的信息。前序只知道根是谁，不知道左右子树各有多少节点。中序中根的位置将数组分成左右两半，确定了子树范围。

前序+后序不能唯一确定：当某个节点只有一个子节点时，前序和后序无法区分这个子节点是左子还是右子。

---

### Q10：链表和树有什么共同点？哪些技巧是通用的？

**答**：
1. **递归思维**：链表和树都是递归数据结构。链表的递归是 `head → head.next`，树的递归是 `root → root.left + root.right`。
2. **快慢指针**：链表找中点，树也可以用快慢指针找路径中点（如验证平衡树）。
3. **分治**：链表归并排序和树的分治本质相同——分成子问题、递归求解、合并结果。
4. **中序遍历**：链表本身是「退化」的二叉树（只有 right 指针），链表遍历就是二叉树的右链遍历。
5. **回溯**：链表路径和树路径都常用回溯法维护「当前路径」。

> **学习建议**：
> 1. **链表题**先掌握反转链表模板，90% 的链表题都会用到它。然后掌握快慢指针和 dummy 节点。
> 2. **树题**先掌握三种遍历（递归 + 迭代），再掌握后序递归的「汇总信息」思维。
> 3. **BST 题目**永远先想中序遍历——BST 中序遍历是有序数组。
> 4. **LRU 缓存**是面试大厂必考题，一定要能完整手写。
> 5. 每道题先画图，理清指针变化，再写代码。链表和树题的 bug 大多来自指针指向错误。
