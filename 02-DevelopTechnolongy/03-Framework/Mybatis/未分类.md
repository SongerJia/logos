## MyBatis 整体优先级

```
第一梯队（面试必考，源码级）：
  01 核心工作流(四大对象)  >  02 映射机制(#{}${}/resultMap)  >  04 缓存机制  >  06 Spring 整合

第二梯队（高频问答+工程实践）：
  03 动态 SQL  >  05 插件/PageHelper

第三梯队（会用+知道原理即可）：
  07 MP 增强
```

**推荐笔记顺序**：`01 → 06 → 02 → 03 → 04 → 05 → 07`

理由：先建立核心工作流的全景视图(01)，再看它怎么融入 Spring 生态(06)（这是面试最爱结合着问的），然后学映射和动态 SQL 这些日常开发核心(02+03)，接着深入缓存机制(04)（和 HashMap 连接），再到插件原理(05)（和 MP 分页连接），最后补充 MP 增强(07)。
